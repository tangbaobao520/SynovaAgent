## Q1: 调研 — 这件事以前怎么做的？

### a) 业界最佳实践
哨兵（Sentinels）= 定时巡检 + 基线对比 + 异常告警。业界模式：
- Prometheus AlertManager: 规则引擎 + 静默期 + 分组聚合
- Datadog Watchdog: 自动基线 + 季节性分解 + 异常评分
- AWS GuardDuty: 持续扫描 + 威胁优先级 + 机器学习异常检测
关键设计模式：每个哨兵独立 compute() → 信号池 → 路由 → 专家

### b) 顶级团队怎么做
Anthropic 方式：一个一个来。每个新哨兵独立 commit，验证通过再下一个。
顺序：先做高频（daily），再做低频（weekly/monthly）。
哨兵接口已定义（Sentinel interface），只需实现 check() 方法。
25 个现有哨兵中有 7 个有真实测量器 compute()，其余 18 个为骨架需要补充。

### c) 我们犯过的错
- memory/project-state-2026-06-17.md: 8 个空壳模块（compute 返回 null）曾注册在 module-registry
- 全量对齐手册 §14: 24 个测量器声称"已实现"，实际只有 7 个真实
- 教训：不工作的代码留在仓库 = 撒谎。每个哨兵必须验证产出真实 finding
