## 项目身份（每次重读）

- SynovaAgent = 组织数字孪生诊断 + 持续增长导航系统。
  诊断是手段，目的是增长。
  核心问题：这家企业的增长卡在哪里？现在该做什么？
- Agent，不是 ChatBot。驻扎企业，持续观测，主动发现，自动诊断，给出行动建议，跟踪执行。
- 五层架构：L1(交互)→L2(编排)→L3(洞察)→L4(本体)→L5(存储)，只能向下依赖相邻层。
- 8 位专家: strategy / org / finance / tech / marketing / action / business_model / knowledge
- 完整数据流:
  原始数据 → 本体层(电子病历) → 7维度×25测量器 → 证据池 → 专家ReAct推理 → 诊断报告

## Q1: 调研 — 这件事以前怎么做的？

### a) 业界最佳实践
- RAG范式: extraction prompt优化 = 更精准的few-shot + 行业schema
- Anthropic: structured outputs + schema约束 → 提高提取准确度

### b) 顶级团队怎么做
- 先分析当前提取失败模式 → 针对最差维度优化 → A/B对比
- 不改核心代码 → 优化extraction prompt模板 + 增加行业特定的维度定义

### c) 我们犯过的错
- DocExtractor在某些行业(制造业)维度覆盖不足
- 根因: 维度定义的行业适配不够
