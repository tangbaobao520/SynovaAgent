## Q1: 调研 — 业界最佳实践 / Anthropic 决策链 / memory 历史教训
a) 业界：git clone 是 git 官方完全隔离工作区机制（独立 .git/index/HEAD）；`git clone --local` 走硬链接秒级完成。注意点：local clone 的 origin 指向本地源路径，push 前必须 `git remote set-url origin` 指回 GitHub，否则 push 会打进主工作区（事故源）。
b) 顶级团队：每任务独立 checkout/容器、共享主干只读，是 monorepo 多 agent 协作通行做法（Anthropic 多 session 隔离同理：独立上下文 + 独立工作区 + 权威 CI）。
c) memory 历史教训：并行会话 stash 事故（禁 stash）、D320 提交劫持（共享暂存区）、D328-D335 多起共享 .git 中间态事故、D482 worktree 中途迁移九步要领——全部指向同一根因：共享 .git/worktree 的中间态互相污染；独立 clone 是根治（同 D540 结论）。
参考：Anthropic/第一性原理 + 结论：隔离单元从 worktree 升格为 clone，skill 文本必须与物理机制一致，否则 agent 按 skill 走就会违规。
