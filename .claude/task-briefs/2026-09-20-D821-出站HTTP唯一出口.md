### c) 决策参考系（D333 四步）
① 第一性原理：一个企业内网能装上的前提是"出网只有一条路"。**出站解析分散 = 有时走代理有时不走**（CTO 卡原话），因此必须先收敛出口，再谈代理生效。
② Anthropic 工程基线：fail-closed —— 声明了代理而代理不可达时，**报错**优于悄悄直连（否则企业会以为流量过了代理，实际绕过了合规网关）；降级必须显式 `degraded: true` + `reason`。
③ 开源实证：DSH `dsh-http-proxy` 536 行实证了「解析顺序 / loopback 整段 / 不可用值降级不阻断」三条语义（见 a 表）；同时实证了其**不支持** CIDR 与 SOCKS 真转发 → 我方按 ①范式复用语义 + ③自建补齐。
④ 收敛检查：①②③ 同向 —— 唯一出口 + 显式降级 + 不可达即失败，无一条要求"静默回退"。
**结论（参考：第一性原理 + Anthropic fail-closed + DSH 源码实证 + 收敛）：出口唯一、不可用值降级不阻断、代理不可达报 `PROXY_UNREACHABLE` 且 `degraded=true`、出口不重试。**
