## 1. 行动项持久化（P0 — 数据丢失风险）

**问题：** `src/routes/actions-api.ts` 使用内存 Map 存储行动项。服务重启后所有行动项丢失。PRD 中右栏的行动跟踪依赖于持久化行动项。

**修复：**
```
src/routes/actions-api.ts
  把 const store = new Map<string, ActionItem>()
  改为 AgentMemoryStore 持久化
  调用 memoryStore.remember() 和 memoryStore.recall()
  状态更新时调用 memoryStore.recall() -> 修改 value -> memoryStore.remember()
```

**参考：** `src/l4/agent-memory-store.ts` 的 `remember()` 和 `recall()` 接口

**验收：** 重启服务后 GET /api/actions 返回上一次创建的相同行动项
