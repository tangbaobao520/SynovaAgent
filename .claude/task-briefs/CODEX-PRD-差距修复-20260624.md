### 修复 3: 行动项持久化

**问题:** src/routes/actions-api.ts L27 使用 `const store = new Map<string, ActionItem>()`。服务重启后全部行动项丢失。

**涉及的免疫细胞:** `memory/lessons-file-lost.md` (warn, 1次) — 知识资产没有备份。行动项是客户确认的方案，丢失意味着企业跟进的信息丢失。

**修复步骤:**

步骤 1 — 在 actions-api.ts 中 import AgentMemoryStore:
```ts
import { AgentMemoryStore } from '../l4/agent-memory-store';
```

步骤 2 — 创建 action 时以 type='enterprise_fact' 持久化:
```ts
await memoryStore.remember({
  orgId: workspaceId,
  key: `action_${id}`,
  value: JSON.stringify(item),
  type: 'enterprise_fact',
  confidence: 0.9,
  source: 'user_confirmed',
  tags: ['action', status],
  expiresAt: null
});
```

步骤 3 — 读取 action 时从 memoryStore recall:
```ts
const actions = await memoryStore.recall({ orgId: workspaceId, type: 'enterprise_fact', tags: ['action'] });
```

步骤 4 — 更新状态时 rewrite:
```ts
await memoryStore.remember({ orgId: workspaceId, key: `action_${id}`, value: JSON.stringify(updatedItem), ... });
```

**验收:** 创建 action → 重启服务 → GET /api/actions 返回相同的 action。原有 Map 保留为缓存层（可选）。
