# Task: SOG 本体层扩展 —— 补充 5 节点 + 3 边

> 基于 SOG v1.0 现有 17 节点 + 14 边，补充管理经济学知识体系要求的缺失部分
> 执行方式：只加 JSON Schema 文件，不改代码
> 文件位置：extensions/ontology/node-types/ 和 extensions/ontology/edge-types/

---

## 一、改动清单

### 新增 5 个节点

| 节点 | 文件 | 管理经济学关联 |
|------|------|-------------|
| Product | node-types/product.json | 定价、单位经济、竞争分析 |
| Supplier | node-types/supplier.json | 交易成本、供应链风险 |
| Market | node-types/market.json | 市场结构、博弈论 |
| Channel | node-types/channel.json | 获客成本、渠道效率 |
| Activity | node-types/activity.json | 价值链、Agent 就绪度 |

### 新增 3 条边

| 边 | 文件 | 管理经济学关联 |
|----|------|-------------|
| SELLS_TO | edge-types/sells-to.json | 收入归因、客户价值 |
| SOURCES_FROM | edge-types/sources-from.json | 交易成本、供应链依赖 |
| COMPETES_WITH | edge-types/competes-with.json | 竞争格局、博弈论 |

---

## 二、验收标准

```
1. 全部 5 个节点 JSON 在 extensions/ontology/node-types/ 下存在
2. 全部 3 条边 JSON 在 extensions/ontology/edge-types/ 下存在
3. 每个 JSON 的 tags 值都在 tags.json 的合法值集合内（禁止 "commercial" 等非法标签）
4. 文件格式与现有文件一致（单行 JSON，无格式化）
5. node-types 目录共 22 个文件（原 17 + 新 5）
6. edge-types 目录共 17 个文件（原 14 + 新 3）
7. pre-commit 检查通过（manifest 完整、tags 合法）
8. 无需改动任何 .ts 文件
```

## 三、改动详情（已完成）

文件已创建。以下是每个文件的具体内容供审核。

### node-types/

**product.json** — Product 节点
- requiredProps: name
- optionalProps: productType(physical|digital|service|platform), unitPrice(number), unitCost(number), status(active|discontinued|development), category(string)
- tags: operational, commercial, generic

**supplier.json** — Supplier 节点
- requiredProps: name
- optionalProps: supplierType(raw_material|component|service|technology|distribution|other), status(active|inactive|contracted), annualSpend(number), alternativeCount(number)
- tags: operational, commercial, generic

**market.json** — Market 节点
- requiredProps: name
- optionalProps: marketType(geographic|industry|demographic|segment|channel), marketShare(number), growthRate(number), stage(emerging|growing|mature|declining)
- tags: strategic, commercial, external

**channel.json** — Channel 节点
- requiredProps: name
- optionalProps: channelType(direct_sales|online|retail|distributor|agent|affiliate|social), costPerAcquisition(number), conversionRate(number), status(active|testing|dormant)
- tags: marketing, operational, generic

**activity.json** — Activity 节点
- requiredProps: name
- optionalProps: activityType(production|marketing|sales|service|rd|administration|partnership), costShare(number), valueDriver(string), agentReadiness(human_only|human_led|agent_assisted|agent_led|fully_automated)
- tags: operational, strategic, generic

### edge-types/

**sells-to.json** — SELLS_TO 边（Product → Client）
- optionalProps: annualContractValue(number), startDate(string), endDate(string), penetration(number)
- tags: operational, financial

**sources-from.json** — SOURCES_FROM 边（Supplier → Client/Process）
- optionalProps: annualValue(number), frequency(one_time|monthly|quarterly|annual), switchDays(number), contractEndDate(string)
- tags: operational, strategic

**competes-with.json** — COMPETES_WITH 边（Product/Market → Product/Market）
- optionalProps: intensity(low|medium|high|direct), advantageScore(number), dimension(price|quality|service|technology|brand)
- tags: strategic, marketing
