### c) 决策

已有覆盖 → 就地替换，不新建。

**关键取舍：`src/services/llm-cost.ts` 的 `'deepseek-chat'` 键保留不动。**
它是**成本查询的向后兼容别名键**，不是「当前模型」声明——已存量的
`llm-credential-store` / 历史调用记录里仍可能是旧 id，删掉会让这些查询
静默掉进 `default` 分支（铁律 11 静默降级）。同一文件已有
`deepseek-v4-flash` / `deepseek-v4-pro` 键，新 id 直接命中，不需要改。

**替换目标 id 的选择**：DSH 侧实测（2026-09-10，api.deepseek.com）真实 id 只有
`deepseek-flash` 与 `deepseek-v4-pro`；`deepseek-v4-flash` / `deepseek-chat` /
`vision-exp` 目前都解析到同一后端 `deepseek-flash`。选 `deepseek-v4-flash`：
① 与 DSH 侧 `~/.dsh/settings.yaml` 保持一致；② 官方 V4 命名，后端切换后自动生效；
③ 今天调用行为与 `deepseek-chat` 完全等价，属**前瞻性命名迁移，非行为变更**。
