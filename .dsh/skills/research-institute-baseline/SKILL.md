## 二、TD-001（版本锚定，创始人 2026-09-24 决策）

- **锚定 DSH `0.1.7-alpha.2`**（内核源码构建）；**唯一判据 = 测量对象 + 绝对路径**（源码树 HEAD `00102833`）；Desktop 打包运行时**不作判据**（回滚档）。
- **强度**：锁定 + **计划解冻**（T1 非 alpha/rc 发布／T2 安全漏洞上游已修／T3 需要无法绕过的新能力／T4 客户合规／T5 已知问题阻塞交付且无变通）。
- **解冻七项准入**（全过）：契约测试／打包冒烟／旧 session 可恢复／回滚单元=容器级版本化发布／回滚不丢数据／**禁止就地改**／准入失败不发布；**用例必须穿生产入口**。
- **允许平移型解冻**（alpha→另一 alpha）；等正式版 = 永不解冻。
- ⚠️ 随锚定锁进的已知问题：macOS 沙箱行为、`session-query-sqlite` 默认 `:memory:`、`mcp-client`/`schedule`/`webhook`/`time-context` 默认零挂载、`session-log-deepseek` 默认开。
- **回滚档** `0.1.6-alpha.2` = 候选，**待准入验证**（数据无损回退不成立）。

## 三、研究议程纪律（对全院生效，我方同步）

1. 不再引用 M3-1 的"不存在／为 0"类读数（数字与结论作废）。
2. **所有对象绑定必须写明「哪个仓库的 HEAD」**（无 `.git` 的目录会落到父仓库）。
3. 靠"扫描某目录"得"不存在"的结论，**必须先证明该目录被完整拷贝**。
4. 判据 = **穿生产入口的用例**，不是 grep。
5. 数字使用规则（见 §〇.5）。
6. 宪章级文件必须自带可复核性：**证据节 + 反例与失效条件 + 未核实清单 + 推断与事实分标**。

**§7.6 七环研究链条**：①取证 → ②**综合（⚠️ 历次事故**全部**出在这一环）** → ③独立复核（复核者自写探针、**不看原结论**） → ④登记 → ⑤分流 → ⑥使用 → ⑦约束。
**规则**：不必每次全走；**但凡进入「决策依据」的产出，必须走满 ②③④⑤⑥**。事故共同点全是**转述失真**，不是取证错误。
