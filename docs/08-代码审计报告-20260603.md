**具体改动**:

在 `src/server.ts` 中，路由注册之前添加 Token 验证中间件：

```typescript
// 在 app.use(cors()) 和 app.use(express.json()) 之后添加
import { loadConfig } from './config';

// Token 认证中间件（排除健康检查和 Web 界面）
app.use((req, res, next) => {
  const config = loadConfig();
  // 健康检查 / 静态页面不鉴权
  if (req.path === '/health' || req.path === '/' || req.path.startsWith('/api/status')) return next();
  // DEV_MODE 下跳过鉴权
  if (config.devMode) return next();
  // 检查 API Token
  const token = req.headers['authorization']?.replace('Bearer ', '') || req.query.token as string;
  if (config.engineTokens && token !== config.engineTokens) {
    return res.status(401).json({ ok: false, code: 'UNAUTHORIZED', message: '缺少或无效的 API Token' });
  }
  next();
});
```

⚠️ 注意 `config.loadConfig()` 每次调用解析环境变量——不要在热路径中反复调用。上面只是示意结构，建议在启动时读取一次并注入。
