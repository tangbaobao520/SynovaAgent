## 1. 缺陷链（现状 → 失效点）

| # | 链路 | 现状 | 失效点 |
|---|---|---|---|
| L1 | 工具循环 → provider 边界 | `tool-loop-executor.ts:106-113` 取 `listTools()` 并 `toOpenAITools()` 传入 | `base.ts:139-146` 组装 body 时不落 `tools` → 出站体恒无 tools（D817 实证 `body_keys_union` 无 tools） |

- 对应验收点：卡②③（前置）；卡⑥（不破坏契约）。

### C. 响应边界：tool_calls → ChatResult.toolCalls

**C1（必做）— `src/providers/base.ts:215-238` `chat()` 映射响应侧 tool_calls**

- 现状：见 §0.3（`:222` 只取 content；`:223` 只要 content 为空就抛 `EMPTY_RESPONSE`）。
- 改后形状（替换 `:221-234` 这段的读取/判空/返回三处）：
  ```ts
  const data = await res.json() as ChatCompletionResponse;
  const message = data?.choices?.[0]?.message;
  const content = message?.content ?? '';
  const rawToolCalls = message?.tool_calls;

    ? rawToolCalls.map((tc, i) => ({

    : undefined;

    throw new DiagnosticAgentError({
      code: ErrorCode.EMPTY_RESPONSE,
  ```
