### 0.11 ⚠️ 独立发现的真实缺陷：`localhost` / `::1` 作为目标**根本连不通**

**取证前提**：真 HTTP server 确实监听在 `127.0.0.1:52030`。实测（sha `c0e68ef2`，稳定复现）：

```
  http://127.0.0.1:52030/  -> REACHED status=200 body=UPSTREAM-DIRECT-MARKER (14ms)
  http://localhost:52030/  -> FAILED code=UPSTREAM_UNREACHABLE phase=connect
                              msg=上游不可达（localhost:52030, ERR_INVALID_IP_ADDRESS）: Invalid IP address: undefined (5ms)
  http://[::1]:52030/      -> FAILED code=UPSTREAM_UNREACHABLE phase=connect
                              msg=上游不可达（[::1]:52030, ERR_INVALID_IP_ADDRESS）: Invalid IP address: undefined (0ms)
```

**根因（定位到行）**：`src/providers/http-exit.ts` 的 `lookupForLocalHost()` 无条件使用**标量回调**：

```js
const lookup: https.RequestOptions['lookup'] = (_hostname, _options, callback) => {
  callback(null, literal, literal.includes(':') ? 6 : 4);
};
```

Node 22 默认启用 happy-eyeballs，会以 **`options.all: true`** 调用 `lookup` 并期望**数组**。最小复现（两个方向均验证）：

```
  [lookup 被调用] hostname=localhost options={"hints":1024,"all":true}
  RESULT: FAILED ERR_INVALID_IP_ADDRESS :: Invalid IP address: undefined
--- 对照：callback 返回数组（遵守 options.all）---
  [lookup 被调用] options.all=true
  RESULT: REACHED status=200
```

→ 结论：**凡 host 非裸 IP 字面量**（`localhost`、`*.localhost`、带方括号的 `[::1]`）必走 lookup → 必然 `ERR_INVALID_IP_ADDRESS`。裸 `127.0.0.1` 能通，是因为 Node 对 IP 字面量**不调用 lookup**。

**影响面（分级）**：
- **不影响本卡字面验收**：本卡验收点只测 `127.0.0.1`/`127.0.0.2` 绕过与代理生效，故卡面不会红。
- **阻断「唯一出口可迁移性」结论**：模块自身 `isLocalPrivateHost()` 把 `localhost`/`::1` 判为 `'loopback'`（应绕过代理**且能直连**），JSDoc 亦称"本机私有目标不得经过 DNS"，**但实测不可达** → 实现与自身分类/文档不一致（属**声称与实测不符**）。
- **D862 迁移时的成片风险**：`src/` 既有调用点大量使用 `http://localhost:${port}/...`，例如 `src/tools/marketing-expert-tools.ts:9`、`src/tools/finance-expert-tools.ts:9`、`src/tools/strategy-expert-tools.ts:9`、`src/agent/synova-agent.ts:57`、`src/tui-v2/chat.tsx:248`。

**建议修法**（一行级）：`if (options?.all) callback(null, [{ address: literal, family }]) else callback(null, literal, family)`。

**自验员处置**：**未修改任何被测文件**（红线）；已上报队长。**队长裁决：冻结前修**（采纳三条理由：实现与自身分类/JSDoc 不一致；D862 迁移时会成片踩中 `http://localhost:${port}/...`；退出唯一出口不应有该盲区）。
