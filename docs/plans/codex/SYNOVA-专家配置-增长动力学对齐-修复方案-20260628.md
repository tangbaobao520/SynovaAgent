# 战略专家理论基础

## 诊断定位

战略专家的诊断范围覆盖增长动力学的两个诊断层：

1. **环境层 (E1-E6)**：企业在什么样的市场里？市场在成长还是衰退？竞争窗口在打开还是关闭？客户需求在怎么变？
2. **界面层生态位质量与壁垒 (I1-I6)**：企业在这个市场里占据什么位置？这个位置有多宽、多深？壁垒是结构性的还是运营性的？在价值网络中的议价能力如何？

战略专家不负责生态位的"实现方式"（那是 business_model 专家的 I7-I13）——只负责生态位的"位置质量"和"壁垒强度"。

## 理论支柱

### 环境层理论 (E1-E6)

| 理论 | 来源 | 对应哨兵 | 核心问题 |
|------|------|---------|---------|
| 产业生命周期理论 | Gort & Klepper (1982), Klepper (1996) | E1 | 市场处于生命周期的哪个阶段？天花板在哪？ |
| 技术-经济范式理论 | Perez (2002) | E2, E6（校准参数） | 企业处于AI革命的哪个阶段？有没有临界窗口？ |
| 技术间断理论 | Tushman & Anderson (1986) | E2 | 是否存在能力破坏型技术间断？ |
| 五力分析 | Porter (1979) | E3 | 行业的结构性利润率是多少？谁在吃掉利润？ |
| JTBD + 颠覆式创新 | Christensen (1997) | E4 | 客户"雇佣"产品完成的任务在变吗？低端市场是否在被忽视？ |
| VRIN 反向推导 | Barney (1991) | E5 | 增长多少来自能力，多少来自环境红利？ |
| 创造性破坏 | Schumpeter (1942) | E6 | 游戏规则是否在永久改变？ |

### 界面层理论 (I1-I6)

| 理论 | 来源 | 对应哨兵 | 核心问题 |
|------|------|---------|---------|
| 生态位理论 | Hutchinson (1957), Levins (1968) | I1, I2 | 生态位有多宽、多深？是否正在被挤压？ |
| 7 Powers 竞争壁垒 | Helmer (2016) | I3, I4 | 护城河是结构性的还是运营性的？强度在增强还是减弱？ |
| 结构洞理论 + 网络科学 | Burt (1992), Barabási (2002) | I5 | 在价值网络中的议价能力？桥接了多少结构洞？ |
| 价值捕获理论 | Brandenburger & Stuart (1996) | I6 | 创造的价值保留了多少？被供应商/客户/竞争者拿走了多少？ |

## 诊断逻辑

### 环境层诊断逻辑

1. **市场阶段判断 (E1)**: 行业增速 + 净进入率 + 价格战频率 → 生命周期阶段
2. **窗口检测 (E2)**: 技术窗口 + 政策窗口 + 需求窗口 → 综合窗口评分
3. **竞争格局 (E3)**: HHI 指数 + 竞争强度 + 市场份额变动 → 格局健康度
4. **客户需求迁移 (E4)**（协同 marketing）: 替代品渗透率 + 客户行为变化信号
5. **环境红利依赖 (E5)**: 企业增速 vs 行业增速 → 超额增长来源分析
6. **结构变化预警 (E6)**: 技术-经济范式阶段校准 + 创造性破坏信号

### 生态位质量诊断逻辑

1. **生态位测量 (I1)**: 客户群 × 价格带 × 地理区域 × 产品品类 → 生态位宽度和深度
2. **挤压检测 (I2)**: 竞争者在相同维度上的密度变化 + 利润空间压缩率
3. **壁垒评估 (I3+I4)**: I3 覆盖可量化壁垒（规模经济、网络效应、转换成本、流程优势）；I4 覆盖定性壁垒（品牌、独占资源、反定位）。只判适用的力量，不适用的不评分
4. **网络权力 (I5)**: 结构洞丰富度 + 中介中心性
5. **价值捕获 (I6)**: 支付给供应商 vs 从客户收取 vs 被竞争者拿走的比例

## 技术-经济范式校准

当 meta.techno-economic-phase 字段存在时，所有环境层哨兵的阈值需要校准：
- installation（导入期）: 竞争强度阈值放宽，现金跑道阈值降低
- turning-point（转折点）: F1（融资约束）成为核心哨兵，E5（环境红利依赖性）急剧上升
- deployment（协同期）: 市场集中度阈值提高，流程效率阈值收紧

| 理论 | 来源 | 对应哨兵 | 核心问题 |

| 融资约束理论 | Fazzari et al. (1988), Kaplan & Zingales (1997) | F1 | 增长是否受制于资金不足？投资-现金流敏感性指数 |

## 诊断逻辑（五步）

1. **体质判断 (I7, I8, I9)**: 段永平六问逐项 → 每项 🟢/🟡/🔴 → 六维雷达图。I8（护城河依赖度）引用 I3/I4 的壁垒评估结果回答"当前赚钱方式对护城河的依赖程度"。I9（时间穿透力）回答"十年后这个赚钱方式还在吗"

5. **AI 时代边界重评估 (I13)**: 人-Agent 混合边界的效率——Agent 大幅降低了搜寻/谈判/执行成本，科斯的结论有效但临界点变了

## AI 时代交易成本修正

经典交易成本理论以人为前提。在人+Agent 混合组织中：
- 搜寻成本：Agent 可毫秒级检索 → 下降 90%+
- 谈判成本：Agent 用结构化 schema → 下降 70%+
- 执行成本：Agent 可自动执行 → 下降 80%+
- 监督成本：Agent 可实时验证，但 Agent 本身的输出需验证 → 可能上升

科斯的核心结论（"企业存在是为了将交易成本高的活动内部化"）仍然有效，但临界点变了。原本应该内部化的活动，现在可能通过 Agent 市场更有效率地完成。

| 100 天计划 | 贝恩咨询实践 | 诊断的目的不是报告，是行动 |
| 90 天行动框架 | Synova 设计 | W1-2 快赢 + W3-6 核心行动 + W7-12 系统建设 |

## 瓶颈识别逻辑

`
输入: 六层的健康度得分
  environmentScore = aggregate(E1..E6)
  capitalScore     = aggregate(F1..F5)
  interfaceScore   = aggregate(I1..I13)
  technologyScore  = aggregate(T1..T9)
  alignmentScore   = aggregate(S1..S3)
  internalScore    = aggregate(O1..O10)

bottleneckLayer = argmin(scores)

当多个层得分相近（差距 < 0.1）时，优先级:
  environment > capital > interface > internal > technology > alignment
  （外部的恶化比内部的低效更具破坏性）
`

**五个聚焦步骤在新框架中的映射**:
1. 识别 (Identify) → 找到健康度最低的诊断层
2. 挖尽 (Exploit) → 在该层内找到评分最低的哨兵
3. 服从 (Subordinate) → 检查该哨兵是否对其他层产生级联影响（如环境层恶化 → 资本层融资约束加剧）
4. 提升 (Elevate) → 生成 90 天行动计划
5. 重复 (Repeat) → 下一诊断周期重新评估

## Plan A / Plan B 双轨

- Plan A: 解决当前瓶颈层（argmin 六层健康度得分）
- Plan B: 如果 Plan A 在 3 个月后失败，转向解决次低层
- 双轨方向不一致 → 当前诊断置信度不足以选出一个最优瓶颈层 → 标注"需人工判断"

## 行动项格式

每个行动项必须包含：
1. **做什么**: 可执行的具体动作（不是"提升效率"，是"将审批链从 5 级减为 3 级"）
2. **谁来做**: 角色或负责人
3. **怎么做**: 方法和步骤（3 行以内）
4. **验证标准**: 怎么知道做完了？怎么知道做好了？（具体到数字）
5. **预期效果**: 做好了会带来什么变化——对应哪个诊断层的哪个哨兵得分预期改善
6. **风险**: 可能出什么问题？概率多大？
7. **依赖**: 什么必须先完成？

### 7.3 哨兵 compute 函数的影响

本方案不修改任何哨兵的 compute 函数。但如果 compute 函数的输出字段名与旧术语耦合（如 compute 返回 { division_of_labor: ... }），则：
- 旧 compute（基于 Novis）→ 重写时自然消失
- 新 compute（基于增长动力学白皮书）→ 应该已经使用新术语（如 { niche_breadth: ... }）

**风险**: 如果某个新旧混合的 compute 返回旧术语字段，但专家 prompt 期待新术语，会导致专家"看不懂"哨兵输出。**缓解**: Phase 4 哨兵分配后，对所有受影响的哨兵运行 
pm test 检查。
