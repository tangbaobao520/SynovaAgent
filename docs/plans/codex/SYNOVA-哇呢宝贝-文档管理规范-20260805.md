# SYNOVA-哇呢宝贝-文档管理规范-20260805

> 客户：哇呢宝贝 | 版本：V1.0 | 2026-08-05
> 定位：统一语言层的"存储和执行层"——让一页纸、DACI、会议纪要、日报产出的文档有统一的命名、归位、状态、权限和生命周期。
> 适用范围：全员（含 AI 辅助产出）；客户数据上库规则见第六章。

---

## 一、设计原则

1. **模板即骨架**：不发明新格式。所有文档挂在已培训的四个格式上（一页纸 8 字段 / DACI 表 / 会议纪要 / 日报 5 行），本规范只定"放哪、叫什么、谁来批"。
2. **一个知识库**：ima 为唯一知识库，workbuddy 管协作与任务；禁止微信收藏、个人文件夹、散文档各说各话。
3. **人机分工**：AI 负责草拟、整理、摘要、检索；人负责判断、确认、审批。**AI 产出 ≠ 最终文档**。
4. **数据受控**：客户数据可进 ima 知识库，但必须分级、脱敏、最小化并取得客户同意（见第六章）；数据事实源始终以伙伴云为准。
5. **文档即追踪**：每个文档可关联项目、议题、待办——下周会议核销的是文档里的待办，不是口头承诺。

## 三、命名规范与元数据

### 3.1 统一命名格式

`YYYYMMDD-类型-主题-V版本`

类型取值固定为：`方案 / 决策 / 纪要 / 汇报 / 制度 / 知识 / 档案`，不得自创类型词（如"计划""总结"统一归入方案/汇报）。

示例：
- `20260805-方案-8月提名单-V1`
- `20260805-纪要-周决策会-V1`
- `20260805-汇报-招人组周报-V1`

### 3.2 元数据头（每个文档顶部必填）

| 字段 | 说明 |
|------|------|
| 负责人（D） | 谁推进 |
| 审批人（A） | 谁拍板 |
| 状态 | 草稿 / 待审 / 生效 / 归档 |
| 关联议题/项目 | 挂在哪个项目或决策下 |
| 最后更新 | 日期 + 谁改的 |

**门禁**：命名不规范、元数据缺项 → 打回。

## 五、生命周期与版本（对应 DACI）

### 5.1 状态机

```
草稿 → 待审 → 生效 → 归档 → 删除
```

- **创建者 = D**（Driver），**审批者 = A**（Approver）。
- 制度类 A = 老板或运营中心；方案类 A = 运营中心负责人（与 DACI 规则一致）。
- 不经过审批的文档不能进入"生效"。

### 5.2 版本与修改规则

- 修改不覆盖原文件：生成 V2，并记录"谁、何时、改了啥"。
- 生效后的版本锁定，修改必须走"重新提交 → 待审 → 生效"。

### 5.3 归档与清理

- 项目结束或季度结束后 90 天归档。
- 归档文档加"归档-"前缀（如 `归档-20260805-方案-8月提名单-V1`），与新文档区分。
- 客户数据类按《个人信息保护法》设保留期限，到期清理。

### 5.4 删除规则

- 删除前必须先归档；只有模板管家/运营中心可执行删除。
- 被删除文档在回收站保留 30 天，确认无误后彻底清理。

## 六、AI 使用规范（5 条）

1. **AI 草拟 + 人工审核**：所有 AI 生成文档必须有人审核（方案类 A 确认、纪要类召集人确认），未审核不得进入"生效"。
2. **来源标注**：AI 产出标注"AI 草拟，人审"；涉及数据结论必须注明出处——**数据以伙伴云为准**（防幻觉）。
3. **客户数据上 ima 五条护栏**：客户数据可进入 ima 知识库，但必须满足——
   - ① 最小化：只上服务所需的必要字段，不上与业务无关的信息；
   - ② 脱敏：手机号等直接联系字段脱敏或编号替代，避免明文全量上库；
   - ③ 授权：取得客户同意（入群/签约时告知用途）；宝宝出生日期等敏感信息需单独同意；
   - ④ 权限：仅客服、财务、运营中心指定人可访问，其余人不可见；
   - ⑤ 事实源：数据以伙伴云为准，ima 仅为辅助索引，不一致时以伙伴云为准；关闭 ima 训练选项，客户数据不用于模型训练；设置保留期限，定期清理并备份。
4. **统一提问规范**：给 AI 布置任务用一页纸要素（目标/基线/约束/产出格式），避免发散——对 AI 也只给方向。标准提示词骨架：
   - 目标：我要做什么（一句话，可量化）
   - 基线：现状数据或已知事实（注明来源）
   - 约束：不能做什么 / 数据边界 / 模板要求
   - 产出：交付格式（一页纸 / 纪要 / 话术卡），供谁用
5. **知识沉淀闭环**：AI 辅助做三类自动化——会议纪要 → 待办清单；录音 → 话术卡草稿；日报 → 周报汇总。沉淀到知识库，全员复用。

## 九、文档管理十条（一页速查）

1. 所有文档只进 ima 知识库，不存个人文件夹。
2. 文件名统一：`日期-类型-主题-V版本`。
3. 每份文档顶部必填元数据：负责人 / 审批人 / 状态 / 关联 / 最后更新。
4. 格式只用四套：一页纸、DACI、会议纪要、日报；缺模板不收。
5. 文档状态：草稿 → 待审 → 生效 → 归档 → 删除；不审批不生效，删除先归档。
6. 改文档不覆盖，出新版本，记变更记录。
7. AI 可以草拟，人必须审核；AI 产出标注"AI 草拟，人审"。
8. 数据以伙伴云为准，AI 结论必须注明出处。
9. 客户数据上 ima 必须满足五条护栏：最小化、脱敏、客户同意、权限最小化、事实源以伙伴云为准。
10. 模板管家负责打回；打回不是批评，是标准。

## 附录：四套格式模板（附件）

### A1 一页纸计划（8 字段）

| # | 字段 | 要求 |
|---|------|------|
| 1 | 目标 | 一句话，完成时是什么状态（可量化） |
| 2 | 现状基线 | 从哪开始，必须带数字 |
| 3 | 负责人 | 唯一负责人，不写"协同人" |
| 4 | 关键结果 | 可量化指标，不是"尽全力完成" |
| 5 | 步骤 | 1/2/3/4/5，每步有产出物 |
| 6 | 时间节点 | 每步截止日 + 最终完成日 |
