## 〇、定位与主线

本手册是哇呢宝贝 2026 年下半年的第一曲线作战框架。

- **主线**：年度目标 2000 万（缺口约 1500 万，8-12 月月均需 300 万，当前 90-100 万）。
- **三大最高权重任务**：招人、培训、提名单。
- **配套**：合伙人体系落地、统一语言、汇报体系。
- **三条底线（任何时候不能破）**：现金流为正 / 名单不继续跌 / 销售不流失。

## 一、统一语言层

### 1.1 一页纸计划模板（8 字段）

| # | 字段 | 要求 |
|---|------|------|
| 1 | 目标 | 一句话，完成时是什么状态（可量化） |
| 2 | 现状基线 | 从哪开始，必须带数字 |
| 3 | 负责人 | 唯一负责人，不写"协同人" |
| 4 | 关键结果 | 可量化指标，不是"尽全力完成" |
| 5 | 步骤 | 1/2/3/4/5，每步有产出物 |
| 6 | 时间节点 | 每步截止日 + 最终完成日 |
| 7 | 所需资源/支持 | 钱/人/会所/系统，写明要谁批 |
| 8 | 阻碍因素/风险 | 可能断在哪，提前找谁 |

**门禁**：缺字段、关键结果不可量化、无截止时间 → 当场打回重写。

### 1.2 五个关键定义

- **目标** = 完成时能看到什么变化
- **关键结果** = 可量化的指标，不是"尽全力完成"
- **风险** = 可能阻碍进展的已知因素
- **完成** = 关键结果已达成 + 负责人确认 + 验收人确认
- **延期** = 必须主动沟通原因并提交新时间（如实汇报不惩罚）

### 1.3 汇报体系（内容要求，SOP 各组自定）

- **日报**：统一 5 行（今日做了什么 / 结果 / 卡点 / 明日计划 / 需要的支持），3 分钟填完；各组日报必须含**过程指标**（见第三章各组卡）；经理每天 21:00 前看完并至少回复 1 条——没人看的日报必死。
- **周报**：本周结果 vs 计划 / 下周计划 / 卡点 / 需要的支持，一页纸。
- **月述职**：上月计划 vs 实际结果对照（红绿灯），**不用 PPT**，会上只看差异、问原因、定下月。

## 二、分组方案（打散后的人员重新安排）

### 2.1 分组原则

1. **先定活，再定人**：从第一曲线需要什么任务出发，列出战斗组清单，再把人员对号入座；不从人反推岗位。
2. **三分类法**：
   - **直接上岗**：技能匹配，马上出活；
   - **快速转岗**：技能部分匹配，给 90 天带教期；
   - **待命池**：暂无匹配岗位，给 90 天限期和明确任务，不闲坐。
3. **不碰的岗位先吃定心丸**：销售、生产、客服、财务、调度、老板及运营总监不在重组范围——重组目的是让前线更好打仗，不是动前线。

### 2.2 战斗组清单（人员来源按岗位/部门，具体名单待定）

| 战斗组 | 定位 | 人员来源 | 状态 |
|--------|------|----------|------|
| ① 招人组 | 解决"人数"杠杆 | 人事/行政岗 + 销冠业务面试官 | 负责人待定 |
| ② 培训组 | 解决"转化率+客单价"杠杆 | 销冠 + 产品岗 + 擅长带教的销售 | 负责人待定 |
| ③ 提名单组 | 解决"客户数"杠杆（最紧急） | 渠道岗 + 数据支援 | 负责人待定（不得悬空，须明确唯一负责人） |
| ④ 产品岗（1 人） | 客单价升级（玉石系列、话术卡） | 产品部 | 人选待定 |
| ⑤ 会所赋能内容组 | 谈会所/保会所的弹药（增值材料） | 自媒体留 1 人 + 品牌/设计岗 | 负责人待定 |
| ⑥ 数据/看板岗（1 人） | 统一名单业绩口径 + 周报看板 | 设计/品牌/行政中数据敏感者 | 人选待定 |
| ⑦ 行政日常（1 人） | 报销、后勤、社保等持续职责 | 行政岗 | 人选待定 |
| ⑧ 第二曲线组（2 人） | 同月龄社群运营（已启动） | 内容/运营敏感者 | 全权负责人待定 |
| ⑨ 待命池 | 90 天限期 + 通用任务 | 其余未分配人员 | 限期管理 |

### 2.3 待命池任务（不闲坐）

通用任务：会所档案整理、20 万历史客户盘点（第二曲线与私域盘活的地基）、标准化文档建设。90 天后复盘：转入正式项目 / 转岗 / 结束合作。

### 2.4 分组决策与保护条款

1. **去向总表**由老板 + 运营中心负责人 + 顾问三方共同确定，全员公示；每行 = 现岗位 → 新去向 → 直接上级 → KPI → 90 天复盘标准。
2. **原薪酬 90 天稳定期**，90 天后按新岗位考核。
3. 开放**转销售通道**（销售提成高，愿意上战场的人可以自己挣出来）。
4. 不接受新安排的，给 1 个月过渡期友好分手；**关键人才重点保护**，不因重组流失。

## 五、录音卡动员（一页 PPT 内容）

**标题：录音复盘——除机制之外，提升销售能力最有效的手段**

**为什么是它（3 句话）**
- 我们所有的复盘都靠记忆和汇报，而记忆会美化现场，汇报会掩盖真相。
- 销冠为什么能签单、新人为什么丢单，答案不在汇报里，在现场那 30 分钟里。
- 培训、话术、机制的有效性，全部建立在"知道现场到底发生了什么"之上——录音是唯一能还原现场的工具。

**怎么用（闭环）**
- 每人每周录 1-2 场：成交一场 + 未成交一场，两个都录才算数。
- 新人每场必录；销冠每周录 1 场，作为全组示范。
- 每周拆 3 段：一段销冠的（学什么）、一段新人的（改什么）、一段流失的（为什么没成交）。
- 拆完沉淀话术卡（"客户说太贵→高手怎么说"），全员复用。

**三条规则**
- 录音只用于提升能力，**不用于考核**——这是信任基础。
- 现场分寸由销售自行把握（此前已有做法，不另行规定）。
- 录音文件内部加密存储，仅培训组和经理可见，定期清理。

**第一步（本周）**
- 销冠先录第一场，下周周会全组一起拆——先让团队看到"原来高手是这样说的"。

## 七、会议制度（细化版，可独立转 PPT）

### 7.1 目的与原则

会议不是讨论场所，是**决策和追踪场所**。五条铁律：
1. 固定时间：每周固定 1 小时决策会，到点结束，不拖延。
2. 明确议题：会前定议题，只有跨部门协调或资源分配事项上会；两人能解决的事不上会；没有方案只有问题的，先填一页纸再上会。
3. 必须有结论：每项议题结束时明确"谁 + 做什么 + 什么时候完成"。
4. 结论有约束力：包括老板。改变结论必须回正式会议重新讨论。
5. 下周复盘：下周会议第一项议程复盘上周执行；连续三次未完成 → 约谈，再不改 → 换人。

### 7.2 会议类型与频率

| 会议 | 频率 | 时长 | 参加人 | 产出 |
|------|------|------|--------|------|
| 周决策会 | 每周 1 次（固定时间） | 60 分钟 | 各组负责人 + 运营中心 | 决策 + 待办 + 复盘 |
| 组内日会 | 各组自定（可选） | 10-15 分钟 | 组内成员 | 当日对齐 |
| 月度经营分析会 | 每月 1 次 | 90 分钟 | 核心团队 + 老板 | 红绿灯 + 下月目标 |
| 季度述职会 | 每季度 1 次 | 2-3 小时 | 核心团队 + 老板 | 计划 vs 结果、晋升/调整 |
| 专项会（项目启动/复盘） | 按需 | ≤60 分钟 | 项目相关人 | 一页纸方案 + 结论 |

### 7.3 会前（24 小时前完成）

1. 召集人发布议题清单，每项议题附一页纸方案（8 字段模板）。
2. 参会人提前读完材料——**会上不念稿、不现场读材料**，只讨论问题和结论。
3. 超时议题不硬塞：进"停车场"（待议清单），下次会议优先。

### 7.4 会中（四段式）

1. **背景**：为什么今天开会（一句话）。
2. **目标**：会议结束必须产生什么结果（写下来）。
3. **议程**：每项议题分配时间，主持人控时，到点切换。
4. **结论**：逐项确认决策、待办（谁+做什么+截止日）、下次会议时间。

发言规则：对事不对人；一次一人发言；争论超过 5 分钟没进展 → 主持人叫停，指定 D 会后再议，会上只出结论。

### 7.5 会后（2 小时内 + 次日追踪）

1. 记录人 2 小时内发出会议纪要：决策 / 待办 / 下次会议。
2. 次日由运营中心检查待办进度（谁没动，当天提醒）——不等老板周五来问才发现偏了 3 天。
3. 所有待办进入统一追踪表（伙伴云），下周会议第一项逐条核销。

### 7.6 会议角色

- **召集人**：发起会议、发议题和材料（议题不过审不上会）。
- **主持人**：控时、控流程、叫停扯皮（可由召集人或专人担任）。
- **记录人**：纪要 2 小时内发出。
- **决策人（A）**：该议题的 Approver，会上现场拍板或明确延期到何时拍板。

## 八、DACI 说明（详细版，可独立转 PPT）

> 示例中的人选仅为演示角色分配，最终负责人以分组确认为准。

### 8.1 为什么需要 DACI

典型场景：一件事大家都讨论、都"参与"，但没人推进、没人拍板——结果就是所有人都拖、都推，最后老板一个人扛。DACI 解决一句话：**每个决策，谁推、谁定、谁参与、谁知道，写下来**。决策权一旦可视化，扯皮的动机就消失了——大家不是在争对错，是在争"谁说了算"，DACI 让"谁说了算"变成白纸黑字。

### 8.2 四个角色

| 角色 | 含义 | 职责 | 数量 |
|------|------|------|------|
| **D** Driver 负责人 | 把这件事往前推的人 | 组织讨论、协调资源、催进度、对推进结果负责。可以不是级别最高的人，但必须是"最想把它做成的人" | 必须且只能 1 个 |
| **A** Approver 批准人 | 最终拍板的人 | 对决策后果负责。D 不能替 A 拍板；A 不能替 D 干活 | 必须且只能 1 个 |
| **C** Contributor 参与者 | 提供输入的人 | 提供信息、专业意见、一线反馈；意见会被考虑，但不决定 | 可多个，宁少勿多 |
| **I** Informed 知情人 | 需要知道结果的人 | 只接收结果通知，不参与讨论 | 可多个 |

**记忆口诀：一事一 D、一 D 一 A、C 提供弹药、I 只收结果。**

### 8.3 谁当 A——这家公司的关键规则

- 老板只保留三类事的 Approver 权：**预算费用、人事、超红线事项**。
- 其余日常项目（提名单、培训、招人、产品等）的 A = 运营中心负责人。
- 改结论必须回正式会议，不能在会外推翻——这是 DACI 能活的前提。

### 8.4 怎么填（启动任何重要决策前，随一页纸方案一起交）

1. 定 D：谁推？没有 D 的事，不上会。
2. 定 A：谁拍板？不确定就问运营中心。
3. 列 C：谁的信息是决策必需的？（只列真正需要的）
4. 列 I：谁需要知道结果？（事前通知，不是事后通知）

### 8.5 两个示例

**示例 1：8 月提名单返点预算**

| 角色 | 人选 | 职责 |
|------|------|------|
| D | 渠道负责人 | 测算返点方案、推进会所激励落地、8/10 前提交 |
| A | 老板 | 批预算额度（预算类事项） |
| C | 财务（预算测算）、培训组（话术配合）、4 位经理（一线反馈） | 提供数据、话术、会所实际反馈 |
| I | 全体销售 | 知悉激励规则并执行 |

**示例 2：新人 90 天带教落地**

| 角色 | 人选 | 职责 |
|------|------|------|
| D | 培训组负责人 | 排带教计划、盯 90 天节点、8 月出话术卡库 |
| A | 运营中心负责人 | 批准计划、验收结果 |
| C | 招人组（提供新人名单）、产品岗（话术包内容） | 提供输入 |
| I | 4 位经理 | 知道每位新人的带教安排并配合陪访 |

### 8.6 五个常见错误（防呆清单）

1. **没有 D**：大家讨论完没人推进——最常见的病。没有 D 的事不上会。
2. **两个 A**：A 一多，争议必然升级到老板，等于没有 A。一事只能一个 A。
3. **A 不拍板**：给 A 设期限——到会必须拍板或明确"X 天内拍板"，逾期默认按 D 方案执行。
4. **C 太多**：C 只提供输入，不当决策。C 一多，会就越开越大、越开越慢。
5. **I 变 C**：只需要知道结果的人被拉进讨论，信息泄露和会议膨胀一起发生。I 只在决策后收通知。

### 8.7 落地节奏

第一个跨部门决策（返点预算）就用 DACI：会前填好表，会上只确认角色、过方案、A 拍板。一次真实使用，比十次培训都管用。
