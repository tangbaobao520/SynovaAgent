### 3.2 修复模式

**commit-msg-check.sh PYBIN 可用性探测（替换 L59-65）**:

```bash
PYBIN=""
for _c in python3 python py; do
  if command -v "$_c" >/dev/null 2>&1 && "$_c" -c "import sys" >/dev/null 2>&1; then
    PYBIN="$_c"
    break
  fi
done
if [ -z "$PYBIN" ]; then
  echo -e "${YELLOW}⚠ D328 一致性检查跳过: python 不可用或损坏（fail-open 显式提示，不静默）${RESET}"
fi
```

**GENUINE 三态（替换 L70）**:

```bash
GENUINE=$(echo "$STAGED_LIST" | "$PYBIN" -c "..." 2>/dev/null)
GENUINE_RC=$?
if [ "$GENUINE_RC" != 0 ]; then
  echo -e "${YELLOW}⚠ D328 一致性检查 degraded: GENUINE 判定执行失败 (rc=$GENUINE_RC)，本次跳过${RESET}"
else
  if [ "$GENUINE" = "1" ]; then
    # ... 原有 CLAIM_DID 比较不变
  fi
fi
```

> 三态语义：输出 `0` = 无真实认领（跳过，G12 兜底）；输出 `1` = 有真实认领（比较 D#）；**执行失败 rc≠0 = degraded（显式提示，绝不静默）**——回应 L4 收割 #1 的最小实现。
