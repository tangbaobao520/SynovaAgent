# SynovaAgent JTBD 穷举 — 场景 2：消费品·中大（100-499人）

> 场景画像：多品类/多品牌消费品企业，年收入3-15亿，职能制+事业部制混合，BI系统建设中但数据口径不统一。
> 核心信息环境：BI看板+财务月报+部门周报+老板直觉，四套信息经常不一致。

| 数据可得性 | 需GA手工采集 — 销售预测在Excel，备货方案在ERP，资金计划在财务系统——三者无自动联动 |
| 协同路径 | 销售提预测 → 供应链算备货和资金需求 → 财务确认资金可行性 → 如不可行则回退调整预测或备货方案 → 三方达成一致 |

### S2-JTBD-C04（对应 S2-JTBD-012 / S2-JTBD-015）
**"我需要决策新品的上市路线图——从研发立项到全渠道铺货的全流程时间线和资源分配，但我不确定研发周期、供应链备货能力、品牌推广窗口和渠道铺货节奏是否能对齐。"**

| 字段 | 值 |
|------|-----|
| JTBD类型 | 干预型 (DESIGN) |
| 执行角色 | 产品总监/研发总监 + 供应链总监 + 品牌总监 + 渠道总监（线下）+ 销售VP |
| 频率 | 每季度 |
| 重要性 | 5 |
| 中层可控性 | 2 — 可调整 |
| 可行动性 | 建立新品上市联合时间线：研发给出配方/设计冻结日期；供应链给出首批量产完成日期；品牌给出推广内容和媒介锁定日期；渠道给出铺货完成日期；四方对齐后反推各环节Deadline并每周联合review进度 |
| 数据可得性 | 需GA手工采集 — 各环节进度分散在项目管理系统（飞书/钉钉/Teambition）和ERP中 |
| 协同路径 | 联合时间线→各角色承诺Deadline→周度联合review→偏差告警→CEO升级 |

### S2-JTBD-C05（对应 S2-JTBD-013 / S2-JTBD-030）
**"我需要判断是否终止一个持续亏损的子品牌/新产品线，但我不确定终止决策对渠道关系、品牌矩阵完整性、团队士气和财务报表的多维度影响。"**

| 字段 | 值 |
|------|-----|
| JTBD类型 | 干预型 (EVALUATE) |
| 执行角色 | 产品总监/研发总监 + 财务总监（CFO）+ 品牌总监 + 渠道总监（线下）+ 销售VP |
| 频率 | 每季度 |
| 重要性 | 5 |
| 中层可控性 | 1 — 可影响（关停决策通常需CEO最终批准，中层提供多维度评估） |
| 可行动性 | 构建关停影响五维评估表：财务（直接亏损+已投入沉没成本+关停一次性费用）、渠道（依赖该品牌的经销商比例和切换成本）、品牌（矩阵完整性和消费者认知影响）、团队（人员安置成本）、战略（未来赛道卡位价值）；综合评分低于阈值→提交关停建议给CEO |
| 数据可得性 | 自动可得 — 财务数据、渠道数据、人员数据在各自系统中可得；战略价值评估需主观判断 |
| 协同路径 | 财务提供损益数据 → 产品提供市场竞争力评估 → 品牌提供矩阵影响 → 渠道提供切换方案 → 汇总给CEO |

### 二、按 JTBD 类型分布

| JTBD类型 | 数量 | 占比 | 说明 |
|----------|------|------|------|
| 干预型 | 33 | 62.3% | ALLOCATE(13) + EVALUATE(8) + CONTROL(4) + DESIGN(8)。中层核心工作是做决策、分配资源、设计方案 |
| 诊断型 | 15 | 28.3% | DIAGNOSE(15)。中层大量的是找出为什么——渠道ROI暴跌、复购下滑、库存恶化、人效走低 |
| 预测型 | 5 | 9.4% | PREDICT(5)。备货预测、GMV预测、现金流预测、经销商压货预测 |

**解读：** 干预型占主导符合消费品中大企业的中层画像——他们不是看数据的人，是做决策的人。诊断型和预测型服务于干预型。这个比例对哨兵设计有直接指导：compute函数应优先服务资源分配(ALLOCATE)和方案评估(EVALUATE)这两类决策。

| 角色 | JTBD数 | 占独立JTBD% | 核心决策类型 |
|------|--------|------------|-------------|

| 供应链总监 | 6 | 14.0% | DIAGNOSE + ALLOCATE + PREDICT |
| 财务总监（CFO） | 6 | 14.0% | DIAGNOSE + ALLOCATE + PREDICT |
| 品牌总监 | 5 | 11.6% | ALLOCATE + EVALUATE + DIAGNOSE |
| 产品总监/研发总监 | 5 | 11.6% | ALLOCATE + DIAGNOSE + EVALUATE |
| 渠道总监（线下） | 6 | 14.0% | DIAGNOSE + PREDICT + ALLOCATE |
| HRD | 5 | 11.6% | DIAGNOSE + DESIGN + EVALUATE |
| 数据/BI负责人 | 4 | 9.3% | ALLOCATE + DIAGNOSE + EVALUATE |

**解读：** JTBD分布相对均衡——核心业务角色（销售/供应链/财务/渠道）各14%，品牌/产品/私域各约12%，BI略少（因为BI是赋能角色而非业务决策者）。SynovaAgent需要同时服务多角色，不能偏向某单一职能。

### 四、按中层可控性分布

| 可控性等级 | 数量 | 占比 | 典型JTBD |
|-----------|------|------|---------|
| 3 — 可直接决策 | 18 | 34.0% | 渠道预算分配、清仓SKU选择、私域策略设计、BI看板优先级、供应商TCO选择 |
| 2 — 可调整 | 32 | 60.4% | 大促策略、库存优化、ROI诊断、账期调整、薪酬设计、组织架构 |
| 1 — 可影响 | 3 | 6.3% | 组织架构调整、CDP投入决策、子品牌关停决策 |

****解读：** 60.4%的JTBD是可以调整但不能独断的——中层有决策空间但需要与上级或其他部门博弈。这对SynovaAgent的产品设计有直接含义：系统需要提供说服弹药——不仅告诉中层情况是什么，还要提供带数据去跟老板/其他部门谈判的证据。

### 五、按重要性分布

| 重要性 | 数量 | 占比 |
|--------|------|------|
| 5（错了会导致重大损失） | 21 | 39.6% |
| 4 | 26 | 49.1% |
| 3 | 6 | 11.3% |
| 2 | 0 | 0% |
| 1 | 0 | 0% |

**解读：** 没有重要性低于3的JTBD。中层面临的所有决策都属于错了会有明显损失的区间。这验证了中层是高风险决策者的假设——他们不是在优化，是在避免翻车。

### 六、按数据可得性分布

| 数据可得性 | 数量 | 占比 |
|-----------|------|------|
| 自动可得 | 16 | 33.3% |
| 需GA手工采集 | 32 | 66.7% |

**解读：** 即使消费品中大企业已有ERP+BI+SCRM等系统，仍有2/3的JTBD所需信息无法自动获取。数据散落在多个系统中、口径不一致、系统间无自动联动。这意味着SynovaAgent在自动可得的16个JTBD上可以做到全自动哨兵，而其余32个JTBD需要设计半自动机制——系统给出框架和部分数据，中层补充人工判断。

### 七、跨角色协同JTBD汇总

| 协同JTBD | 涉及角色数 | 核心张力 |
|----------|-----------|---------|
| C01 营销资源跨部门分配 | 4 | 销售 vs 品牌 vs 渠道 vs 财务的预算博弈 |
| C02 全渠道价格管控 | 3 | 线上冲GMV vs 线下保利润 |
| C03 大促备货与现金流平衡 | 3 | 销售报大数 vs 供应链怕积压 vs 财务怕断流 |
| C04 新品上市路线图 | 5 | 全链路协同——任何一环延迟全线受影响 |
| C05 子品牌/新产品线关停 | 5 | 财务要求止损 vs 品牌要求保矩阵 vs 渠道怕丢客户 |

**解读：** 5个跨角色JTBD中，3个涉及现金流/预算分配的博弈。消费品中大企业中层最大的摩擦面是钱怎么分和价格怎么管。SynovaAgent的协同JTBD哨兵需要特别设计——不仅要给出答案，还要给出各方都能接受的客观分配逻辑。

### 八、行业特征观察

1. **渠道冲突是第一大痛点。** JTBD-006（线上价格伤线下）、JTBD-023（窜货溯源）和C02（全渠道价格管控）三箭齐发。线上线下互搏是这个规模消费品企业的普遍困境。
2. **营销归因是最大数据黑洞。** JTBD-001（渠道边际ROI）、JTBD-007（品牌vs效果投放）、JTBD-004（抖音ROI暴跌诊断）——三个JTBD指向同一个问题：钱花在哪了，什么真正有效？现有BI系统无法回答。
3. **库存周转是供应链第一高频JTBD。** JTBD-018（周转恶化诊断）、JTBD-019（清仓决策）、JTBD-021（断货风险）——库存管理已从要什么数据进化到怎么用数据做决策，但决策框架缺失。
4. **人效是新晋核心关注点。** JTBD-035（人效诊断）、JTBD-037（离职根因）——200到350人扩张期的典型焦虑。这不是消费品特有，但消费品行业人效测量方法不成熟。
5. **关停线是缺失的管理工具。** JTBD-003（关停电商店铺）、JTBD-013（产品退市）、C05（子品牌关停）——消费品中大企业缺乏什么时候该停的客观标准，导致沉没成本持续膨胀。
