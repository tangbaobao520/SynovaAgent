## 元方法论：ALLOCATE 的认知特征

| 维度 | ALLOCATE |
|------|----------|
| 认知姿态 | 资源分配决策——有限资源在多个竞争选项间的配置 |
| 核心信息需求 | 各选项的边际收益/成本 + 资源约束 + 机会成本 + 外部竞争参照 |
| 时间取向 | 未来导向（分配后的预期结果），基准数据来自历史 |
| 假设依赖 | 边际收益/成本的估算准确性、竞争环境的稳定性 |
| 错误代价 | 二类：浪费资源在低ROI选项（机会成本）+ 错配导致流失或产能瓶颈 |

ALLOCATE 是所有决策动词中信息需求最"量化"的一类——需要可比较的 ROI 评估、边际分析、以及"如果不投这里还能投哪里"的机会成本意识。

# 一、ALLOCATE × Customer（8个）

> ALLOCATE × Customer = 对客户群体或个体客户的资源/政策分配决策。核心张力：单客户价值 vs 整体资源效率。

### U-JTBD-0010 | ALLOCATE | Customer | BUYS_FROM,FLOWS_TO
> 决定是否对中小客户全面推行纯自助Onboarding以释放CSM资源给大客户，需权衡自助激活率下降风险和CSM成本节省。

因果信息需求：

1. ND-010-A {需要[Customer][FLOWS_TO.激活率][过去24个月][按客户分层(大/中/小)×Onboarding模式分组聚合P50/P25][vs 混合模式基线68%]}
   [前提假设: 自助Onboarding的激活率下降幅度 > CSM成本节省 ÷ 客户LTV时，决策为负]
   [数据源覆盖度: 自动 — 产品Onboarding漏斗数据 + CSM工时系统 + 客户分层标签 — 涉及3个数据源]
   [时间约束: 月(<4h) — 历史数据聚合，A/B测试需4-8周]

2. ND-010-B {需要[Customer][PRODUCES.客户LTV][过去24个月][按规模分层聚合中位数][vs 各层CSM人均服务成本]}
   [前提假设: 中小客户LTV分布可用历史数据外推，且自助化不显著改变LTV]
   [数据源覆盖度: 自动 — 订阅/交易系统 + 续费率数据 — 涉及2个数据源]
   [时间约束: 月(<4h)]

3. ND-010-C {需要[Resource][CONSUMES.CSM工时分配][过去6个月][按客户分层×活动类型聚合∑工时][vs 客户分层营收占比]}
   [前提假设: CSM工时记录完整，活动分类粒度足以区分高价值服务和低价值重复操作]
   [数据源覆盖度: 企业补充 — CSM工时日志 + 工单系统 — 涉及2个数据源]
   [时间约束: 月(<4h)]

4. ND-010-D {需要[Customer][BUYS_FROM.流失率与激活率关联][过去36个月][按分层回归分析][vs 阈值：激活率每降1%→流失率升?%]}
   [前提假设: 激活率与留存率存在可量化的因果关系，且不受同期市场变化混淆]
   [数据源覆盖度: 自动 — 产品分析平台 + CRM续约数据 — 涉及2个数据源]
   [时间约束: 月(<4h) — 需要长历史窗口建立稳定回归]

中层可控性：2 — 可控制Onboarding模式切换，但客户激活行为不可控
可行动性映射：输出"三层客户 × Onboarding模式"的Cost-LTV矩阵，标注损益平衡的激活率阈值
主动触发器：当中小客户CSM人均服务数 > 80 或 CSM成本占比 > 该层营收贡献的25%时触发重评估
决策反馈闭环：追踪"切换后6个月内中小客户激活率、续费率、CSM服务大客户深度评分"

### U-JTBD-0011 | ALLOCATE | Customer | COMPETES_WITH
> 决定新产品的"低价冲量→后期提价"螺旋策略，需判断竞品价格天花板和用户价格敏感度。

   [前提假设: 竞品价格可通过抓取+分销商数据获得，且竞品定价逻辑可用成本加成或价值定价推断]
   [数据源覆盖度: GA手工 — 电商平台价格抓取 + 分销商报价 + 行业价格监测工具 — 涉及3个数据源]
   [时间约束: 周(<1h)]

2. ND-011-B {需要[Customer][BUYS_FROM.价格弹性系数][过去24个月][按类目×价格区间回归计算][vs 行业品类弹性基准]}
   [前提假设: 历史价格变动可归因到需求变化，且排除季节性/促销噪声]
   [数据源覆盖度: 自动 — 交易记录 + 定价变更日志 — 涉及2个数据源]
   [时间约束: 月(<4h) — 回归分析 + 外部基准校验]

3. ND-011-C {需要[Customer][COMPETES_WITH.品牌转换成本][过去12个月][按客群分层调查聚合][vs 行业转换成本中位数]}
   [前提假设: 低价吸引的客户在提价后的留存率可用"转换成本×满意度"模型预测]
   [数据源覆盖度: 企业补充 — 用户调研 + 竞品切换行为日志 — 涉及2个数据源]
   [时间约束: 季(<8h) — 需要调研周期]

4. ND-011-D {需要[Product][PRODUCES.毛利率模拟][模拟期12-24个月][情景分析(乐观/基准/悲观)][vs 公司目标毛利率]}
   [前提假设: 生产成本曲线在量增阶段可预测（规模效应斜率已知）]
   [数据源覆盖度: 企业补充 — 成本核算系统 + 采购价格预测 — 涉及2个数据源]
   [时间约束: 月(<4h)]

中层可控性：2 — 可设定价格，但市场反应和竞品反击不可控
可行动性映射：输出"价格-销量-利润"三情景曲线，标注竞品可能反击的价格点
主动触发器：当竞品价格变动 > 10% 或 TOP3 竞品中任一家推出新品定价时触发重评估
决策反馈闭环：追踪"提价后3个月内销量、市场份额、竞品价格响应"

### U-JTBD-0012 | ALLOCATE | Customer | DEPENDS_ON,FLOWS_TO
> 决定是否收紧大客户账期（缩短或要求预付款），需评估累计利润率、坏账风险和关系重要性。

因果信息需求：

1. ND-012-A {需要[Customer][PRODUCES.累计利润率][过去36个月][按客户聚合∑(营收 - 全分摊成本) / ∑营收][vs 公司平均客户利润率]}
   [前提假设: 全分摊成本可按客户级别准确分配（直接成本+按驱动因素分摊的间接成本）]
   [数据源覆盖度: 企业补充 — ERP + 成本核算系统 + 物流/仓储分客户数据 — 涉及3个数据源]
   [时间约束: 月(<4h)]

2. ND-012-B {需要[Customer][FLOWS_TO.账期逾期历史][过去24个月][按客户聚合逾期次数/逾期天数P90][vs 行业同规模客户逾期率基准]}
   [前提假设: 历史逾期行为可预测未来违约概率，且客户财务状况未发生结构性变化]
   [数据源覆盖度: 自动 — 应收账款系统 + 银行回款记录 — 涉及2个数据源]
   [时间约束: 周(<1h)]

3. ND-012-C {需要[Customer][DEPENDS_ON.关系重要性评分][当前][多维评分(独占供应商占比/替换难度/转介绍价值/战略协同)][标准化为0-1重要性指数]}
   [前提假设: "关系重要性"可分解为可量化的子维度，且权重由管理层共识确定]
   [数据源覆盖度: 企业补充 — CRM客户关系记录 + 销售主观评分 + 合同分析 — 涉及3个数据源]
   [时间约束: 月(<4h)]

4. ND-012-D {需要[Market][DEPENDS_ON.行业信用风险][当前][按行业聚合信用评级分布][vs 该客户自身信用变化趋势]}
   [前提假设: 行业信用风险与该客户个体风险正相关，可作为外部锚定]
   [数据源覆盖度: GA手工 — 第三方征信报告 + 行业信用数据 — 涉及2个数据源]
   [时间约束: 季(<8h)]

中层可控性：3 — 可直接调整账期政策，且有合同约束力
可行动性映射：输出客户"利润-风险-重要性"三维矩阵，标注账期调整建议（收紧/维持/放宽）
主动触发器：当某大客户连续2次逾期 > 30天 或 行业信用评级下调时触发重评估
决策反馈闭环：追踪"账期调整后6个月内回款速度变化、客户流失、客户投诉"

### U-JTBD-0013 | ALLOCATE | Customer | FLOWS_TO
> 决定是否给大客户A降价5%保订单，需评估真实利润贡献、降价后能否覆盖固定成本、丢失后果。

因果信息需求：

   [数据源覆盖度: 企业补充 — 成本核算系统 + ERP + 物流成本分客户 — 涉及3个数据源]
   [时间约束: 周(<1h) — 单一客户计算]

2. ND-013-B {需要[Product][PRODUCES.边际贡献率][过去12个月][按该客户订单聚合(收入 - 变动成本) / 收入][vs 盈亏平衡点]}

   [数据源覆盖度: 自动 — ERP成本模块 + 生产BOM — 涉及2个数据源]
   [时间约束: 周(<1h)]

3. ND-013-C {需要[Customer][FLOWS_TO.丢失客户A的连锁影响][模拟][情景分析](产能利用率下降→分摊升高 / 供应商折扣取消 / 员工闲置 / 市场声誉)]

   [时间约束: 月(<4h)]

4. ND-013-D {需要[Market][COMPETES_WITH.竞品报价水平][当前][该客户同类订单的竞品报价范围][vs 自身降价后价格]}
   [前提假设: 可通过销售反馈或客户透露获取竞品报价范围]
   [数据源覆盖度: GA手工 — 销售CRM记录 + 客户沟通记录 — 涉及2个数据源]
   [时间约束: 实时(<30m) — 紧急决策]

中层可控性：3 — 可直接决定降价幅度
可行动性映射：输出降价5%的完整损益分析 + 不降价的最坏情景 + 谈判替代方案（如：保持价格但增加服务）
主动触发器：当TOP5客户中任一个提出降价要求或表示考虑竞品时触发
决策反馈闭环：追踪"决策后12个月内该客户订单量、利润率变化、竞品是否跟进"
