---

## 元方法论：EVALUATE 决策动词的认知特征

| 维度 | EVALUATE |
|------|----------|
| 认知姿态 | 多维度比较与权重判断 - 在多个选项或方案中选出最优 |
| 核心信息需求 | 可比选项的多维度评分 + 权重向量 + 灵敏度分析 + 竞品/供应商基准对比 |
| 时间取向 | 现状扫描 + 近期历史 + 预测期（决策后的影响范围） |
| 假设依赖 | 维度间可比较、权重可获取、评分可量化 |
| 错误代价 | 选错选项（机会成本）、延迟决策（窗口关闭）、评估偏差（忽略关键维度） |
| 典型边参数 | COMPETES_WITH, BUYS_FROM, PRODUCES, DEPENDS_ON |
| 输出特征 | 可比较的选项排名 - 必须产出排序、评分或二选一结论 |

### U-JTBD-0119 | EVALUATE | Customer | BUYS_FROM
> 我需要判断这次跨界联名合作要不要签续约，但我不确定首期合作带来的增量销售中有多少是一次性尝鲜、有多少转化成了品牌忠实用户。
> 等价变体 (3个): S2-JTBD-010, S5-JTBD-019, S5-JTBD-023
> 来源场景: S2, S5

因果信息需求：
1. ND-0119-A {[Customer][BUYS_FROM.联名增量销售分解][合作期内][分解为(一次尝鲜/复购转化/品牌新客/联名独有客)][vs 同类联名行业基准]}
   [前提假设: 联名销售增量可追踪到个体消费者级别，且可区分首次购买和后续复购]
   [数据源覆盖度: 企业补充 - CRM消费记录 + 订单来源标签 + 品牌交叉分析 - 涉及3个数据源]
   [时间约束: 月(<4h) - 联名期结束后复盘分析]

2. ND-0119-B {[Customer][SIGNAL_TRANSMITS.联名期间品牌健康度变化][合作期前后各3个月][对比(品牌搜索量/社交媒体声量/NPS)][vs 合作前基线]}
   [前提假设: 品牌健康度短期变化可归因于联名合作，排除同期其他营销活动]
   [数据源覆盖度: 企业补充 - 社交媒体监听 + 搜索数据 + NPS调研 - 涉及3个数据源]
   [时间约束: 月(<4h)]

3. ND-0119-C {[Customer][METRIC_BINDS.联名续约预期ROI][预测期12个月][蒙特卡洛模拟(乐观/基准/悲观)][vs 首次合作实际ROI]}
   [前提假设: 首次合作ROI可作为基线，但需考虑边际效应递减系数]
   [数据源覆盖度: 企业补充 - 首次合作数据 + 续约条款模拟 + 行业联名衰减系数 - 涉及3个数据源]
   [时间约束: 周(<1h) - 基于已有数据的模拟计算]

中层可控性：0
可行动性映射：输出续约决策矩阵(尝鲜占比/复购转化/品牌提升 -> 续约评分 -> GO/NO GO)
主动触发器：当联名ROI低于同类联名行业P25分位时触发告警
决策反馈闭环：追踪续约后12个月内复购转化率与预测值偏差
