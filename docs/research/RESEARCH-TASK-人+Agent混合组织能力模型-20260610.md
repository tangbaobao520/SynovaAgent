# 研究课题：人+Agent 混合组织的组织能力模型

> **发起日期**：2026-06-10  
> **发起方**：SynovaAgent 产品定义书 §3.1  
> **研究产出**：文献综述 + 理论框架 + 工程路线图  
> **目标读者**：Synova 创始人（产品方向裁定）+ 工程团队（落地参考）  

---

## 一、课题背景

### 1.1 理论缺口

杨国安教授提出：**企业成功（持续成长）= 战略 × 组织能力**。

组织能力的经典理论是杨三角：**员工能力 × 员工思维 × 员工治理**。但这个理论的前提是——组织由纯人类构成。

Synova 面对的现实是：**Agent 已经进入组织**。企业里有人在用 ChatGPT、有团队在用 Claude Code 写代码、有部门在用 AI 做客服。Agent 不是"另一个工具"——它会主动做决策、协作、传递信息。协作模式变了，决策流程变了，知识流转变了。

**核心问题：组织能力理论需要为"人+Agent 混合组织"重新发明。**

### 1.2 产品背景

Synova 是一个组织诊断 Agent，驻扎企业、7×24 观测、主动诊断。我们诊断的对象是**人+Agent 混合组织**——但我们目前用的是纯人类组织的诊断框架（杨三角 + McKinsey 7S + 六缝隙）。

产品定义书 §3.1 写到："我们需要在杨三角的基础上发展'人+Agent 组织能力模型'"——但这句是旗帜，不是结论。

### 1.3 为什么现在必须研究

- Synova 即将进入 Phase 0 演示（Week 1），诊断框架的理论基础不能是空白
- 如果不先理解"人+Agent 组织的健康标准是什么"，诊断就是在用旧尺子量新东西
- 本课题不要求"给出最终答案"——要求给出**当前世界最前沿的认知 + Synova 可以验证的假设**

## 二、研究目标

### 2.1 核心问题（必须回答）

| # | 问题 | 为什么重要 |
|---|------|-----------|
| Q1 | Anthropic、OpenAI、Google DeepMind 等前沿公司如何理解"AI Agent 进入组织后的影响"？他们公开了哪些研究、工程实践、部署经验？ | 认知基线——最前沿的人怎么想 |
| Q2 | 学术界对"人+AI 协作"和"组织中的 AI Agent"有哪些最新研究（2023-2026）？核心发现是什么？ | 学术证据——哪些结论有数据支撑 |
| Q3 | 现有的组织理论（杨三角、McKinsey 7S、Galbraith 组织设计、Mintzberg 组织结构）中，哪些假设在"人+Agent 混合组织"下不再成立？ | 理论诊断——旧框架哪里坏了 |
| Q4 | 有没有已经提出的"混合组织"或"AI 增强组织"的替代模型？它们的长处和短板分别是什么？ | 理论替代——别人已经做了什么 |
| Q5 | 以当前的研究证据，Synova 的"人+Agent 组织能力模型"的**工作假设**（working hypothesis）应该是什么？ | 工程落地——我们能开始验证什么 |

### 2.2 输出要求

1. **文献综述**（≤ 3000 字）：按主题分类，每篇论文：核心发现 + 方法论 + 与 Synova 的相关性
2. **理论框架草案**：基于研究证据，提出 Synova 的"人+Agent 组织能力模型"初版——哪几个维度？每个维度的定义？为什么选这些维度？
3. **工程路线图**：这个模型怎么在 Synova 的诊断引擎中落地？哪些维度可以通过现有数据源测量？哪些是远期目标？
4. **未解问题清单**：诚实标注"当前研究无法回答的问题"——这是 Synova 自己的实验要解决的问题

#### B. 学术论文（至少阅读 20 篇原文，不能只读摘要）

**搜索策略**：
- 关键词：`"human-AI collaboration"`, `"AI agent" organization`, `"multi-agent systems" organizational design`, `"LLM" workplace`, `"generative AI" productivity`, `"AI teammate"`, `"human-in-the-loop" organizational`, `"AI augmented" decision making`, `"algorithmic management"`
- 数据库：arXiv, ACM Digital Library, Google Scholar, Semantic Scholar
- 时间范围：2023-2026（重点 2025-2026）
- 筛选标准：有实证数据（实验/田野调查/大规模部署数据）优先于纯理论论文

**建议阅读的论文方向**（非穷举，由研究 Agent 自行扩展）：

1. **AI 对生产力的因果效应** — Microsoft Copilot RCT、GitHub Copilot 研究
2. **AI Agent 作为组织成员** — 人类如何与 AI Agent 建立信任、协作模式
3. **多 Agent 系统的组织设计** — 多 Agent 之间的协调、角色分配、冲突解决

6. **组织网络分析** — 用数据衡量组织健康的实证方法
7. **认知负荷与 AI** — AI 如何改变人类的认知负荷、决策质量
8. **AI 与组织学习** — AI 如何影响组织的知识积累和能力进化

```
阶段 1：并行搜索（4-6 个 Agent 同时进行）
  ├─ Agent A: Anthropic + OpenAI 公开研究深挖
  ├─ Agent B: 学术论文搜索 + 筛选（arXiv, ACM, Google Scholar）
  ├─ Agent C: 组织理论经典文献 + AI 时代的批评

阶段 4：综合与起草
  ├─ 文献综述
  ├─ 理论框架草案
  ├─ 工程路线图
  └─ 未解问题清单
```
