一、目录分类

目录用途文档类型
docs/research/活跃文档——正在使用或持续更新的文档路线图、开发计划、编码指南
docs/archive-research/归档研究——已完成的研究报告，仅供追溯所有历史研究 HTML 报告
docs/audit/审计报告——代码审计和安全审计审计发现、修复计划

二、命名规范

2.1 通用规则

规则项要求
文件名语言英文大写 + 连字符，不使用中文文件名
日期格式YYYYMMDD，可选后缀，置于文件名末尾
文件扩展名.html（推荐，可读性强）或 .md（纯文本场景）
字符集仅允许 A-Z 0-9 -

2.2 命名格式

[领域前缀]-[内容主题]-[YYYYMMDD].html

领域前缀（大写）：
  L1-   → 交互层
  L2-   → 编排层
  L3-   → 分析层
  L4-   → 本体层
  L5-   → 数据层
  SYNOVA-  → 全局/跨层

内容主题（英文，连字符分隔）：
  INTERACTION-DEEP-DIVE    → 交互层深度研究
  ORCHESTRATION-RE-AUDIT   → 编排层再审计
  DATA-LAYER-DEEP-DIVE     → 数据层深度研究
  PROVIDER-EXTENSION       → Provider 扩展
  STRATEGIC-ROADMAP        → 战略路线图
  USER-EXPERIENCE-RESEARCH → 用户体验研究
  HERMES-COMPARISON        → Hermes 对比

日期（可选，YYYYMMDD）：
  用于标识版本，大版本更新时追加

示例：
  L1-INTERACTION-DEEP-DIVE.html                    ← 无日期（最新版）
  L5-DATA-LAYER-COMPREHENSIVE-RESEARCH.html        ← 无日期
  CODE-AUDIT-COMPREHENSIVE-20260605.html           ← 带日期
  DEPLOYMENT-DELIVERY-OPTIONS.html                 ← 无日期

2.3 文档内元数据

每个 HTML 文档的 <title> 标签必须包含中英文对照名称：

<title>L1 交互层深度研究报告 — SynovaAgent</title>
<!--    中文名称          英文名称    -->

实际渲染：
L1 交互层深度研究报告 — SynovaAgent
↑ 中文                 ↑ 项目名

如果文档需要被检索，在头部加 meta：
<meta name="description" content="L1 Interaction Layer Deep Dive — SynovaAgent 组织智能诊断系统">

三、文档生命周期

阶段目录说明
起草中（Draft）docs/research/正在编写的文档
活跃（Active）docs/research/完成并正在使用，可能持续更新
归档（Archived）docs/archive-research/已完成的研究，不再更新，仅供追溯
废弃（Deprecated）docs/archive-research/已被新文档取代，保留历史记录

归档时机：

  • 研究报告对应的研究阶段结束后
  • 新文档完全取代旧文档后
  • 文档内容超过 6 个月未更新且无引用后

四、INDEX.md 维护规则

docs/INDEX.md 是所有文档的入口索引。每次新增或归档文档时同步更新。

索引格式：
- [文档名称（中文 — English）](path/to/file.html) — 一句话说明

示例：
- [L1 交互层深度研究报告 — L1 Interaction Deep Dive](research/L1-INTERACTION-DEEP-DIVE.html) — 图可视化/SSE Bug/多渠道
- [战略迭代路线 — Strategic Roadmap](research/STRATEGIC-ROADMAP.html) — 方向决策与迭代计划

活跃文档放在前面，归档文档单独一节。
