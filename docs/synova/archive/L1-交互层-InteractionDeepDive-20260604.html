SynovaAgent 组织智能诊断系统 · 2026-06-04 · 前端架构与用户体验

⚠️ 核心结论：L1 交互层成熟度 3/10 — SSE 流式解析被一个字符 Bug 彻底破坏

src/routes/chat.ts:183 将 buffer.split('\n') 写成了 buffer.split('\\n')（双反斜杠字面量而非换行符），导致前端 SSE 解析功能完全不可用。用户发起诊断后永远看不到任何事件推送。这是所有 L1 问题中最紧急的 P0 错误。

除此之外，L1 只有基本的内联 HTML 对话界面和 neo-blessed TUI，缺少图可视化、多渠道适配、离线能力、国际化等核心能力。

2. 最关键 Bug 详解

🚨 routes/chat.ts:183 — SSE 流式解析彻底失效

// 当前代码（有 Bug）:
const lines = buffer.split('\\n');  // 按字面字符串 "\n" 分割

// 应该:
const lines = buffer.split('\n');   // 按换行符分割

影响：前端的 SSE 事件解析循环永远找不到换行符，整个 while(true) 循环会一直累积 buffer 直到浏览器主动中断连接（通常 2-5 分钟后）。用户看到的唯一结果是"诊断已启动，等待结果..." → 再无下文。

修复：只需将双反斜杠改为单反斜杠。30 秒修复。

3. 图可视化方案深度选型

3.1 需求分析

Synova 的组织本体图（SOG）对可视化有独特需求：

  • 10 万+ 节点和边：200 人团队 × 14 种节点类型 × 平均每人 50+ 关系
  • 复合节点层级：Team 包含 Person，Person 包含 Role
  • 路径高亮：诊断发现从 A→B→C 的因果链时需要可视化路径
  • 时间轴回放：SOG 双时序特性，可查看组织图在任意时间点的状态
  • 增量更新：诊断不断产生新节点和边，需要增量渲染而非全量重绘

3.3 推荐方案

方案：Cytoscape.js (主) + WebGL (性能关键路径)
  • 常规视图（<10K 节点）：Cytoscape.js Canvas 渲染，利用其丰富的布局算法和事件系统
  • 大型视图（10K-100K）：抽象为簇（community）级别显示，展开时局部加载子节点
  • 时间轴动画：Cytoscape.js 的 animate 选项 + 自定义定时器
  • 路径高亮：利用 Cytoscape.js 的 path 样式和 dijkstra 算法
  • 增删改：Cytoscape.js 的增量 API（add()/remove()/style()）原生支持

若未来证明 Cytoscape.js 无法满足 100K+ 性能需求，可降级为 Ogma（商业许可） 或自研 WebGL 渲染器。

4.3 白板模式

白板模式允许用户自由布局和组织发现：

  • 从对话中拖拽关键发现到白板
  • 在白板上连接发现形成推理链
  • 白板可保存为"诊断视图"供团队共享
  • 技术方案：React Flow / tldraw 作为白板引擎
