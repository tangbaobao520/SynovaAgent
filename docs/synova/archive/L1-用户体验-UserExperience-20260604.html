L1 交互层用户体验深度研究

将诊断能力转化为用户可感知、可理解、可信任的产品体验 · 2026-06-04

⚡ 关键发现：当前 L1 存在"两套 SSE 不兼容"和"零图可视化"问题

代码审查发现两个架构级 UX 问题：1) WebViewAdapter 写 event: type 格式但前端 HTML 只解析 data: 行，两种 SSE 格式不兼容，事件类型无法在前端做差异化展示；2) Cytoscape.js 未在任何地方使用，图可视化完全不存在——用户无法看到 SOG 本体图。修复这两个问题是 L1 体验改进的前提。

执行摘要：五大核心设计原则

  1. 渐进式价值呈现——用户不需要一次性理解所有能力。第一次打开看到"团队协作地图"，第二周看到"月度健康报告"，第三个月看到"趋势分析"。每步只给用户当前需要的。
  2. 叙事化诊断报告——不是"展示数据"，是"讲一个关于你组织的故事"。金字塔结构：结论先行 → 证据分层 → 建议落地。
  3. 进度即价值——六阶段诊断的等待时间是用户体验低谷。每阶段完成时推送一个"中间发现"，让等待本身产生价值感。
  4. 直白语言，零术语——"本体图"→"协作地图"，"实体解析"→"人员匹配"，"交叉验证"→"多源核对"。用户不需要理解技术就能感知价值。
  5. 异常即触发——不需要用户每天登录。当 SOG 监测到新增高风险节点或矛盾信号时，主动推送预警。系统找人，不是人找系统。

二、用户旅程与场景设计

2.1 完整用户旅程地图

📥 阶段 1：首次接触（Day 1）
😐 好奇 + 不确定 → 😊 惊喜（5 分钟内）
设计机会：5 分钟快速诊断 Demo
用户提供飞书 Token → 系统自动拉取通讯录 + 最近 7 天消息 → 生成"团队协作快照"。 不需要配置、不需要等待、"把你的 Token 给我，3 分钟后给你一份你团队的协作热力图"。 这是整条用户旅程中最关键的时刻——决定了用户是否会继续。
🔍 阶段 2：深度访谈（Day 1-3）
😌 被理解 → 🤔 思考
设计机会：共情式 AI 访谈
Phase 0 的提问要从"填问卷"变成"经验丰富的顾问在聊天"。AI 不直接问"你们的战略清晰度如何？"，而是问"如果让团队用一句话描述公司今年的目标，大家会说一样的话吗？"。 每条问题后显示进度：已覆盖 5/8 个诊断维度。参考目标梯度效应——用户看到进度时更愿意完成。
⏳ 阶段 3：诊断运行（Day 1-3）
😐 等待 → 逐渐感兴趣
设计机会：进度即价值
六阶段诊断需要 20-60 秒（LLM 调用为主）。当前 UX 低谷：用户看着"诊断中..."不知道发生了什么。 改进方案：每完成一个子阶段（如"战略专家完成分析"），立即推送一个中间发现卡片。 用户看到"你的销售团队跨部门沟通频率比研发低 40%"——这是有价值的信息，即使还在等待完整报告。
📊 阶段 4：报告交付（Day 3）
🤩 惊艳 → 信任建立
设计机会：金字塔叙事报告
第一层（10 秒）：一句话核心结论——"贵组织当前最大问题是跨部门协作效率，这是导致交付延期的根因。" 第二层（2 分钟）：三个关键发现，每个附带证据来源和置信度。 第三层（15 分钟）：完整报告含数据明细、专家分析、改进建议。 用户不需要从头读到尾——可以选择自己关心的维度深入。
🔄 阶段 5：持续使用（Month 1+）
📱 习惯 → 🛡️ 依赖
设计机会：习惯回路（Hook 模型）
触发：月度健康报告自动推送 + 异常事件实时预警。用户不需要主动打开系统，系统主动找用户。 行动：点击卡片 → 看到本月变化 → 一个向上/向下的趋势箭头，比任何复杂图表都有说服力。 奖励：看到团队改善（"跨部门协作分提升了 12%"）——这是用户持续使用的核心动力。 投入：用户在平台上留下的数据越多、标记的反馈越多，诊断越精准——迁移成本越高。

四、对话式交互与报告融合

4.1 当前 SSE 机制问题

两套不兼容的 SSE 格式

// WebViewAdapter（写 event: 格式，但前端不消费）
event: hypothesis
data: {"expertType":"strategy","confidence":0.85}

// diagnosis.ts（写 data: 格式，前端消费但无差异化展示）
data: {"type":"phase_completed","phase":1}

// 结果：前端无法区分"诊断进度"和"专家假设"和"异常预警"
// 所有事件都被渲染为同一格式的灰色系统消息

修复方案：统一为结构化 SSE 事件协议，让前端能根据事件类型做差异化渲染。

4.2 推荐的富媒体 SSE 事件类型

事件类型前端渲染优先级
phase_progress进度条 + 阶段标签P0
interim_finding诊断发现卡片（标题+摘要+置信度）P0
expert_hypothesis专家假设卡片（专家头像+假设+证据引用）P0
graph_update图增量更新（新节点/边动画）P0
contradiction_signal矛盾信号高亮卡片（红色警示+详情）P1
degradedDegradedBanner（模块名+影响说明）P1
complete完整报告入口 + 核心发现摘要P0
error错误提示+重试按钮+用户友好的解释P0
