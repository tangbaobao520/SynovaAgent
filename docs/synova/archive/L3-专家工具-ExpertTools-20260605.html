专家工具完整目录

按 6 大专家 + 跨层公共工具分类 · 每个工具标注参考来源路径 · 2026-06-05

📋 编制原则

基于 Synova 产品定位——多源数据进 SOG → 专家分析 → 诊断产出。

每个专家 Agent 的工具分为 3 层：

  • 公共工具：所有专家都需要的（查 SOG 图、读文档、搜行业信息）
  • 专业工具：该专家领域特有的分析能力
  • 框架工具：从 85 认知框架注入的分析透镜
