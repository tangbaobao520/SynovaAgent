安全架构概览（两阶段）

Phase 1（本月交付）：子进程隔离 + 凭证加密

核心原则：连接器在子进程中运行，不共享主进程内存。凭证加密存储，运行时解密后在子进程内使用，主进程不持有明文。

│  │  SQLite 表: connector_creds            │  │
│  │  + id | encrypted | created_at         │  │
│  │  + 加密密钥: deriveKey(MASTER_SECRET)  │  │

凭证管理实现

class CredentialVault {
  private key: Buffer;
  private db: Database;

  constructor(masterSecret: string, salt: string) {
    // 从主密码派生加密密钥
    this.key = scryptSync(masterSecret, salt, 32);
  }

  store(connectorId: string, creds: Record<string, string>): void {
    const iv = randomBytes(16);
    const cipher = createCipheriv('aes-256-gcm', this.key, iv);
    const encrypted = Buffer.concat([cipher.update(JSON.stringify(creds), 'utf8'), cipher.final()]);
    const tag = cipher.getAuthTag();
    this.db.prepare('INSERT OR REPLACE INTO connector_creds VALUES (?,?,?,?)')
      .run(connectorId, encrypted.toString('base64'), iv.toString('base64'), tag.toString('base64'));
  }

  decryptForChildProcess(connectorId: string): string {
    const row = this.db.prepare('SELECT * FROM connector_creds WHERE id=?').get(connectorId);

    // 主进程不保留明文
  }
}
