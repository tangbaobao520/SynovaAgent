附录 A：连接器接口统一方案

解决"3 套接口并存，零条数据通路"的问题

当前问题

三个互不兼容的接口同时存在，任何一个都不能把数据从外部系统送到 L4 本体层：

接口位置方法状态
DataConnector (旧)src/connectors/types.ts:53fetchMessages/fetchMembers/fetchEvents/mapToOntology2 存根实现
DataConnector (新)@synova/connector-registry/types.ts:64getTools/connect/disconnect/executeTool/healthCheck零实现
AirbyteOntologyAdapterengine-core airbyte-ontology-adapter.tsspec/check/discover/read2 mock 实现

推荐裁决：采用 AirbyteOntologyAdapter + 集成 ConnectorRegistry

统一方案：以 AirbyteOntologyAdapter 的 spec/check/discover/read 作为连接器接口标准，用现有的 ConnectorRegistry 管理生命周期。 
// 统一的连接器接口（废止其他两个）
interface SynovaConnector {
  // Airbyte 协议 4 方法（数据通道）
  spec(): ConnectorSpecification;
  check(config: Record<string, unknown>): ConnectionStatus;
  discover(config: Record<string, unknown>): Catalog;
  read(config: Record<string, unknown>, state?: Record<string, unknown>): AsyncIterable<OntologyEvent>;

  // 生命周期（复用 ConnectorRegistry）
  connect(config: Record<string, unknown>): Promise<void>;
  disconnect(): Promise<void>;
  healthCheck(): Promise<HealthStatus>;

  // 工具注册（接入 ToolRegistry）
  getTools(): ToolDefinition[];
  executeTool(name: string, params: unknown): Promise<unknown>;
}
