Round 5：模板进化引擎（EC-09）

🔄 EC-09：模板进化引擎 — 原理层/方案层分离

P2 参考: MASTER-REPORT §0.4.2 · 预计 4 小时

核心思想（MASTER-REPORT §0.4.2）：

  • 原理层（why） — "为什么排班不合理会导致人员流失"。时间无关（timeless），长期有效。
  • 方案层（how） — "具体怎么排班"。随技术/法规/市场变化可能过时。
  • 系统用真实诊断结果持续检验模板有效性：有效→置信度提升 / 失效→推送专家复核→标记历史参考。
interface Template {
  id: string;
  principle: string;     // 原理层（不变）
  solution: string;      // 方案层（可变）

  // 进化状态
  status: 'experimental' | 'active' | 'partial' | 'needs_review' | 'outdated';
  confidence: number;    // 0-1
  validationCount: number;
  confirmedCount: number;

  // 时间线
  createdBy: string;     // 贡献专家
  createdAt: string;
  lastValidatedAt: string;
  lastReviewRequestedAt?: string;
}

// 状态转换（只进不退）
experimental
  → confirmedCount >= 10 → active
  → confirmedCount / validationCount < 0.5 → needs_review
active
  → 30 天未验证 → needs_review
  → 50% 客户反馈根因不一致 → needs_review
needs_review
  → 专家确认有效 → active (reset timer)
  → 专家确认过时 → outdated (principle 保留为 "历史参考")
grep -n "status.*experimental\|status.*active\|needs_review\|outdated" src/expert-platform/*.ts → 状态机完整
