2.1 L2→L4 违规（主要问题）

conversation-engine.ts（L2）直接引用大量 L4 组件：

import { ReportGraphAdapter } from '../l4/report-graph-adapter';        // ❌ L2→L4
import { reflectOnTriples } from '../l4/triple-reflection';             // ❌ L2→L4
import { resolveEntitiesL3 } from '../l4/entity-resolver';              // ❌ L2→L4
import { generateCommunityReports } from '../l4/community-reports';      // ❌ L2→L4
import { findDiagnosticPaths, ... } from '../l4/diagnosis-graph-query'; // ❌ L2→L4
import { DecisionInput } from '../l4/decision-capture';                  // ❌ L2→L4

// 这些已在代码中标注 @deprecated EC-03
// 但未被移除——因为 L3 层还没有完全接管这些能力

根因：L3（ExpertAutonomyEngine）的 QueryAPI 太弱（只有 4 个方法），Message 能做的查询 L3 做不了，所以 L2 直接调用 L4。修复路径是增强 L3 的工具能力（query_sog_graph 等），让 L2 不再需要直接访问 L4。
