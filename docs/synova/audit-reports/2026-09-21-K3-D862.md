## 四、必核 4 — 无静默直连回退（强判别）

### 4.1 死端口代理 → 全链路 PROXY_UNREACHABLE / degraded

### 4.2 「直连可达也不许偷走」（强判别，本审计新增）

台账/自验的 P3 用「`upstream-*.test` 不可解析」论证，属**弱判别**（不可达目标无法区分「回退直连」与「未回退」）。本审计构造**强判别**：canary = `93.184.215.14:80`（本机实测直连 10524ms 超时，见下 control 组）。

```json
{
  "controlNoProxy": { "code": "UPSTREAM_TIMEOUT", "phase": "response", "ms": 75006 },
  "withLiveProxy":  { "status": 200, "ms": 8 },
  "proxyEntriesForCanary": [
    { "kind":"HTTP","method":"GET","absoluteUri":"http://93.184.215.14/canary-direct-probe",
      "hostHeader":"93.184.215.14","proxyAuthPresent":false }
  ]
}
```

- **对照组（不配代理）**：`UPSTREAM_TIMEOUT`（75s）→ 该目标**确实不直连可达**，判别有效
- **实验组（配活代理）**：**200 / 8ms** + 代理日志逐条记录该绝对 URI → 这个 200 **只可能**来自代理合成响应；若出口「因为直连可达就偷走」，得到的只会是 `UPSTREAM_TIMEOUT`
- **结论：配了代理就必须走代理，直连可达也不许绕过** ✅
