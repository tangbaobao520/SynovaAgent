7.2 pre-commit 质量工具缺陷

TOOL-01 MEDIUM as any 检测正则疑似 bug
scripts/pre-commit-check.sh:57 — grep -rn 'as any[];,)}>]'
字符类 [];,)}>] 匹配的是集合中的单个字符（如 as any;），而不是预期的 as any[] 模式。该正则实际上会匹配任何包含 as any 后跟 [];,)}>] 中任意字符的代码——虽然误报率高但对阻断目的来说是保守的（安全侧）。
TOOL-02 MEDIUM check-architecture.sh shell 计数 bug
scripts/check-architecture.sh:25,42
grep -c . 在空输入时输出 "0" 但不返回 exit 1 给 ||，导致 grep -c . || echo 0 在计数=0 时产生两行 "0\n0"。虽然不影响退出码但控制台有噪音。
