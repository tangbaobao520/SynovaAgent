执行摘要

Synova 是一个驻扎在企业内部的 AI 增长诊断系统。它 7x24 监测全量组织数据，主动发现增长卡点，8 位 AI 专家协同诊断根因，给出可落地的行动方案，并跟踪执行效果。最终决策由人做出。

解决了什么问题？

辛辛苦苦一年做到 5000 万营收，却因为一次错误的战略决策，利润全亏。创始人不是神，他们身边缺一个敢说真话、看得懂数据的人。

中小企业并不是没有咨询。他们花几万块上课，花几十万请中小咨询公司——但这些咨询只能聚焦某个领域（组织、营销、财务），没有一家能做全面诊断。方案能不能落地，全看企业自己。更致命的是，所有传统咨询都是基于过去和当下的时点做判断，顾问离场后，企业又回到"凭感觉"的状态。运行时监测和实时诊断，传统咨询做不到。

核心流程

Synova 的核心不是"人找系统做诊断"，而是 Agent 在后台持续运转、主动发现问题、主动汇报。

数据持续注入
飞书/钉钉/财务系统/CRM/文档。数据自动流入企业本地实例，不需要人工采集。
本体层自动关联
新客户、新员工、新收入自动生成 SOG 节点和关联边。组织数字孪生实时更新。
哨兵不间断扫描
7 维度 x 26 哨兵定时自动执行 compute()。信号聚合引擎交叉关联多个哨兵，判断是否存在结构性风险。一切正常时不打扰任何人。
发现异常 -> 专家推理
根据异常类型自动路由到对应专家。8 位专家并行推理，证据池交叉验证，形成结构化判断。
主动分层汇报
置信度高 -> 推送给对接人。置信度低 -> 升级给 GA。重大风险 -> 同步老板信箱。
执行跟踪 -> 反馈闭环
执行结果反馈到数据层。哨兵扫描自动对比：有效继续，无效重新诊断。永不停止的循环。

这个流程是持续运转的，不是一次性服务。传统咨询做不到这一点。

文件驱动架构 —— 最深的壁垒

传统咨询每服务一个新行业 = 招一个新合伙人团队（年成本 500 万+）。Synova 每服务一个新行业 = 加文件，不改代码。

传统咨询公司扩张靠的是招更资深的合伙人（年薪 500 万+）。Synova 的扩张靠的是知识资产化——任何行业老兵，把他的毕生经验写成一个 Markdown 文件，系统就能自动学会诊断。新增一个行业，1-2 天，改文件，不改代码。这是咨询业的"工业革命"。

更重要的是，现在的咨询界绝大多数是基于"纯人类组织"的咨询。未来十年，所有企业都会变成"人+AI Agent"的混合组织。这需要全新的咨询方式——既要诊断人的协作，也要诊断 Agent 的行为。Synova 的 SOG 本体模型，是面向人+Agent 混合组织的诊断标准。这是我们最深的技术护城河。

Synova 的能力通过四个扩展模块实现：新增能力 = 加目录 + 加配置文件。这带来了传统咨询无法实现的规模化能力。

专家模块

8 位 AI 专家（战略/组织/财务/营销/技术/商业模式/行动/知识），每位独立 9 个配置文件（IDENTITY / SOUL / RULES / TOOLS / KNOWLEDGE / THEORY / STAGE_LOGIC / CROSS_EXPERT / OUTPUT_SCHEMA）。新增专家 = 新建目录 + 9 个配置文件 -> 自动注册到 ExpertDispatcher。不需要改调度代码。

哨兵模块

26 个哨兵适配器，7 维度 76% 覆盖率。三层粒度：专家（领领域）-> 哨兵（子领域）-> 计算（指标）。新增监测维度 = 加 manifest + 计算函数哨兵自动发现。每个哨兵可以独立说"这个子领域出问题了"。

行业模块

每个行业一个目录，含行业基准数据、特有哨兵阈值、诊断规则、案例库。新行业 = 加一个目录。新增行业不需要改代码、不需要重新训练模型、不需要停服务。客户属性 -> 自动匹配行业知识 -> 调用对应专家。

本体模块

SOG（Strategic Organization Graph）v1.0——自主知识产权的组织数字孪生标准。17 种节点类型、14 种边类型，全部通过 JSON Schema 文件定义。新增实体类型 = 加 JSON Schema 文件。

验证方式：签下 pizza-chain（连锁餐饮），不修改任何 .ts 文件，系统能正确诊断该行业的组织健康度。

产品交互与用户角色

GA（增长顾问）

行业老兵。按 8 维框架调研客户 -> 输入 Synova -> 审阅 AI 专家报告 -> 用经验修正判断 -> 确认方案。服务 10-20 个客户。数据脱敏（L0-L2 可见）。

企业对接人

内部协调。收到 Agent 推送 -> 审阅方案 -> 确认或调整 -> 推动落地。不需要行业经验。只看本企业数据。

部门负责人

在独立工作区和 Agent 讨论本部门方案细化。权限隔离：只看本部门。结果汇入全局。

老板

每周摘要邮件 + 异常即时推送。飞书对话调整信息密度。不打开系统就能知道公司健康度。

三栏交互：左栏工作区列表（每个问题独立上下文）| 中栏对话区（Agent 输出结构化判断+行动按钮）| 右栏行动跟踪（目标/卡点/遗留）。

自我进化：两路反馈回路（GA 纠正 + 客户反馈）。候选池 X2 确认机制。执行效果数据为最高仲裁者。
