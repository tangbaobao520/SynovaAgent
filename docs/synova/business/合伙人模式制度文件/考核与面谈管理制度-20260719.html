考核与面谈管理制度

独立于合伙人管理制度 | 配套执行 | 2026年7月

第七章 考核体系

7.1 考核设计原则

原则一：客观可量化，减少主观判断。 每个考核维度都有明确的评分公式和数据来源，不依赖上级的"印象分"。考核结果由系统数据和客观记录自动生成，人工干预仅限于COO对管理动作执行情况的抽查评估。

原则二：行为+结果双维度。 只考核业绩（结果）不考核管理动作（行为），会导致管理质量失控；只考核管理动作不考核业绩，会导致团队不出单。两个维度必须同时存在。专员层结果占80%行为占20%，经理层结果占60%行为占40%——层级越高，行为维度权重越大。

原则三：月度/季度/半年三级递进。 月度看数字（业绩过没过），季度看趋势（方向对不对），半年看成长（人有没有进步）。三个周期的考核结果用途不同——月度挂钩佣金，季度挂钩升降预警，半年挂钩超额分红和长期晋升。

7.2 专员考核（4维度）

维度权重考核项评分公式数据来源
业绩完成率60%月度个人业绩 / 个人目标完成率×100分（封顶120分）——完成80%得80分，完成120%得120分系统数据自动采集
会所维护质量20%负责会所月产出波动率波动率<20%=100分，20-40%=80分，>40%=50分。波动率=（本月产出-近3月均值）/近3月均值系统数据自动计算
客诉与合规10%月度客诉次数+系统录入及时性0客诉且按时录入=100分，1次客诉=60分，≥2次客诉=0分。系统录入延迟1次扣20分运营记录+系统日志
团队参与10%周会出席率+陪访配合度全勤=100分，1次缺席=80分，≥2次缺席=50分。经理评估陪访配合态度（积极配合/一般/消极）对应100/80/50分经理评估+周会签到

专员考核总分 = 业绩60% + 会所20% + 客诉10% + 团队10%

7.3 经理考核（5维度）

维度权重考核项评分公式数据来源
个人业绩20%月度个人业绩 / 个人目标完成率×100分（封顶120分）系统数据自动采集
团队业绩30%团队月度总业绩 / 团队目标完成率×100分（封顶120分）系统数据自动采集
团队达标率15%团队中完成月目标的成员占比达标率≥80%=100分，60-80%=80分，<60%=50分系统数据自动计算
管理动作执行20%周会纪要提交率（50%）+一对一完成率（30%）+陪访达标率（20%）全部达标=100分，1项未达标=70分，≥2项未达标=0分。各项达标线：周会纪要提交率≥90%、一对一完成率≥90%（当月全员完成）、陪访达标率≥80%COO抽查+系统记录
人员稳定性15%月度团队主动流失率（不含公司淘汰和正常晋升）流失率<10%=100分，10-20%=80分，>20%=50分。流失率=当月主动离职人数/月初团队人数人事数据

经理考核总分 = 个人20% + 团队30% + 达标率15% + 管理动作20% + 人员稳定15%

维度权重考核项评分公式数据来源
区域业绩40%区域月度总业绩 / 区域目标完成率×100分（封顶120分）系统数据自动采集
会所净增长率20%区域月均净增长率（含新签-流失）净增长率≥2%=100分，0-2%=80分，<0%=50分系统数据自动计算
经理梯队达标率40%管辖经理中月度考核合格（≥70分）的占比达标率≥80%=100分，60-80%=80分，<60%=50分系统数据自动计算

总监考核总分 = 区域业绩40% + 会所增长20% + 经理梯队40%

7.5 考核等级与结果运用

等级综合分数月度（佣金影响）季度（升降预警）半年（分红影响）
S≥110分佣金×1.1（超额激励）—超额分红权重+20%
A90-109分全额佣金—全额分红
B70-89分全额佣金—分红×0.8
C60-69分佣金×0.9启动改进计划（1个月观察期）无分红
D<60分佣金×0.8降级预警，连续2个月进入淘汰/解除流程无分红

考核等级的刚性约束： S级比例不超过团队人数的20%（防止评分虚高）。C级和D级不设比例下限——如果全部达标，可以全员A级。每个考核周期结束后3个工作日内公布考核结果，被考核人对结果有异议可在3个工作日内向COO提出复核。

7.6 考核周期与侧重

周期考核重点考核内容结果用途
月度数字业绩完成率+会所维护+客诉（快速反馈，当月出结果）佣金发放依据
季度趋势+行为月度考核平均分+管理动作执行检查+团队状态评估升降预警：C级启动改进计划，D级进入降级程序
半年成长+结果6个月累计业绩成果+团队人员成长情况+管理能力提升超额分红分配+晋升/降级终评

改进计划模板（COO和经理参照执行）： 改进目标（业绩达标率从60%提升到80%以上）→执行动作（每日拜访量从2个提升到4个、每周向经理做一次客户跟进复盘）→检查节点（每周一15分钟面谈检查进度、每周五提交书面周报）→评估标准（30天期满：业绩达标率≥80%为通过，70-80%为延长，<70%为不通过）。

第九章 面谈机制与沟通管理

9.1 经理候选人面谈制度（首次启动专用）

面谈对象： 业绩排名前8的全体候选人。

面谈组织： 由总监和公司决策层逐一进行，每人20-30分钟。面谈在7月底前全部完成。

面谈内容（分两类）：

前4名（正式经理候选人）： 确认任命意向；讲清楚"你不仅自己要业绩好，还要带出3个人"的双肩挑要求；明确管理提成的计算方式；明确告知后4名储备经理的存在及排队竞争机制。

后4名（储备经理候选人）： 首先肯定其业绩成绩——进入前8本身就是公司的认可；讲清楚储备经理的设计目的和晋升路径（3个月时间表、自我组建条件、替代评估资格）；明确告知他们的收入不受影响（个人提成A22%/B24%/C24%）；当面问一句："你觉得自己还需要补什么？"这个问题的答案本身就是一次筛选——能说出具体缺什么的人，比只说"我什么都行"的人更值得培养。

9.2 全员面谈制度（常态化）

每年至少一次由总监或决策层与每位销售专员进行一对一绩效面谈（15-20分钟/人）。面谈内容：过往业绩回顾、能力盘点、职业发展路径、对公司制度的反馈。面谈结果汇总后作为制度迭代的输入。

9.3 意见反馈通道

目的： 让每一位员工有安全的、低门槛的渠道对制度、管理、团队提出意见或投诉。没有反馈通道的制度，员工的意见会累积到离职面谈才爆发。

反馈渠道一：匿名问卷（月度）。 COO每月发起一次匿名调研问卷（企业微信内置问卷功能即可，不需要额外工具），覆盖以下问题：①你对本月团队管理满意吗？（1-5分）②你最近有没有遇到没有渠道说的问题？③你对公司制度有什么改进建议？问卷匿名提交，结果由COO汇总，在月度复盘会上通报处理进展。

反馈渠道二：实名通道（随时）。 员工可随时通过企业微信向COO直接反馈意见或投诉。COO在48小时内给出初步回复。如果投诉涉及COO本人，由公司决策层处理。

反馈处理规则： 每次反馈在48小时内确认收到，明确反馈处理时限（简单问题3个工作日内处理，复杂问题7个工作日内给出方案）。每月汇总反馈处理结果，在团队群内公示（匿名化处理，只说"某位同事提出的XX建议，处理方案是XX"）。
