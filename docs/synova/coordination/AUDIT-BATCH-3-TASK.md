# 第三批审计任务：注册表验证与定稿

> 任务类型：权威文档审计 — 验证阶段
> 执行者：K3（独立会话，零上下文）
> 输入：AUTHORITY-DEVIATION-REGISTRY-v1.md（17KB）
> 输出：AUTHORITY-DEVIATION-REGISTRY-v2.md（最终版）
> 预计时间：45-60 分钟

---

## 任务目标

注册表 v1.1 是第二批审计的分析产出。第三批的任务是**独立验证 v1.1 中的关键结论**——不假设 v1.1 正确，用物理事实重新检验。

**核心原则**：审计者不相信自己的上一份工作产出。

---

## 验证范围（4 个子任务）

### 子任务 1：验证"已闭环"项（10 分钟）

注册表 v1.1 标记了 3 项"已闭环"。逐项验证：

| 项 | 验证方式 | 判定标准 |
|---|---------|---------|
| 已闭环项 A | Read 声称已修复的文件，grep 确认修复存在 | 修复代码真实存在且生效 |
| 已闭环项 B | Read 声称已修复的文件，grep 确认修复存在 | 修复代码真实存在且生效 |
| 已闭环项 C | Read 声称已修复的文件，grep 确认修复存在 | 修复代码真实存在且生效 |

**降级处理**：若任一项验证失败，标记为"虚假闭环"，升级为 P1。

### 子任务 2：P0（N13）深度根因（15 分钟）

注册表 v1.1 中只有 1 个 P0。对其做故障注入验证：

1. **Read 相关代码文件**，确认 P0 描述的现象是否物理存在
2. **构造最小复现**：如果 P0 是"某功能失效"，尝试在干净环境中复现
3. **判定**：
   - 复现成功 → P0 真实存在，保留
   - 复现失败 → 可能是误判，降级为 P1 或删除

### 子任务 3：改判项交叉验证（10 分钟）

注册表 v1.1 有 4 个改判/修正。验证改判的合理性：

| 改判项 | 验证方式 |
|-------|---------|
| D-G2："已修复"→"引擎已修复，数据链路未担保" | 分别验证"引擎修复"和"数据链路"两个子结论 |
| 组 11："phantom"→"已并入组 4" | grep 确认 pre-commit-check.sh 中组 11 确实不存在 |
| 铁律 38："推断覆盖"→"实证全覆盖" | Read pre-commit-check.sh:211-215，确认 `as any` 扫描逻辑 |

**降级处理**：若任一改判验证失败，标记为"改判存疑"，退回原判。

### 子任务 4：待决策项分析（10 分钟）

注册表 v1.1 有 2 个待创始人决策项（P0-8、N14）。不做决策，只做**分析材料**：

| 项 | 分析内容 | 输出 |
|---|---------|------|
| P0-8 | 根因分析：涉及哪些文件？改代码影响多大？改文档影响多大？ | 决策材料（不改代码/文档） |
| N14 | 根因分析：5 分钟 vs 30 分钟的业务影响？用户场景差异？ | 决策材料（不改代码/文档） |

**原则**：K3 只出分析，不替创始人做决策。

---

## 验收标准

### 输出物

**文件**：`docs/synova/research/AUTHORITY-DEVIATION-REGISTRY-v2.md`

**必含章节**：
1. **验证摘要**：4 个子任务的验证结果汇总
2. **已闭环验证**：每项的验证结果（真实闭环 / 虚假闭环）
3. **P0 根因**：故障注入实验过程和结论
4. **改判复核**：每项改判的验证结果（确认 / 存疑 / 退回）
5. **待决策项分析**：P0-8、N14 的根因分析材料
6. **最终偏差清单**：P0 / P1 / 文档任务 / 已验证闭环 的最终状态
7. **版本变更日志**：v1.1 → v2.0 的所有变更

### 判定标准

| 条件 | 判定 |
|------|------|
| 全部 4 个子任务完成 | 任务完成 |
| 有"虚假闭环"或"改判存疑" | 正常产出，标记问题 |
| 有 P0 降级为 P1 | 正常产出，修正分级 |
| 未做故障注入实验 | **任务未完成** |

## 输入材料

1. `docs/synova/research/AUTHORITY-DEVIATION-REGISTRY-v1.md`（唯一输入，不读其他文档）
2. 注册表中引用的具体代码文件（按需 Read/grep）
3. 注册表中引用的控制塔脚本（按需 Read/grep）

## 降级处理

| 场景 | 降级行为 |
|------|---------|
| 某项验证无法执行（如相关代码已删除） | 标注 [DEGRADED]，记录原因 |
| 故障注入实验环境不支持 | 改为代码静态分析，标注局限性 |
| 验证时间超时 | 优先验证 P0 和已闭环项，其余标注待验 |
