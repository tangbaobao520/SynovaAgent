## 二、TD-001（版本锚定与解冻预案，创始人 2026-09-24 决策）

- **锚定**：DSH **`0.1.7-alpha.2`**（内核源码构建）；**唯一判据 = 测量对象 + 绝对路径**（源码树 HEAD `00102833`）；Desktop 打包运行时当日为**回滚**，不作判据。
- **强度**：锁定 + **计划解冻**（非永久冻结）；一句话："用冻结换零跟版成本，账单延期支付"。
- **解冻触发 T1–T5**：T1 发布非 alpha/rc 版本／T2 影响我们的安全漏洞且上游已修／T3 产品需要无法绕过的新能力／T4 客户合规要求／T5 本版本已知问题阻塞交付且无变通。
- **七项准入闸门**（解冻必须全过）：契约测试套件／打包冒烟／旧 session 可恢复／回滚单元=容器级版本化发布／回滚不丢数据／**禁止就地改**／准入失败不发布；**且用例必须穿生产入口**（不是 grep 命中）。
- **回滚档**：采用"同时锚定上一个可用版本"；候选 `0.1.6-alpha.2` 现状态=**候选，待准入验证**（降级硬拒绝：能退版本但**数据无损回退不成立**）。
- **允许平移型解冻**（锚定 → 平移到另一个 alpha）；否则"等正式版"= 永不解冻。成本 1.5–3 人日/版本步。
- **随锚定锁进来的已知问题**：含 macOS 沙箱行为、`session-query-sqlite` 默认 `:memory:`、`mcp-client`/`schedule`/`webhook`/`time-context` 默认零挂载、`session-log-deepseek` 默认开、headers 关不掉、`web-search-deepseek` 直连等。⚠️ **其中"45 个包不可达"的数字已作废**（见 §五）。
- **纪律**：**不能自己修 DSH 的 bug**（禁止就地改）→ 我方借鉴实现只能**在自己侧绕过或自研**。

## 三、研究议程 §七 的纪律（**对全院生效，我方同步遵守**）【我实读】

1. 不再引用 M3-1 的"不存在／为 0"类读数（机制判据可用，**数字与"不存在"结论作废**）。
2. **所有对象绑定必须写明「哪个仓库的 HEAD」**（无 `.git` 的目录 `git rev-parse` 会落到父仓库）。
3. 凡靠"扫描 `process.cwd()` 下某目录"得出"不存在"的结论，**必须先证明该目录被完整拷贝**。
4. **判据必须是「穿生产入口的用例」，不是 grep 命中。**
5. **数字使用规则**：**任何进「决策依据段」的数字，必须先出现在未核实登记册且状态为"已核实"**；源头标【未核实】/【证据不足】者**不得进决策依据段**。
6. **宪章级文件的证据要求**：必须自带可复核性 = **证据节 + 反例与失效条件 + 未核实清单 + 推断与事实分标**（理由：*宪章级文件自己不可复核，就约束不了任何人*）。

**7.6 七环研究链条**：① 取证 → ② **综合（⚠️ 历次事故全部出在这一环）** → ③ 独立复核（复核者自写探针、**不看原结论**）→ ④ 登记 → ⑤ 分流 → ⑥ 使用 → ⑦ 约束。
**使用说明**：不必每次全走；**但凡进入「决策依据」的产出，必须走满 ②③④⑤⑥**。
**为什么**：五次事故共同点全是**转述失真**（口径错/事实反了/口径混/方法漏洞/限定词丢失），不是取证错误。

## 五、边界评估（14 件）的错误清单与 CTO 裁定

**必须先处理（我复现过的 8 条）**：
1. **「45 个包不可达」+ 六档闭包规模 → 数字作废**：其复跑脚本 R3 是**空壳 heredoc**；探针目录**无任何闭包脚本**；多口径互不相等（45 ／ 62·68 ／ 63·65）。
2. `dsh-client-runtime` **在 0.1.7-alpha.2 不存在**，而我方插件 `synova-dsh-dashboards` 仍在注入它（死声明，静默跳过）。
3. **任务四判据指向错消费者**：`src/sentinel/sentinel-loader.ts:222` 与 `:228` 的谓词作用于哨兵 `manifest.dependsOn.nodeTypes`，与 `targetNodeType` 无关；真消费者 `src/agent/data-ingest-service.ts:128` 按**文件名约定**解析，JSDoc 明写"当前 8 个映射类型均成立" → 照文档做会得出**错误的数据迁移裁定**。
4. **【05】"web 档无联网工具"与源码相反**：host 行 disable，但 `web-app/presets/*.patch.yml` 按 agent 重新挂上。
5. **【05】"会话格式三次"少一代**：实为四个迁移包（v0→v4，且 `v3→v4` 正落在锚定版）；且**漏了 `0.1.7-rc.1` 已发布**（改变 T1 时间预期）。
6. 【05】标题「四项前提已满足」与正文「⚠️ 降级为基本成立」并存；§八仍在请创始人裁**已裁事项**。
7. **登记册 §五"8 条源文件未改"实测全部已改**（3 条写册前就改了）；登记册"已核实"实测 **2/76**（而非 0）。
8. `边界E` 引用**系统性 -3 行**（实测 4/4）；E 的「N=1／客户是老板本人」判据**挂错文件行**。

**方法上可复用（`边界D` 六件套）**：① 断面绑定先行（根非 git 仓时禁出现 `git rev-parse`，改逐文件 blob 比对）② 自写探针复跑 ③ 同一判据横向对照多输入 ④ 口径裁定表 ⑤ 三类系统性错误专查（口径／断面／时序）⑥ 置信度分层 + "证据不足"与"无法核实"两张独立清单。

**⚠️ 时效教训**：实验根在 `.tmp` 内**会消失**（`exp-m3-capability` 已不存在）→ 证据必须落 **生成方式 + 校验清单**，否则不可复现。
