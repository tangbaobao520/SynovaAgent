## 三、Win 侧同步操作（可复制执行）

```bash
# 0) 前提：DSH 已装、gh/ssh 凭据可用（凭据见 ~/.dsh/.credentials.yaml，不入仓）
cd <Win 仓库路径> && git fetch --all && git status -sb     # 必须在 main 且与 origin/main 一致
git pull --ff-only

# 1) 技能同步（仓内单源 → .dsh）
bash scripts/workflow/sync-dsh-skills.sh --check   # 期望 SYNC-OK（当前应为 16 个技能）
bash scripts/workflow/sync-dsh-skills.sh           # 需要同步时执行

# 2) 预设落位（G1 修好后可自动探测；修复前用 --standard-from 显式给路径）
bash scripts/control-tower/install-dsh-preset.sh --install --standard-from "<DSH standard 预设目录>"
bash scripts/control-tower/install-dsh-preset.sh --check   --standard-from "<同上>"   # 期望 SYNC-OK

# 3) 小队队长预设
bash docs/synova/presets/install-squad-lead.sh "$(pwd)"

# 4) 门禁自检（必须全绿才开工）
bash scripts/pre-commit-check.sh
bash scripts/workflow/sync-dsh-skills.sh --check
```
