## 一、规约（四句话）

1. **一个切片/模块只派一个执行方**：不因域边界把同一模块/切片拆给两台机器 → 期间一律 **Mac 侧执行**（不再「Mac 做一半、Win 排队等」）。
2. **域声明不变**：产物域仍按 `ownership.yaml` 判定（Win 文件就声明 `域: win`），Mac 代行**不改变归属**，只改变执行方。
3. **单域 PR 门禁不变**：跨域切片在同一执行方内拆成多个 PR（各自单域），但**连续做完、连续提交**，不等 Win；D734 预算上限照旧（超 12 文件拆单，禁调上限）。
4. **验收分两级，不许混同**：
   - **代码级**（类型 / 单测 / 集成 / 真实路由接线）→ **Mac 可验，必须验**，证据落 git
   - **实机级**（Windows 安装/升级/双击 GUI/NSIS 路径/权限框等真机行为）→ **挂账**，登记在案，Win 回归后补验；**禁止**用 Mac 结果声称实机通过
