## 取号规矩（三条）

1. **侧内自取，取到即 push**（不得只放本地，否则对侧看不到水位）。
2. **不得越段**：Mac 不取 D1000+；Win 不取 D1000 以下；两侧均不跳取到本段上限之外。
3. **每次取号回报当前最高已用号**（一行），由 Mac-CTO 更新本表水位。

## 发号前置（Mac-CTO 自查，2026-09-25 新增）

发任何号段前**必须**三步取证（缺一不得发号）：
```bash
# ① 目录内已用号（含未合并分支）
git ls-tree --name-only origin/main task-state/ | grep -oE 'D[0-9]+' | sort -u | tail -3
for b in $(git ls-remote --heads origin | awk '{print $2}' | sed 's#refs/heads/##' | grep -E 'cto|win|k3'); do \
  git ls-tree --name-only origin/$b task-state/ 2>/dev/null | grep -oE 'D[0-9]+' | sort -u | tail -2; done
# ② 本文件水位
sed -n '/## 现行分区/,/## 取号规矩/p' docs/synova/coordination/号段水位.md
# ③ 对侧最近回报的最高已用号
```
