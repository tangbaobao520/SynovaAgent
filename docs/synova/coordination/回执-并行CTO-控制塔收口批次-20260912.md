## 二、逐任务结论

### D706 — 提交链静默丢删除项（P1）

- **根因（实测，**推翻派单初判**）**：`synova-commit` L600/L602/L693/L695 用 `git commit -m msg -- <pathspec>`。该形式走 git **部分提交机制**（对匹配路径用**工作区内容**内部重算）。当路径满足「索引已删除 + `.gitignore` 命中 + 磁盘仍存在」（D665 摘除 gitlink 的真实形态）时内部 add 因 ignored 跳过 → 删除不进提交；其它路径有变更 → git 仍 `exit 0` 报「提交完成」→ 提交后 git 用新 HEAD 回填索引 → **暂存态被静默销毁**。
- **派单假设被证伪**：派单认为缺陷在**失败回滚路径**。实测——门禁失败分支只在 `:763` 追加 bypass.log 后 `exit 1`，**不触碰索引**；跨调用复现证明拒绝后暂存态完好。丢失发生在**成功路径**。
- **修法**：① 索引精确提交（`git commit` 无 pathspec/-a）② `--files` 前置断言 staged ⊆ FILES ③ 提交后不变量校验，不一致 → `exit 1` + 点名差异 + **撤销提交 + 还原索引**（防「报告失败但提交已进历史」的假阻断）。
- **验收**：沙箱复现 `git ls-tree` 1→0；`synova-commit.test.sh` **17/17 绿**；同测试跑 `origin/main` 原版 **6 红**（反向验证）。
- **附带发现**：`git add <gitignore 命中路径>` 必然拒绝 → 旧写法使 `--files` 模式**无法表达** D665 型摘除（已一并修）。

### D707 — brief 架构层双解析器口径统一（P1）

- **缺陷 A（派单已列）**：组 6 的 awk `next` 跳过标题行 → 内联值永远读不到。存量实测 **232/629 份 brief（37%）** 用内联写法，全部误报。
- **缺陷 B（派单未列，实测发现）**：`brief_parser.py:100` 旧正则 `\s*(.+)` 的 `\s` **会吃掉换行** → 下一个 `## 标题` 被当成架构层的值 → **空值被判「已填写」= fail-open 假绿**（`## 架构层:` + `<!-- 待填 -->` 实测 PASS）。
- **修法（推翻派单建议）**：派单建议「顺手改 D660 brief 1 行」。实测 232 份内联 → 改 1 份属治标。改为**收敛到单一事实源**：删除组 6 的 awk 第二实现，改调 `brief_parser.py --layer`（与本文件 `:1234` 既有 Q2 同源用法一致）；解析器规则改精确（禁跨行吞标题、拒绝注释占位）。不保留 awk 回退（回退实现自身会漂移——实测全角冒号 `## 架构层：X` 在 awk 下失败而解析器正常）。
- **验收（真实 `pre-commit-check.sh`）**：内联写法组 6「架构层: 未填写」计数 **1→0**；空值负例保持 1（门禁未改软）；`brief-parser-strip.test.sh` **30/30 绿**，原版脚本跑同测试 **6 红**。

### D664 — grep -P 家族清理（P1）

- **基线修正**：不是「6 处」，实测 **10 文件 28 处**（需转译 **27 处**；另 1 注释 + 2 文档）。**27 处里 24 处在 D661 回归网的覆盖范围之外**。
- **转译**：`\d`→`[0-9]`、`\s`→`[[:space:]]`、`\S`→`[^[:space:]]`、`\K`→「`grep -oE` 取全匹配 + `sed -E` 剥前缀」（3 处）、其余 `-oP`→`-oE`。
- **执行期两次自纠（均在 CI 之前）**：
  - **陷阱 A**：`\]` 在 PCRE 里是转义 `]`，在 POSIX ERE 方括号内**不是转义符** → `]` 提前闭合字符类 → 模式匹配不到任何东西。**被本批新增的语义金值断言当场抓到**。
  - **陷阱 B**：3 处 `\K` 转译把文件参数留在 `sed` 之后（`grep -oE 'PAT' | sed -E 'S' "$FILE"`）→ grep 改读 stdin → **提取恒空**。金值断言测不到（只测模式不测命令形态）→ 补**静态形态守卫 + 可执行断言**。
- **回归网扩容（旧版是纸老虎）**：只扫 2 个目录 → 扩到 `scripts/` **全目录**；**不在 ci.yml 密封清单 → 从未在 CI 跑过**（M3 未接线）→ 接入密封清单末尾 +1 行。断言 1 → **36**（含反向哨兵）。
- **验收**：`grep-oP-regression.test.sh` **36/36 绿**；macOS `pre-commit-check.sh` rc=0（13 组）。
