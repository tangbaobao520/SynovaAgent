## 三、交付要求（每次审计都要有）

1. **审计报告**落 `docs/synova/audit-reports/<日期>-<D#>.md`（或批次合并报告），每条结论带 **file:line 或命令 + 原始输出**
2. **结论回填** `task-state/D###.json` 的 `audit` 段（`verdict` / `report` / `at` / `by` / `note`）——**这是看板与产品进度页的唯一真相源**
3. **FAIL 必进台账** `docs/synova/coordination/AUDIT-FINDINGS-LEDGER.md`（含 M 模式归类：M1 fail-open / M2 声称 vs 事实 / M3 未接线 / M4 证据链断裂 …）
4. **不许预设结论**：证据不足 → `NOT-AUDITABLE` 并写清缺什么（不许"基本通过"）
5. 对 A 组：**必须独立重跑**（不接受转述的命令与输出）
