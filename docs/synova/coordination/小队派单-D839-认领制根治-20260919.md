## ③ 执行形态：**单人单工作树（不启用 agent team）**

> **明文结论**：本卡**不 spawn 队员**，由一个编码 session 独做。理由：① 可并行的独立切片 = **0**；
> ② 两个必改文件（`staging_guard.py` / `session_registry.py`）被 ①②③ 三处要求**跨项重叠引用**，
