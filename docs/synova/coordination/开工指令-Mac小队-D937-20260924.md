## 一、执行形态（**硬要求，缺一即退回**）

1. **必须用 Agent Teams 组队**：预设 `synova-squad-lead` 已挂 `agent-team` + `tool-agent-team` + `ui-agent-team`，`maxMembers=4`。
2. **编制**：队长 + ≤2 编码 + **1 独立自验**（自验**不得**由编码兼任）；**队长不下场写码**。
3. **派活走共享任务**：每成员一份，正文含「**写集（逐文件） + 验收命令 + 写者**」；写集两两不重叠。
4. **重型验证串行 ≤1**（vitest／全量门禁／黄金门禁）。
5. **回执必须含「团队成员运行记录」**：成员名 · 运行状态 · token · 共享任务 id 与状态。
6. **判定与退回**：只队长在跑 / 成员未运行 / 无共享任务 id / 写集未逐人拆 / 自验由编码兼任 → **退回**。
   ⚠️ **严禁用子代理代替小队**：子代理无共享任务板、无 mailbox、无持久身份 → 无法独立自验、无法留运行记录 = 作者自判通过（已发生过的 M3 型事故）。
