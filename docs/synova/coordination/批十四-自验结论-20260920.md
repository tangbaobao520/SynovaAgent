### 2.1 基线缺陷：我独立复现（不引用交付方复现）
按 HEAD 基线原样复刻 DDL/触发器后实测：
```
messages = 1 fts = 1
DELETE agent_messages -> FAIL: SQL logic error
DELETE agent_sessions -> FAIL: SQL logic error
after: messages = 1 fts = 1              ← 删不掉
FTS search hits after delete attempt = 1  ← 已"删除"内容仍可召回（隐私面）
```
成因：`agent_messages_fts` 是**普通** FTS5 表（`session_id UNINDEXED, content, tokenize='unicode61'`，无 `content=''`），而 `agent_msg_fts_delete` 用的是 **contentless/external-content 专用** 的 `('delete', old.session_id, old.content)` 命令 ⇒ SQLite 物理拒绝 ⇒ `deleteSession` 全路径失败（`DELETE /api/sessions/:id` → 500）。
