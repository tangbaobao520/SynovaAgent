# 模块归属（Mac / Win）— 一个模块只归一边

> 规则：① 一个模块 = 一个 owner（整目录/整包，禁按文件切）② owner 负责该模块全部改动类型 ③ 跨模块任务拆两张卡、串行，禁跨侧同文件并行。
> 落地方式：`ownership.yaml` 路径前缀 → 唯一域（最长前缀优先），未登记 = 不可改（fail-closed）；由既有 `check-ownership.py`（D733）+ PR 单域（D734）**物理执行**。
