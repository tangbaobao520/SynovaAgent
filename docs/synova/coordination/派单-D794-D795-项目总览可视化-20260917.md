## 〇、本单要解决什么

创始人看不到"哪些做好了 / 哪些卡住"，且要求**可视化必须进 DSH GUI**（侧边栏一个入口，全局可见），而不是靠人翻文档。

链路：**git 真相（task-state + product-lines + 证据）→ D795 派生 `ledger.json` → D794 插件把它渲染进 DSH 侧边栏**。
原则：**插件只做视图**——真相在 git；插件零写入；每块独立降级；不新增第二个真相源。

**内部一致性自检（历史教训：同一单两条要求对同一路径互斥，是执行方替我发现的）**：
- 两卡文件集**互不重叠**：D794 只动 `dsh/plugins/**` + `~/.dsh/profiles/web/**`（用户目录，不进仓库）；D795 只动 `scripts/project/**` + `tests/project/**` + `docs/synova/project/ledger.json`。
- 无互斥要求：D795 是数据源、D794 是消费者；D794 在 D795 未就绪时用 mock 先搭壳（不阻塞）。
- 唯一共享文件是 `README.md` 之外的**无**；`docs/synova/project/` 下 D795 写 `ledger.json`，D794 **只读**。

## B. D795 — 项目账本派生器（执行方：编码 session · Mac 域）

### B.1 目标

新增 `scripts/project/gen-project-board.py`（纯 Python3，禁止新增三方依赖），读 git/文件事实，产出
`docs/synova/project/ledger.json`（**派生物，禁手工编辑**，文件头字段写 `generated_by` / `generated_at` / `git_head`）。

### B.2 输入（全部只读）

| 输入 | 用途 |
|---|---|
| `task-state/D*.json` | 任务卡（status/owner/depends_on/blocked/updated_at；**本卡起新增 6 字段为可选，缺省=未知**） |
| `docs/synova/product-lines/product-lines.yaml` | 26 线 + 164 个验收点 + 线级 `done_definition` |
| `docs/synova/project/26线-V1验收标准-草案v0.1-20260917.md` | **V1 断言表**（125 条：ID/断言/verify/证据类型/fail_when）→ 解析出 V1 分母 |
| `docs/synova/product-lines/evidence/*.json` | 机器证据（scenario/test/ci/founder_demo/k3） |
| `scripts/golden-scenarios/evidence/*.json` | GS 场景证据（**注意：calc 只扫产品证据目录，本派生器两处都算**，并在输出 `sources` 标明来源，避免 K3-B5-P1 那类静默丢弃） |
| `docs/synova/audit-reports/*`（可选） | K3 复核记录（判 `verified` 用） |

### B.3 口径（照抄，不得自创）

- **交付度** = `v1_passed / v1_total`（分母 = **125 冻结**；V1 外 39 点计入 `backlog_points` 不参与）
- **断言通过** = ① 有证据且未过期 ② 证据类型与断言 `verify` 声明匹配（优先级 k3 > test > scenario > founder-demo）
- **验证率** = `v1_verified / v1_passed`（`verified` 需对应线/点的 K3 PASS）
- **保鲜** = 证据龄：≤7 天 🟢 / 8–14 天 🟡 / >14 天 🔴（**只计数，不扣交付度**）——这是 09-17 创始人拍板的口径变更
- **阻塞** = 仅当 `blocked{reason,since,needs}` 三要素齐全才计入；`days = today - since`
- **降级** = 任一输入缺失/坏 → 记入 `degraded_sources[]`，对应字段用 null 并置 `degraded: true`，**不得抛异常、不得静默填 0**

### B.5 测试与反向验证（铁律 48：非空壳）

`tests/project/gen-project-board.test.sh`（用临时目录夹具，禁写真仓库）：
1. 正常路径：夹具 → 断言数字与手算一致
2. **反向**：删掉一条证据 → 该断言 `ok` 由 true 回退 false（证明不是硬编码）
3. 降级：缺 yaml / 坏 JSON → `degraded:true` + `degraded_sources` 非空，退出码非零或显式字段（按契约二选一并写清）
4. 保鲜边界：7 天 = 🟢、8 天 = 🟡、14 天 = 🟡、15 天 = 🔴
5. 幂等：连跑两次，除 `generated_at`/`git_head` 外逐键相等

- **红线**：`calc-progress.py` **零提交**；不写回 `product-lines.yaml`；不碰 `scripts/audit/**`；不新增三方依赖。
