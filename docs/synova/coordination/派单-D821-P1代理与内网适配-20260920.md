1. **规格冻结（编码 A 主笔，队长批）**：`docs/plans/<日期>-D821-出站HTTP唯一出口-规格.md` — 定义**唯一出口**的输入/输出/降级契约（铁律 47）：代理来源（env / 配置）、超时、重试、错误分类（`.code/.phase/.retryable`，铁律 32）、降级标记（`degraded: true` + `log.warn`，铁律 11/24/31）、凭据处理（禁入业务层）；
2. **实现**：所有外部 HTTP 调用**收敛到该出口**；

4. **降级路径**：代理不可达 → 明确错误分类 + `degraded` 可见，不得静默失败；
5. **回归**：既有调用点全部改造后，相关测试全绿（给命令与输出）。
