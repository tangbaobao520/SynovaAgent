# 1-1 安装包能打出来 — 产物清单 + 版本一致性 (2026-09-13, Mac / arm64 主机)
## 打包命令（本机实测链）
npm run build:backend  →  (cd electron-renderer && npm run build)  →  cd node_modules/better-sqlite3 && npx prebuild-install -r electron -t 33.4.11  →  npx electron-builder --config build-synova.cjs --mac

## 关键发现（构建链缺口，非本批代码变更）
build-synova.cjs 头注释写的'三步链'未含 native 依赖准备步；CI (.github/workflows/desktop-build.yml:75
'Prep native deps (better-sqlite3 electron prebuild)') 才做 prebuild-install -r electron。
本机只跑三步链 → 包内 better-sqlite3 为 node ABI(127)，Electron 33 需 130 → 装完后端 ERR_DLOPEN_FAILED。
补跑 prebuild-install 后重打包 → 实测通过（1-3/1-4 四断言全过）。
