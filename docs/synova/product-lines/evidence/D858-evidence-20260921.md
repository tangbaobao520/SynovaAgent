## 8. 已知局限（诚实清单，与"未覆盖"分开列）

1. **静态解析固有边界**：覆盖来源 = ci.yml 的**非注释行文本** + 文件系统物理展开；不执行 ci.yml 语义。因此字符串内的路径（如 `echo "tests/x.test.sh"`）仍会被计为覆盖；`#` 前无空白（`foo;#bar`）亦属代码段。K3 P1 只要求"不得由**注释**承载"，已满足。
2. **未启用 globstar**：macOS `/bin/bash 3.2` 无 `globstar` → `**` 按单层语义；脚本 L64-67 显式声明，当前真实形态为单层 glob。
3. **C3（本卡写集外）**：`.github/workflows/ci.yml:277` `|| true` 吞新 exit 1 → 假覆盖在 CI 层尚不阻断。已登记 CT-78 + D862 排期。
4. **实机环境**：本地 macOS（bash 3.2 + BSD 工具）验证；真实 runner 为 bash 5 + GNU 工具 → CI 腿为实机补充证据（§7）。
