## 3. 已知边界（自验员登记，不阻断通过；均已进收口遗留清单）

1. **`$(...)#` 残余误红**（fail-closed 方向）：`bash -c 'echo $(echo a)#c'` → `a#c`（命令替换后的 `)#` 不是注释），而脚本一律把 `)` 当词边界 → 该形态下真实可执行路径被判为注释声明 → 误红。反证：该通道**无法隐藏路径**（截断内容仍进 DECLARED 并受"必须被物理覆盖"校验）→ 不产生假绿。修法需命令替换深度感知（静态单遍引号跟踪难以兼顾裸子 shell 的 `)#` 真为注释）。
2. **文本级残余（固有）**：覆盖来源是"非注释行文本 + 物理展开"，不执行 ci.yml 语义 → 字符串内的路径（如 `echo "tests/x.test.sh"`）仍算覆盖。卡面 P1 的要求是"不得由**注释**承载"，已满足。
3. **gawk/Windows awk 未实机对拍**：本机仅 BSD/BWK awk；仅静态论证 + 中文夹具实测支持方言等价（结论：脚本只用 POSIX 构造 + `sprintf("%c",39/92/9)` 规避转义方言）。bootstrap：本卡 CI 的 ubuntu/windows 双腿为真实 runner 证据（见证据件 §7）。
4. **`|| true` 对新增 exit 2 同样吞码** → 已并入 CT-78 / D862 修复范围。
