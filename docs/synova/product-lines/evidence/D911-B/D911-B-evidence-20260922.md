### 关键差异（逐处「为什么改」）
**① `docs/synova/coordination/ownership.yaml`（+18）—— B1 单点开关**
```diff
+standby:
+  win:
+    offline_since: "2026-09-20"
+    proxy: "mac"
+    authority: "创始人 2026-09-20 口令（转抄: .claude/task-briefs/2026-09-22-D861-win测试修复-代行.md:5）: win 机器不在线，所有 domain:win 任务一律 Mac 代行，直到创始人说「win 回归」"
+    domains: ["win"]
```
- 段内注释写明：**本段缺失 = 严格模式（现状）**；**win 回归 = 删本段 + 重跑 `--emit-codeowners`**。
- `domains: ["win"]` = **owner 域**语义（非 glob）；实测 `--proxy win=bogus` 仍 `EXIT=2`，故与 owner 域集合一致。
- 语义是「事实状态登记」，不是「权限授予」→ **状态消失即回严格，不依赖任何人记得关**。
- `authority` **如实标注转抄**出处（非创始人原始消息）。

**② `scripts/control-tower/check-ownership.py`（+363/−43）—— B2/B4/B5**
- 新增 `known_owners()` / `_parse_standby()`：结构校验（非映射 / 空映射 / 未知域 / 缺 `proxy|authority` / `proxy=自身` / `domains` 非法）→ `_die` → **`exit 2`（fail-closed）**。
- `offline_since` **值校验**：非 `YYYY-MM-DD` → `exit 2`；日历越界（`2026-13-45`）→ `exit 2`，**坏值不进审计链**（避免污染 B2 的理由串）。
- 新增 `--proxy <域>=<代行域>`：仅当 standby 段授权一致才代行，逐条 `↪ 代行 <原域>→<代行域>` + 归属 / 理由 / 授权 / 依据。
- **三态统一**：`--proxy` 域值非法 → `exit 2`；**合法但未授权** → `⚠️ 不生效` + `exit 1`（非 fail-open）。
- B5：`docs/**` / `tests/**` 下**无显式规则**目录 → 显式诊断「真正的错是该目录没登记」，**不新增阻断**。
- `emit_codeowners()` **签名不接受 standby** → `standby` 不是产物输入（单点开关无双写点）。

**③ `scripts/control-tower/check-pr-budget.sh`（+377/−6）—— B3**
- 新增 `--pr-body <FILE>`（缺省回退 `GITHUB_EVENT_PATH`）与 `--decl-file <PATH>`（env-free）。
- 声明源② 走**认领制指针** `.claude/current-brief[.<session>]` → `.claude/task-briefs/<名>`；**绝不回落固定路径**（防「依赖不相干文件放行」的 fail-open 面）。
- 段标题正则 `HEAD = re.compile(r"^#{2,4}\s*代行声明")` —— **同 D708:246**（`\s*` 含零空格），**不 import 跨切片代码**。
- `resolve()` 用 D708 同型：收段 `^#{1,4}\s`｜条目仅 `- ` 开头｜分隔 `\s+[—–-]{1,2}\s+`；`reason_ok()` 额外要求理由含字母/数字/记号（**补 D708 `strip()` 挡不住纯标点的洞**，已在注释写明不是口径分叉）。
- 无 `## 代行声明` → **硬阻断 `exit 1`**；放行与 PASS 行都**点名声明源文件**。
- 授权判定**不自己算**：交 `check-ownership.py --proxy` 单点真相，并自校验 `代行 N` 与 `↪` 行数一致，不符则 `⚠️` + `exit 2`。
