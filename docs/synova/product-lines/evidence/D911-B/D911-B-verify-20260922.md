## 二、切片 B 判据验收（B1/B2/B3/B4/B5）

### B1 `standby:` 单点开关 ✅
- `ownership.yaml` 增顶层 `standby:` 段（仅 `win`）：`offline_since` / `proxy: mac` / `authority` / `domains`。
- `authority` 如实标注为**转抄件**并给出出处 `.claude/task-briefs/2026-09-22-D861-win测试修复-代行.md:5`（非创始人原始消息）。
- **单点可逆已实证**：删 `standby:` 段 → 立即恢复严格（`EXIT=1`）；且 **`standby` 不参与 CODEOWNERS 生成**（见 §三），故 win 回归只需删一处。

### B2 代行断言路径 ✅
```
$ python3 scripts/control-tower/check-ownership.py <#696 变更集> --proxy win=mac
↪   代行 win→mac  tests/agent/expert-file-loader.integration.test.ts
      · 归属: 原始 owner=win（规则 glob=**（兜底/default））→ 代行 owner=mac
      · 理由: standby[win] offline_since=2026-09-20｜授权: 创始人 2026-09-20 口令（转抄: …D861…:5）: win 机器不在线，所有 domain:win 任务一律 Mac 代行，直到创始人说「win 回归」
（× 3 条 win 文件，逐条打印）
✅ PASS 9 个文件同域: mac（无归属 0，域判定豁免 6，代行 3）
EXIT=0
```
**逐条打印四要素**：归属（原始→代行）/ 理由 / 授权出处 / 依据 —— 满足 B2「逐条打印被代行文件归属 + 理由」。

### B3 PR 预算门禁代行放行 ✅
- `check-pr-budget.sh` ② 域判定接入 `--proxy`；**无 `## 代行声明` → 仍硬阻断**。
- 声明源：① `--pr-body <file>` / 回退 `GITHUB_EVENT_PATH`；② env-free 认领制指针 `.claude/current-brief[.<session>]` → `.claude/task-briefs/<名>`。
- **放行逐条打印**，且**放行行与 PASS 行都点名「声明源是哪个文件」**。
- 端到端（CI 形态：零参 + `--quiet` + 事件体）：**修前 `EXIT=1` → 修后 `EXIT=0`**。

### B4 判据钉死（fail-closed）✅
**口径定案**（派单件 B4 与 §三反例② 字面矛盾，队长裁定）：
- **整段不存在 = 严格模式**（`EXIT=1`）—— win 回归的合法路径；**不是** `exit 2`
- **段存在但结构/字段非法 = fail-closed `EXIT=2`**

实测：
```
$ … --proxy win=bogus …                                       → EXIT=2（域值非法 = 坏参数）
$ … --yaml <offline_since: "not-a-date">                      → EXIT=2（不是 YYYY-MM-DD）
$ … --yaml <offline_since: "2026-13-45">                      → EXIT=2（日历越界）
$ … --yaml <缺 authority>                                     → EXIT=2
```
**红线未动**：合法域对但**未授权**（`k3=mac` / `mac=win`）→ 仍 `EXIT=1` + `⚠️ 不生效`（不是 `exit 2`，也不是放行）。

### B5 新目录登记门禁（诊断性）✅
```
$ … tests/circular-dependency.test.ts docs/README.md scripts/control-tower/check-ownership.py
⚠️  B5 目录未登记（ownership.yaml 内**无显式规则** → 落 `**` 兜底 = win）:
```

- **诊断性显式提示，不新增阻断**（派单 §三 要求「零新增红 + 既有测试全绿」）。
- **无假阳性守卫**：超范围 `scripts/control-tower/sub/deep/x.py` → 提示行 **0**；已登记目录 → 无提示。
- 范围只含 `docs/**` + `tests/**`（与卡面一致）；文案已按实测改为「无显式规则」+ 层级标注。
