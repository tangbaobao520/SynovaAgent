### ⑦ concurrency 生效证据
```yaml
concurrency:
  group: "${{ github.workflow }}-${{ github.ref }}"
  cancel-in-progress: "${{ github.ref != 'refs/heads/main' }}"
```
- **为何不误取消 main**：`group` 含 `github.ref`，main 的 ref 恒为 `refs/heads/main`；且 `cancel-in-progress` 对 main 显式取 **false** ⇒ main 上每次 push 的 run 与 check 记录完整保留（branch protection / tag 对账要读）。
