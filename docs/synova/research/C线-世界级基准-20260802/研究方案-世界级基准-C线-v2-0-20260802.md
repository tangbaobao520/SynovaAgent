# C线《世界级基准定义 v1》研究方案 v2.0

> 2026-08-02 | 经创始人确认后定稿 | 评审 A/B/C 与定位修正全部并入
> 定位：研究 session 最后一条主线——定义"世界级"的外部标尺，回答"Synova 差多少、该做到多少"

## 一、研究背景

1. **总计划最后一条主线**：A线给了"内部真相"（文档 vs 代码）、B线给了"客户视角"（老板信什么）、C线给"外部标尺"——世界级长什么样、量化为多少、Synova 差多少。
2. **时机**：员工分享已交付，盛和塾演示 8 月底——C线第一版赶在演示前交付"对标弹药"。
3. **市场定位**（2026-08-02 修正方向，待创始人定稿）：5–1000 人、请不起麦肯锡级咨询的企业。客户并非"没有 AI/IT 系统"，而是系统不全、散乱、不成体系；传统软件是给人看的，未来软件是给 Agent 用的；客户有系统对 Synova 反而是数据利好。
4. **参照系结论**：SMB 老板心智里的真实参照系不是麦肯锡——是老板自己的直觉，加上真实接触过的机构（盛和塾、长松咨询、昆仑定位、和君咨询、行动教育等，或商学院自学）。方法论口径：**对标顶级（提取机制），也要结合实际（老板心智锚点）**。（2026-08-03 补充：行动教育=国内唯一 A 股上市企业培训公司，价格带 3.58-35.8 万/人，详见第一章 §二）

## 二、研究问题

- Q1: 世界级组织诊断/增长导航的可量化标准是什么？（六维度 × 三值结构）
- Q2: 8 类对标对象各自的最强机制是什么、证据是什么？
- Q3: Synova 在每个标准上的现状与差距？（只消费 A线结论，不重新审计）
- Q4: 哪些标准在 SMB 市场被重新定义、重定义成什么、依据是什么？（双轨制：通用世界级刻度 + SMB 合理值 + 差异推导）
- Q5: 差距清单如何反哺 A/B 线与开发排期？演示对标弹药如何预埋？

## 三、核心模型：六维度 + 时间横切 + 三值结构

**推导顺序**：先提取标杆最强机制（第一章）→ 抽象共性维度 → 用"信任建立"视角补充 → 第一性原理验证完备性（第二章）。不是先画靶再射箭。

| # | 维度 | 核心问题 | 关键标准（示例） |
|---|------|---------|----------------|
| 0 | 信任建立（第一视角） | 老板凭什么放下直觉相信系统？ | 价值第一印象 / 闭环验证 / 制衡机制 |
| 1 | 诊断质量 | 准不准、全不全、深不深 | 根因命中率、42 边覆盖率、因果链 vs 指标罗列 |
| 2 | 交付形态 | 老板看得懂、用得上吗 | 报告可读性、行动采纳率、首个价值时间 |
| 3 | 部署运营 | 没有 IT 的人能自己跑起来吗 | 双击 exe 级部署、无数据诊断、权限安全、稳定性 |
| 4 | 经济模型 | SMB 付得起、愿意续吗 | 价格/单位经济、续费率/NRR |
| 5 | 进化能力 | 越用越准吗 | 反馈→规则更新闭环、知识沉淀、组织记忆 |

**时间维度（横切贯穿）**：诊断准确率持续改善速度、首次价值时间、诊断周期、模型校准周期、从反馈到规则更新的闭环时间。参照：Palantir Foundry 部署到价值需数月、麦肯锡进场到汇报需数周——Synova 数天，时间本身就是差异化。

**三值结构（每个标准必答）**：
1. 通用世界级刻度（外部锚点：麦肯锡/Palantir/行业顶级在这个维度是多少）
2. SMB 市场合理世界级（在"没有人、没有钱、没有时间"约束下是多少）
3. 差异推导依据（为什么重定义成这样）

## 四、对标对象清单（8 类）

| # | 类别 | 对象 | 提取什么机制 |
|---|------|------|-------------|
| 1 | 顶级咨询 | 麦肯锡/Bain/BCG、四大 | 结论先行、证据分层的结构化汇报；问题框架 |
| 2 | 数据/情报平台 | Palantir Foundry/AIP | 本体驱动的跨源因果推理 |
| 3 | Agent 平台 | OpenAI Codex（2026-07-09 起并入新版 ChatGPT 桌面端）、Anthropic Claude Code/Agent SDK、微软 Copilot、OpenClaw | 自主性、可靠性、治理机制 |
| 4 | 开源 Agent 框架 | LangGraph、CrewAI、AutoGen | 工程质量层：自主性机制、错误恢复策略、多 Agent 协调协议 |
| 5 | 组织诊断/员工体验 | Culture Amp、Glint、Lattice、Qualtrics | 让 HR/老板看懂的组织健康仪表盘 |
| 6 | SMB 生意工具 | 有赞/微盟/生意参谋、飞书/钉钉、金蝶/用友 | 上手时间、价格、续费模式 |
| 7 | 老板心智里的真实参照系 | 盛和塾、长松咨询、昆仑定位、和君咨询、行动教育（605098.SH，唯一上市培训公司） | 他们花过钱、有对比锚点的服务长什么样 |
| 8 | 增长方法论 | 麦肯锡增长三层面、安索夫矩阵、第二曲线 | 增长导航的理论标尺 |

**"最强机制"统一定义**：该对象在六维度中得分最高的那一层，不用主观判断。

## 五、方法细则

1. 推导顺序：对标证据 → 抽象维度 → 信任视角补充 → 第一性原理验证完备性
2. 双轨制刻度：每个标准保留"通用世界级"参照刻度 + SMB 重定义值；演示话术："麦肯锡的标准是 X，我们在 SMB 市场把它重新定义为 Y，原因是 Z"
3. 证据强度分级：强（官方/代码/一手）/ 中（权威二手）/ 弱（行业文章）/ 推测（不入报告）
4. 证据过时边界：重大产品变更即时标注；静态数据超 12 个月未复核即标"证据过时"
5. 量化判定：0/1 或数值区间，禁止模糊词；答不出三值就标"数据真空"，不硬编
6. A线消费边界：第三章只消费 A线审计结论，不重新审计
7. 无 IT 支持约束：部署独立标准 = "双击 exe、下一步下一步、不打开命令行"
8. 对抗性验证：差距清单经受"老板三刀"（比麦肯锡的深度、比 Palantir 的数据、比免费 AI 的价格）
9. 分治边界：发现①最强机制判断被新证据推翻 ②维度失效需重构 ③重大外部事件 → 暂停章节，同步创始人
10. 定义冻结：C线期间维度定义冻结；发现维度缺陷 → 暂停确认后统一修订

## 六、研究任务分章

- 第一章 对标证据库：8 类对象 × 最强机制 × 证据条目（来源+日期+强度+原文数字）
- 第二章 标准维度框架：从第一章机制抽象共性 + 信任建立视角 + 第一性原理完备性验证 → 六维度 × 三值结构 × 时间横切标准定义（与第一章并行迭代）
- 第三章 Synova 现状评估：消费 A线四条件审计 + 代码/文档核对，六维度逐标准打标（不自创数字）
- 第四章 SMB 市场标准重定义：无 IT 支持约束 + 老板参照系 + 双轨制三值推导（≥5 个被重定义的标准，每个带推导链）
- 第五章 差距清单、路线图与对标弹药：差距 → P0/P1/P2 → 反哺 A/B 线；对标弹药 = 演示开场预埋版（含预埋点，落回 B线剧本分钟级位置）

## 八、定量验收标准

1. 对标矩阵：8 类对象 × 六维度，每格有证据（强/中）或明确"数据真空"；开源框架类每对象 ≥3 条强级证据
2. 每个标准：三值结构完整（通用刻度/SMB 值/差异推导），缺一不算完成
3. 时间横切标准 ≥4 项（首次价值时间/诊断周期/模型校准周期/反馈→规则闭环时间）
4. 信任建立维度 ≥3 项（价值第一印象/闭环验证/制衡机制）
5. SMB 重定义标准 ≥5 个，每个带推导链
6. Synova 差距：六维度每维 ≥3 个可量化差距（全部源自 A线/代码核对，不自创）
7. 对标弹药：含 ≥3 个预埋点（对应 B线剧本分钟级位置）
8. 推测级结论零进入正式报告

## 十、局限

- SMB 市场缺少公开基准 → 重定义部分依赖第一性原理推导，推导与证据严格分界
- 定位表述（传统软件给人看 vs 未来软件给 Agent 用）尚未定稿，第四章引用时标注"待定稿"
