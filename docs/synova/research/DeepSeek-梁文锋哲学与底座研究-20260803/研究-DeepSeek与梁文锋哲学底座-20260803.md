1. **项目定位**：Synova 默认构建在 DeepSeek 之上（API + 本地部署双路径），agent 配置默认 DeepSeek API（按任务性质分配 token 预算 200-500 元/人/月）

## 三、产品哲学与 AGI 路线图

### 3.1 阶梯论：CoT → Agent → 持续学习 → 奇点 → 具身

```
2025 思维链(CoT) → 2026 Agent → 持续学习 → 自我迭代奇点 → 具身智能
```

| 阶梯 | 实录条号 | 原文要点 |
|------|:---:|---------|
| 思维链是上一阶梯 | 18-19 | "去年走的阶梯是思维链……今年的阶梯是 Agent，Agent 用到 CoT，CoT 用到语言模型，没有一步白走" |
| Agent 是今年主线 | 19/96 | "用 Agent 方式能力范围更大、智能上限更高""全力做通用 Agent，CodingAgent 现阶段最重要" |
| **持续学习是下一步** | 17/20/32-34 | **"AI 并不能替代你的员工。但如果 AI 具有持续学习的能力，它跟你的员工一样，到公司学习两个月，就可以替代天下的人，所以我们离下一步还差一个持续学习"**；"下一代模型的核心能力必须要有持续学习" |
| 奇点是渐进不是突变 | 21-22 | 持续学习后"能自己开发自己的版本"，"是长渐变，不是突变" |
| 具身是最后一步 | 23-24/30-31 | "先解决持续学习，再自我迭代奇点，再具身智能——后面可以用前面的技术开发后面的" |
| 只做主线 | 25-28 | 不做 3D/视频生成（"跟智能主线没关系"）、不追世界模型（"现在最重要的不是世界模型，是 AI 训练和持续学习"） |

### 3.2 对"智能"的判断

- **AI 不缺品位和直觉，缺持续学习**（条 115）："你让它写个文章，它的品位和直觉没有问题"
- **Scaling 没有到头**（条 58-60/86）："语言模型 Scaling 我没看到上限""硅谷说 Scaling 到头，对中国人来说我们离那个还很远"
- **数据=模型一半**（条 105-109）："数据几乎等于模型的一半"；标数据瓶颈是时间不是钱
- **幻觉可解**（条 110）："可以通过更好的 Post-training 解决"
- **AI 加速 AI 研究**（条 29）："AI 可以加速 AI 研究，不是线性的，到后面可能是非线性的"

### 3.3 竞争观

- 最终差距只有三个：**成本、时间、用户体验**（条 75-76）
- "拿得多的人会被拿得少的人打败"（条 78）——成本是第一位差异
- 中国角色=产量最大、价格系统性便宜（条 73-74/80）
- 大模型公司会收敛，不需要那么多家做基模（条 45/82）

### 4.3 Harness：持续学习的工程落点（与 Synova 关系最大）

- **梁文锋原话（36氪 2026-07-31）**："投资人看 Agent，我们看怎么解决学习。持续学习听起来是模型层面的命题，但它的工程落点，恰恰在 **Harness** 上"
- DeepSeek Agent Harness 团队 2026 年 3 月组建；Harness 规划与 V4 正式版同步推出；极简模式已在官方基准测试中使用，尚未公开
- 含义：**DeepSeek 把"Agent 执行框架（Harness）"视为持续学习的第一落点**——即"让模型在任务轨迹中学习"，而不是等模型训练层面的突破

### 4.4 持续学习研究实例

- DeepSeek 研究员陈德里（Deli）论文两弹，聚焦 **continual learning + self-iteration**：
  - 第一弹（2026-05）：DeliAutoResearch SKILL，自主科研智能体框架，人类只动脑 2 小时、6 天迭代 6 次完成综述
  - 第二弹（2026-05-31）：三轴统一分类框架、五类方法系统分析、形式化自我改进收敛条件、六大开放挑战；L1-L5 自主分级体系
  - 论文约 99% 工作量由 DeepSeek-V4-Pro 承担（arXiv 不允许 AI 列作者，移至脚注）——"AI 加速 AI 研究"的实证

### 4.5 芯片与部署

- V4（2026-04）已适配**华为昇腾**架构；梁文锋称华为 950 完全平替 GB200/GB300、已获取 16000 张 950 芯片
- V3 训练已不用英伟达生态（自研 TileLang 编译器）
- 战略含义：DeepSeek 走向国产算力，且开源模型内外一致——本地部署路径长期成立

## 五、对 Synova 的适配启示（核心章节）

### 5.1 模型路由：能力模型 / 生产模型分工（直接落地）

DeepSeek 官方已按"Pro=能力上限、Flash=高频生产"分工，这与 Synova 的任务结构天然匹配：

| Synova 任务类型 | 推荐路由 | 理由 |
|----------------|---------|------|
| 哨兵定时检测、简单测量、日常对话、数据清洗 | **V4-Flash** | 高频低成本；13B 激活；1 元/2 元；2500 并发 |
| 六阶段诊断中的根因推理、专家交叉验证、深度报告 | **V4-Pro**（或 Flash+提高思考预算） | 能力上限场景；量少价高可接受 |
| 复杂 Agent 任务长轨迹（诊断→证据→报告） | Flash 为主 + Pro 关键节点 | DeepSeek 自己的哲学：绝大多数步骤用便宜快速模型，关键步骤用强模型 |

> 落地建议：Synova 增加**模型路由配置层**（按循环/任务类型分路由），把"每个任务几十次调用"的成本放大效应压下来——这正是 V4-Flash 存在的意义。

### 5.2 峰谷定价 → 定时循环的调度优化

- DeepSeek 2026-08 起峰谷定价（高峰 2 倍）——Synova 的 Cron 哨兵/夜间批量任务可调度到低谷时段
- 建议：`loop-scheduler` 增加"成本窗口"约束——快循环避开高峰，中/慢循环默认低谷执行
- 这是"深度适配"里立即可做的工程项（研究建议，排期归开发）

### 5.3 持续学习：从梁文锋命题到 Synova 的进化能力

- 梁文锋（条 17）：**"就差一个持续学习；有持续学习，Agent 就能替代大多数人的工作"**
- Synova 的反馈→规则闭环（N13）、GA 纠错回流、知识沉淀、组织记忆——就是**企业场景的持续学习工程近似**（模型层持续学习尚未到来，Synova 用 Harness/知识层先做到"企业级持续学习"）
- C线 S5-1/T-3（P0-block）修复的意义升级：**这不是一个普通缺口，是 Synova 兑现"Agent 越用越懂企业"承诺的关键路径**——与 DeepSeek 的 AGI 主线同构
- 演示话术可用（不越红线版）："DeepSeek 说 AI 现在缺的是持续学习。我们在企业场景先把它工程化了——系统记得上个月的结论，下次诊断带着上次的知识来"

### 5.4 Harness 印证：Synova 的 Loop Engineering 方向正确

- 梁文锋：持续学习的工程落点在 Harness。Synova 的 Loop Engineering（6 循环×3 尺度）、控制塔、GA 回流、契约门禁——就是**企业级 Harness 工程**
- 这意味着：我们之前基于自身工程教训建的控制塔/Loop 体系，与 DeepSeek 官方判断的"Agent 下一步关键"方向一致——研究上获得外部锚点
- 未来研究点：DeepSeek Harness 公开后，做"Harness vs Synova Loop 工程"对标（可并入 C线维度 5 进化能力的证据库）

### 5.5 垂直 Agent 定位：机会窗口与护城河

- 梁文锋（条 96）："垂直 Agent（金融、医生）优先级更低，现阶段最重要的是 Coding Agent"
- **对 Synova 是机会窗口**：DeepSeek 明确不优先做企业诊断类垂直 Agent——底座+通用层它做，**企业诊断的深度（42 边本体、专家体系、行业模板、企业数据）是 DeepSeek 不会做的**
- **风险与应对**：DeepSeek Harness 通用层未来可能提供"企业 Agent 脚手架"——Synova 的护城河必须是**企业因果本体（42 边）+ 企业数据沉淀 + 行业模板 + GA 人机闭环**，这些不在底座公司的路线上
- 一句话定位（未来演示可用）："DeepSeek 造发动机，我们造'企业增长医生'这辆车——发动机是它的，方向盘、仪表盘和驾驶方法论是我们的"

### 5.6 成本哲学同构：定价方法论的互证

| 维度 | 梁文锋（DeepSeek） | Synova（C线 R7） |
|------|------------------|-----------------|
| 定价原则 | 合理利润，十个月回本 | 6-15 万/年建议带，锚定员工年薪/研修价 |
| 价格观 | 价格降到 1/4，用户更多 | 下界 5 万（"低于则显得不值"） |
| 竞争观 | 成本是第一位差异 | "花 1/2 个错误决策的钱买一个不犯错的系统" |
| 结论 | 便宜是系统性能力，不是营销 | 单位价值最高，不是最贵 |

> 启示：Synova 的定价推导与底座公司的成本哲学一致——底座持续降价=Synova 毛利空间扩大，可将"DeepSeek 成本下行"纳入 C线经济模型的长期假设。

### 5.7 开源与本地部署

- 最强模型开源、内外一致（条 99-104）→ Synova 无底座锁定风险；API 与自部署可选
- V4 适配华为昇腾 → 客户数据敏感场景的国产算力本地部署路径成立（C线 S3-3 权限安全的远期选项）

### 5.8 上下文与组织记忆

- V4 支持 100 万 token 上下文 → Synova 的企业事实库、历史诊断、知识沉淀可以更完整地进入上下文——组织记忆（S5-4）的实现条件比之前更成熟
- 建议：研究 S5-4 时把"长上下文+知识层"双路径都纳入（RAG 之外增加长上下文直读）

### 5.9 克制与聚焦：从梁文锋到我们的研究纪律（2026-08-03 创始人指示）

- 梁文锋（条 116）："AI 很大，我只做一块"；"AI 时代会产生很多家万亿级公司，我们是其中一家"（条 25-28：只做主线，不做与智能主线无关的事）
- **Synova 应用（创始人明确）**：传统培训-咨询（盛和塾/长松/昆仑/和君/行动教育）**不在我们的赛道上**——了解它们只为读市场（付费带、老板心智锚点），不深挖、不扩展、不对标竞争；研究预算聚焦 Synova 主线：**企业增长诊断 Agent 的世界级缺口**
- 判定问题（研究立项前自问）："这件事是帮助 Synova 成为世界级的企业增长 Agent，还是在追逐市场噪音？"——与主线无关的参照物研究一律降级为"了解即可"
