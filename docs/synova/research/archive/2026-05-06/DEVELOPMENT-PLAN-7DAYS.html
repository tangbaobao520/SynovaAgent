⚠️ 核心原则（阅读本文档前必读）
  1. 接线验证是硬门禁 — 每个模块写完后必须 grep 确认被生产代码引用。Claude Code 历史上 6 次接线失败（见 CLAUDE.md 铁律 1-7）。不接线 = 没完成。
  2. 测试先行 — spec → test → impl → verify → wire → commit。跳过测试直接写代码 = 禁止。
  3. 逐项 commit — 每个独立功能单独 commit，不批量提交。commit message 必须 Conventional Commits 格式。
  4. tsc --noEmit + vitest run 全绿 — 每次 claim "完成" 前必须跑。零失败。
  5. 不假设上下文 — 每个任务开始前先读当前代码状态，不靠记忆。
🤖 Claude Code 工作模式
• 每个 Day 是独立的工作流，尽量并行执行独立任务
• 使用 Agent（子代理）并行处理不相关的模块
• 有上下游依赖的任务必须串行，不得并行
• 每天结束时：tsc + vitest + iron-laws 三道门禁通过后才能声称"当天完成"

TS 侧：

// src/providers/python-bridge.ts
export class PythonBridge {
  private pythonPath: string;

  async run<T>(module: string, command: string, params: unknown): Promise<T> {
    const proc = spawn(this.pythonPath, ['-m', `synova_worker.${module}`], {
      stdio: ['pipe', 'pipe', 'pipe'],
      timeout: 30_000,
      env: { PYTHONUNBUFFERED: '1', ...process.env },
    });

    const input = JSON.stringify({ command, params, requestId: crypto.randomUUID() });
    proc.stdin.write(input + '\n');
    proc.stdin.end();

    let output = '';
    for await (const chunk of proc.stdout) output += chunk;

    const result = JSON.parse(output);
    if (!result.success) throw new Error(result.error?.message || 'Python 进程错误');
    return result.result;
  }
}

Python 侧：

# synova_worker/__init__.py
import sys, json, importlib

def main():
    line = sys.stdin.readline()
    request = json.loads(line)
    try:
        module = importlib.import_module(f"synova_worker.{request['command'].split(':')[0]}")
        handler = getattr(module, f"handle_{request['command'].replace(':', '_')}")
        result = handler(request['params'])
        print(json.dumps({"requestId": request["requestId"], "success": True, "result": result}))
    except Exception as e:
        print(json.dumps({"requestId": request["requestId"], "success": False, "error": {"code": type(e).__name__, "message": str(e)}}))

if __name__ == "__main__":
    main()

from synova_worker.sog import SOGNodeType, SOGEdgeType

def map_members_to_sog(members):
    nodes = []
    edges = []
    for m in members:
        # Person 节点
        node_id = f"feishu_person_{m['id']}"
        nodes.append({"id": node_id, "type": "Person", "props": {
            "name": m["name"], "email": m.get("email"),
            "source": "feishu", "sourceId": m["id"]
        }})
        # Team 节点（部门）
        if m.get("department"):
            team_id = f"feishu_team_{m['department']}"
            nodes.append({"id": team_id, "type": "Team", "props": {
                "name": m["department"], "source": "feishu"
            }})
            # BELONGS_TO 边
            edges.append({"type": "BELONGS_TO", "from": node_id, "to": team_id})
    return {"nodes": nodes, "edges": edges}

import { pinyin } from 'pinyin-pro';

function phoneticSimilarity(nameA: string, nameB: string): number {
  const pyA = pinyin(nameA, { toneType: 'none' }).join(' ');
  const pyB = pinyin(nameB, { toneType: 'none' }).join(' ');
  const dist = levenshteinDistance(pyA, pyB);
  return 1 - dist / Math.max(pyA.length, pyB.length);
}

🚨 Claude Code 专属纪律

AI 开发的 5 条铁律（附加于 CLAUDE.md 已有的 40 条之上）

  1. 用完即弃 — 每个子代理完成自己的任务后立即返回，不跨任务保持状态。下一个任务重新读文件。
  2. 批量写入限制 — 单次 Write 调用不超过 200 行。超过的拆分为多个 Write。防止截断 CJK 内容（历史教训：6 次）。
  3. 接线验证自动化 — 每个任务完成后的最后一步必须是 grep 命令验证接线。人类无法每次都检查，但 grep 可以。
  4. 测试不 mock 管线 — 集成测试必须 hit 真实 SQLite、真实 Express 路由。铁律 22（测试前目标确认）是硬门禁。
  5. 并行上限 — 最多同时运行 3 个子代理。超过 3 个时，人类（你）需要确认不会冲突。

每日开工仪式

  1. git pull --rebase（确保最新）
  2. npx tsc --noEmit（确保零编译错误）
  3. npx vitest run（确保全绿）
  4. 读 docs/research/DEVELOPMENT-PLAN-7DAYS.html 今日任务
  5. 开始今日第一个任务前，确认上游依赖已全部完成
