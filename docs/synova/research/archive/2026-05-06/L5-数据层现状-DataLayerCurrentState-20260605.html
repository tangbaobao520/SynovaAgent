二、数据流（已接通）

触发方式（2 种）：
  POST /api/connector/sync             ← 手动触发
  定时器每 30 分钟自动同步              ← 自动触发

数据流：
  触发 → ConnectorPipeline
    → Python Bridge (子进程)
    → Python 连接器 (feishu.py)
    → OntologyEvent[]
    → OntologyEventBus
    → GraphStore (SQLite)

安全层（每步都有）：
  Python 子进程隔离（临时目录 + 30s 超时）
  CredentialVault 解密（AES-256-GCM）
  FileGuard 文件安全（三层拒绝列表）
  ConnectorAuditLog 审计（SQLite append-only）
  PIIScrubber 脱敏（4 级敏感度, S1-S4）

缺少的安全层：
  ❌ SQLite 加密存储
  ❌ 日志脱敏（RedactingFormatter）
  ❌ 输入脱敏中间件（sanitize-check）
