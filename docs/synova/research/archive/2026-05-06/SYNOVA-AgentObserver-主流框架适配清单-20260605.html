Agent Observer 适配清单

用户决定监测哪个 Agent，就在那个 Agent 上装 observer · 2026-06-05

一、MCP 原生——零适配，配置即可

Synova 作为 MCP Server 注册到 Agent 的配置文件中。Agent 启动时自动连接。

框架厂商配置文件位置配置示例
Claude CodeAnthropic~/.claude/settings.json"mcpServers": { "synova": { "command": "npx", "args": ["@synova/mcp-observer"] } }
ClineOpen Sourcecline_mcp_settings.json同上
ContinueContinue Devconfig.json同上
WindsurfCodeium~/.windsurf/settings.json同上
CursorAnysphere~/.cursor/mcp.json同上
GitHub CopilotMicrosoftVS Code settings同上
OpenClawNous Researchopenclaw.json同上
GooseBlock~/.config/goose/config.yaml同上
GenkitGoogleMCP 原生支持同上
Vertex AI Agent BuilderGoogleMCP 原生支持同上

需要开发的：一个 MCP Server（TypeScript），Agent 启动时 Synova 感知到连接，创建 SOG AGENT 节点。

四、优先实现顺序

优先级框架理由
P0OpenClaw 生态（含国内封装版）最大装机量，已有 agent-end 钩子
P0Claude Code / Cline / ContinueMCP 标准，配置即可，零代码
P1LangChain / CrewAI / AutoGen / OpenAI SDK开发者常用，一行代码接入
P1HermesPlugin 系统，有源码参考
P2Cursor / Windsurf / CopilotIDE 类 Agent
P2Coze / 百度 / 通义智能体国内平台，需调 API
P2Bedrock / Vertex云厂商，需对接日志

五、产品形态

synova-observer/
├── README.md
├── mcp-server/          ← 覆盖 10 个框架（配置即用）
├── openclaw-skill/      ← OpenClaw 生态（clawhub install）
├── langchain/           ← Python 框架（pip install）
├── hermes-plugin/       ← Hermes
└── core/                ← 公共上报逻辑
    ├── collector.py
    ├── reporter.py      ← HTTP 上报到 Synova
    └── schema.py        ← 统一数据格式

用户装哪个 Agent，就在那个 Agent 上装对应的 observer。装好后数据自动流入 SOG，6 个专家自动能分析。
