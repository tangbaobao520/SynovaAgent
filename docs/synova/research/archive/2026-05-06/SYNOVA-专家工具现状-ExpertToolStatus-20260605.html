四、根因：ExpertAutonomyEngine 不调用专家工具

系统 A：ToolRegistry（统一工具注册中心）
  注册 24 个工具 ← builtin-tools ← src/tools/*-expert-tools.ts
  其中有 3 个能真正调 ontology API
  → 但 ExpertAutonomyEngine 不使用

系统 B：ExpertAutonomyEngine.executeQuery()
  switch(functionName) {
    'findDiagnosticPaths'      → 硬编码参数 ('Risk', 'Person')
    'summarizeSubgraph'        → 硬编码参数 ('root', 3)
    'findCrossDimensionalBrokers' → 无参数
    'match_pattern'            → 硬编码空数组 []
    default → 返回错误
  }
  → 不调用任何 src/tools/ 下注册的工具

两条系统并行存在，互不感知。
修复办法：ExpertAutonomyEngine 的 executeQuery() 改为调用 ToolRegistry.execute()。
