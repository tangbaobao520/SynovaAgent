📌 核心思路

Synova 不需要自己开发所有工具。优先使用现成的 MCP Server 和可信大厂 Skill。

  • MCP Server → 直接集成到 ToolRegistry，给专家 Agent 调用
  • 大厂 Skill（券商/36氪等）→ 云鼎审计后，提取知识注入专家 PKB
  • 社区 Skill → 必须过云鼎审计，Malicious 拒绝，Suspicious 只提知识
  • 自建工具 → query_sog_graph 等无法从生态获得的，需要自己开发

一、已安装的 MCP Server

Server路径用途对接专家
Brave Searchvendor/mcp-servers/brave-search行业搜索、竞品信息战略/市场/全部
GitHubvendor/mcp-servers/github代码仓库分析(46工具)技术

安装方式：npm install 到 vendor/mcp-servers/，npm 自带完整性校验。

安全风险：3 个 high 漏洞在 @modelcontextprotocol/sdk（ReDoS + DNS 重绑定），无修复。缓解：所有 Server 在子进程中运行，受 Python Bridge 沙箱保护。

三、Skill 来源与处理方式

3.1 可信大厂 Skill（优先于社区）

来源内容处理方式
36氪（3 个官方 Skill）24h 热榜、融资报道、AI 测评提取知识 → 市场专家 PKB
中金/华泰/广发等券商研报解读、行情分析、选股分析云鼎审计 → 提取分析框架 → 财务/战略 PKB
国泰海通投研能力、数据模型同券商

策略：大厂 Skill 可信度较高，但仍需过云鼎审计。审计通过后直接按需提取知识注入专家 PKB，不执行社区脚本。

3.2 社区 Skill

  • 必须先过云鼎 7 步审计
  • Malicious（0-30 分）→ 拒绝
  • Suspicious（31-75 分）→ 只提取 SKILL.md 知识，不执行脚本
  • Benign（76-100 分）→ 正常使用
