Hermes + Claude Code + Synova 三方对比 · 2026-06-05

结论：Synova 的工具格式（ToolDefinition + toOpenAITools）是正确的

三个系统都使用 OpenAI function calling 格式。但 ExpertAutonomyEngine 不使用标准 function calling——它用自己的手写 JSON 解析 + 硬编码 switch-case。修复就是让专家 Agent 走标准 tool_calls 路径。

三、ExpertAutonomyEngine 的问题

当前 ReAct 循环的 LLM prompt 要求输出自定义 JSON：

输出 JSON: {"thought":"...","action":"query_graph"|"finalize","function":"...","hypothesis":"...","confidence":0.0-1.0}

解析后走硬编码 switch：

switch(functionName) {
  case 'findDiagnosticPaths'  → queryApi.findDiagnosticPaths('Risk', 'Person')   // 参数固定！
  case 'summarizeSubgraph'    → queryApi.summarizeSubgraph('root', 3)              // 参数固定！
  case 'findCrossDimensionalBrokers' → queryApi.findCrossDimensionalBrokers()    // 无参数
  case 'match_pattern'        → queryApi.matchPattern([])                          // 硬编码空数组
  default → 返回错误
}

三个问题：

  1. 不是标准 function calling——LLM 输出 JSON 文本再解析，不是 tool_calls 结构化格式
  2. 参数硬编码——专家不能决定查什么，只能查 4 种固定模式
  3. 不调 ToolRegistry——src/tools/ 下注册的 24 个工具全部闲置

四、修复方案

目标：ExpertAutonomyEngine 走标准 function calling 格式，通过 ToolRegistry 调用工具。

修改前：
  LLM 输出自定义 JSON → parseResponse() → switch(functionName) → 4 种固定查询

修改后：
  LLM 输出标准 tool_calls → toolRegistry.execute(name, params) → 任意注册工具

4.1 替换 executeQuery()（核心改动）

// src/l3/expert-autonomy.ts — 修改 executeQuery 方法

private async executeQuery(functionName: string, args: string): Promise<unknown> {
  // 改为调 ToolRegistry，而不是硬编码 switch
  const result = await this.toolRegistry.execute(functionName, JSON.parse(args));
  return result;
}

4.2 修改 ReAct 循环的 LLM prompt

// 当前（自定义 JSON 格式）：
`输出 JSON: {"thought":"...","action":"query_graph"|"finalize","function":"...","hypothesis":"...","confidence":0.0-1.0}`

// 修改后（标准 function calling——LLM 自动生成 tool_calls，不需要手写指令）：
// 只需传 tools 参数给 LLM，LLM 自动决定调用哪个工具

4.3 工具调用循环改为标准流程

// src/l3/expert-autonomy.ts — 修改 run() 方法

// 当前：
const response = await this.llm.consult(systemPrompt, context, { temperature: 0.3 });
const parsed = this.parseResponse(response.content);
if (parsed.action === 'query_graph') {
  const result = await this.executeQuery(parsed.function);
}

// 修改后：
const tools = this.toolRegistry.toOpenAITools();
const response = await this.llm.consult(systemPrompt, context, { temperature: 0.3, tools });
if (response.toolCalls?.length) {
  for (const tc of response.toolCalls) {
    const result = await this.executeQuery(tc.function.name, tc.function.arguments);
  }
}
