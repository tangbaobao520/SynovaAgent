# 第一章 模块一：AI 发展史与 Agent 时代（25 分钟）

## 目的

让员工建立一条清晰的主线：**AI 的历史 = 知识的载体不断更换，每一次更换，'会干活的主体'就换一次。** 最终落点：Agent 是第一个"会干活"的 AI，而它的下一站在梁文锋的路线图里已经画出来了。

## 脚本

### 第一段：60 年压缩史（4 分钟）

【讲】"AI 1956 年出生，前 60 年都在'读书'：
- **规则时代（1950s-1980s）**：知识 = 程序员写的规则。专家系统能看病、能找矿，但换个场景就失灵。后来泡沫破了，就是著名的'AI 寒冬'——冰封了十几年。
- **数据时代（2010s）**：知识 = 数据。2012 年 AlexNet 在图像识别上碾压人类方法，2016 年 AlphaGo 赢李世石——但它只会'想'，不会'做'。
- **语言时代（2022 起）**：知识 = 语言。ChatGPT 让全世界第一次和机器说话。但还是'会说话'。
- **行动时代（2024 起）**：知识 + 工具 + 行动 = **Agent**。它第一次不是回答问题，而是**接受委托、制定计划、调用工具、交付结果**。

【互动 0:04】"谁能猜到，AI 从'会说话'到'会干活'，中间差了什么？……（引导回答：工具）对——**手**。过去的 AI 只有大脑，没有手；Agent 第一次有了手。"

【幽默 0:04】"就像一个孩子读了二十年书，突然从书桌前站起来，开始帮你干活——虽然他偶尔还会把活干砸。"

### 第二段：Agent 的完整解剖——四个抽屉，十三个概念（13 分钟）

【讲 0:04】"Agent 不是玄学。把它拆开看，就是一个'会干活的实习生'的完整构造。我把它装进四个抽屉：**身份、能力、运行、治理**。每个概念，我都用我们熟悉的 OpenClaw 和 Synova 的真实例子讲。

**抽屉一：身份层——它是谁**
1. **人格**：岗位说明书 + 文化手册 + 业务知识。OpenClaw 的每个 Agent 都有身份配置；我们 Synova 的 7 位专家各有一份 IDENTITY/RULES/THEORY——每个 Agent 知道'我是谁、我的边界、我按什么准则干活'。**没有人格的 Agent 不可靠，有人格的 Agent 可追责。**
2. **配置文件**：把老师傅的隐性经验写成文件——可复用、可传承、可审计。我们公司的 AGENTS.md、专家 RULES.md、playbooks 就是这门手艺。**配置 = 组织知识的资产化。**（互动：最会处理客诉的老员工离职，经验还在吗？配置就是让他'人走经验留下'。）

**抽屉二：能力层——它会什么**
3. **工具（Tools）**：读文件、执行命令、调 API——Agent 的'手'。没有手，它只会说不会做。
4. **技能（Skills）**：可复用的专业动作包，像员工培训后拿到的技能证书。OpenClaw 用技能扩展能力，Synova 内置 41 个技能。
5. **MCP**：模型连接世界的'USB 口'——让 Agent 读你的系统、调你的工具、写你的数据。2024 年 11 月 Anthropic 发布，现在已被行业广泛采用。

**抽屉三：运行层——它怎么干活（Agent 时代的新物种）**
6. **工作方式（ReAct 循环）**：思考→行动→观察→再思考（2022 年 Yao 等人的论文，现在所有 Agent 的默认姿势）。不是一问一答，是**边想边干边看结果**。
7. **定时任务（Cron）**：到点自动执行。注意，这是关键对比——**传统软件也有定时任务**：Windows 计划任务、服务器 cron，但它只是到点执行一条固定命令，不判断、不变通。**Agent 的 cron 是到点唤醒一个会思考的行动者**：它自己看数据、做判断、采取行动、汇报结果。OpenClaw 用它跑每日报告、每周复盘；Synova 的哨兵用它做定时体检。
8. **心跳（Heartbeat）**：Agent 独有的'生命体征'。**传统软件不主动干活，所以不需要心跳。Agent 是自主运行的，主人必须知道：它还活着吗？在忙什么？有没有卡住？需要我决策吗？** OpenClaw 默认每 30 分钟做一轮心跳，批量检查收件箱、日历、通知；Synova 的循环调度器有 heartbeat.json，每天检查哪些循环'停滞'了——Agent 卡住，系统自己会报警。
9. **钩子（Hooks）**：事件触发的自动化——会话重置、工具调用前拦截、门禁检查。OpenClaw 有 hooks，Synova 有 PreToolUse/PostToolUse hooks——**像安全员，每次动手前拦一下检查**。

**抽屉四：记忆与治理层——它记什么、守什么规矩**
10. **记忆（Memory）**：短期上下文 + 长期知识库。OpenClaw 有 memory，Synova 有记忆层——它记得'上次聊到哪、这家公司的规矩'。
11. **权限与沙箱**：能做什么、不能做什么——审批、允许列表、写锁。OpenClaw 有 allowlist，Synova 有写锁和权限体系。**自主越强，边界越要硬。**
12. **审计（Audit）**：做了什么、为什么——任务记录、审计日志。出了事能回溯。
13. **协作（多 Agent）**：子代理分工、编排器调度。OpenClaw 有 subagents，Synova 有子代理体系。"

【互动 0:11】"你们发现没有：工具、技能、MCP——这些像'手'和'工具包'，还算熟悉。但 **cron 和心跳——定时任务和生命体征——是 Agent 之前不存在的物种**。传统软件是'你叫它才动'，Agent 是'它自己醒、自己干、自己汇报'。这就是'会干活'和'会说话'的分水岭。"

【幽默 0:12】"把 Agent 比作员工：人格是工牌，配置是入职手册，工具是工位电脑，技能是培训证书，MCP 是公司系统接口，cron 是排班表，心跳是每天早上的例会汇报——钩子呢，是门口那位保安。传统软件的定时任务像闹钟：响完就完。Agent 的 cron 像 CEO：到点自己开晨会、看报表、下指令、等你验收。"

【讲 0:14】"解剖完这 13 个零件，回到你们每天都在用的东西：免费的 DeepSeek App、豆包 App——**它们和 Agent 到底差在哪？**

一句话：**那些 App 是'顾问'，Agent 是'员工'。**

- 免费 App **失忆**：每次对话基本从零开始，关了窗口就忘——它没有你的上下文，没有记忆
- 免费 App **没有手**：只能在对话框里说话，不能读你的文件、查你的系统、改你的表格
- 免费 App **被动**：你问它答，聊完即散——它不会半夜醒来帮你干活
- Agent **记得**：有记忆和完整上下文——你的公司、历史决策、知识库
- Agent **有手**：工具、技能、MCP——能读系统、调接口、写数据
- Agent **主动**：cron 定时干活、heartbeat 心跳汇报、干完跟你汇报
- Agent **有规矩**：配置边界、权限、审计——干了什么可回溯

这不是我们编的。Anthropic（Claude 的公司）对 Agent 的工作定义就是：**'一个在循环中使用工具完成目标、自己决定何时完成的 LLM'**。行业里还有句更直白的：**聊天机器人是一次模型调用；Agent 是模型在循环里调用工具，直到任务完成。**"

【互动 0:16】"你们手机里都有 DeepSeek 或豆包吧？举手看看……好。今天回去做个实验：问它'我们公司上季度客户流失怎么回事'——它会给你一堆正确的废话。为什么？因为它不知道你们公司。**这就是 App 和 Agent 的差距：差一个'知道你是谁'的系统。** 免费 App 给你'答案'，Agent 给你'结果'——答案是一次性的，结果是持续的。"

### 第三段：梁文锋的路线图（4 分钟）

【讲】"梁文锋把 AI 的路画成阶梯（原话摘录）：
- #18：'去年的阶梯是思维链。'
- #19：'今年的阶梯就是 Agent……它的能力范围会更大，它的智能上限会更高。'
- #20：'在 Agent 之后，我们觉得应该要解决的问题是持续学习。'
- #21：'当模型能够持续学习之后，它已经能够做人类能做的所有事情了。它就能自己开发自己的版本，自己再研究……'
- #23：时间表——持续学习 → 自我迭代的奇点 → 具身智能（走进现实世界，给你做家务、给你养老）。"

【讲 0:18】"注意他说的是'阶梯'，不是'如果'。每一步都不是白走的（#19：'它并没有一步是白走的'）。**所以 AGI 不是会不会来，是路线图已经画出来了，差的只是持续学习这一步。**"

【幽默 0:19】"持续学习难在哪？打个比方：你现在会骑电动车，现在让你学开飞机——你不会把骑电动车的技能忘掉吧？但神经网络会——它学新东西的时候，可能把旧的忘光，这叫'灾难性遗忘'。科学家从 1989 年研究到今天，还没完全解决。"

### 第四段：问题与诚实（4 分钟）

【讲】"说了这么多，泼三盆冷水，句句有出处：
1. **幻觉**：AI 会一本正经地胡说。梁文锋 #110：'幻觉问题……是一个能解、能够改善的问题'——能改善，不能消灭。
2. **不会持续学习**：#17/#33：现在 Agent 能力受限，因为它不能有效地持续学习。
3. **依赖完整指令**：#16：'你能够把一个问题描述得很清楚，给它完整的上下文和指令，它已经超过人类了。'——注意前提：**你得会描述问题。**

【互动 0:23】"梁文锋还有一句总结（#115）：'AI 现在不缺品位和直觉，它缺的是持续学习的能力。'——它能写漂亮文章、能讲漂亮话，但还没法像人一样到公司学习两个月。所以现在 AI 靠谱吗？大部分不靠谱——包括我们自己的。但正因为不靠谱，才需要方法。还有一个概念没讲：Agent 的'自我进化'——从反馈里修正自己的规则。**这是当前最大的缺口**，也是梁文锋说的'差一个持续学习'的另一种说法。下一个问题：如果 AI 是个不靠谱但有潜力的实习生，**你该怎么用它？** 这就是模块二。"
