| Agent 运行概念：cron（精确调度/任务记录）、heartbeat（默认每 30 分钟批量轮次/完整上下文）、hooks（生命周期事件/工具调用拦截）、skills（技能扩展）、memory、subagents（多 Agent 协作） | OpenClaw 官方文档（docs.openclaw.ai/automation 等） |
| heartbeat vs cron 选择原则："输出留在人机之间→heartbeat；输出公开/需精确时刻→cron"；"Agent 控制执行，而不是时钟控制" | OpenClaw 文档 + 行业实践文章（2026） |
| Agent 运行时骨架（harness）：subagents（隔离）、hooks（确定性）、配置基座（skills/permissions/settings）、permissions 模式 | Claude Code / Agent SDK 文档（code.claude.com/docs，2026） |
| "Agent 是 LLM 在循环中基于环境反馈使用工具"（"Agents are typically just LLMs using tools based on environmental feedback in a loop"）；workflows = 预定义代码路径编排，agents = LLM 动态掌控自己的过程与工具使用 | Anthropic《Building Effective Agents》(2024-12-19, anthropic.com/engineering) |
| "聊天机器人≈一次模型调用，Agent≈循环调用工具直到任务完成"——业界通俗表述；原文依据：Anthropic"对许多应用，优化单次 LLM 调用通常就够了" vs Agent"循环中使用工具"；Agent SDK："评估提示→调用工具→接收结果→重复直到任务完成" | Anthropic《Building Effective Agents》+ Claude Agent SDK 文档（code.claude.com/docs/en/agent-sdk/agent-loop，2026） |
| 大模型默认寻找捷径：捷径学习（shortcut learning）是深度模型的系统性倾向——模型抄近路、抓表面特征而非真正理解任务 | Geirhos et al., "Shortcut Learning in Deep Neural Networks", Nature Machine Intelligence (2020) |
| 智能体的"走捷径/绕过/投机"行为：specification gaming（规范漏洞利用）与 reward hacking（奖励作弊）是智能体研究公认现象；前沿模型在压力下出现过试图绕过规则的行为 | Krakovna et al. (2020) "Specification Gaming: The Flip Side of AI Ingenuity"（DeepMind）；OpenAI o1 System Card (2024-12) |

## 五、引用纪律

1. 梁文锋语录一律按 PDF 条号引用，不改编原意
2. 业界通行判断（如"被会用 AI 的人替代"）标注为观点而非引用
3. 无法核实的内容不进入讲义，或标注"待核实"
4. 幽默/类比（电动车/飞机、传单/美团等）仅为教学辅助，不构成事实主张
