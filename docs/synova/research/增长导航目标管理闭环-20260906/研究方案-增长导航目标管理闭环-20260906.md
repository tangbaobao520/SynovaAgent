# 增长导航（企业目标管理闭环）研究方案 —— 最终版

> 2026-09-06 | 研究 session | 麦肯锡框架推导定稿
> 结论：导航 = 企业目标全生命周期管理系统，诊断是目标的一个来源（最重要，非唯一）

---

## 一、研究背景

Synova 两大模式：**诊断 + 导航**。导航是诊断出结论后，客户采纳 → 按部门/角色执行 → 跟踪 → 提醒 → 修正 → 验证回流的闭环，是区别于咨询公司（给结论就走）、传统软件（给数据不管执行）、通用 AI 助手（一问一答）的**最大差异化**。

导航不是空白：权威文档13（增长导航系统工程规范，2026-07-14）已定义 6 介入节点 + 5 章设计；代码已大量实现（goal-lifecycle 7 态状态机、goal-sentinel 三因子偏离检测、proposal-engine、workspace-builder 等）。

本次研究定位：**在权威文档13 地基上，用麦肯锡框架重新审视，把导航提升为"企业目标全生命周期管理"，并审计设计 vs 实现的差距。**

## 二、研究定位（回答什么 / 不做什么）

**回答**：导航（企业目标全生命周期管理）的完整设计——目标来源、分解对齐、执行跟踪、纠偏、验证回流、管理方式适配，含现状审计与 DSH 借鉴。

**不回答**：不重做诊断；不重新定义 Goal 数据结构（权威文档13 已有 28 字段）；不改代码（出报告 + 建议）。

## 三、核心模型（麦肯锡框架，5 个 MECE 维度）

**结论**：导航 = 企业目标全生命周期管理。诊断是目标最重要的来源，但不是唯一来源。

### 维度一：目标生命周期（时间维，8 环节，天然 MECE）

设定 Set → 分解 Decompose → 对齐 Align → 执行 Execute → 跟踪 Track → 纠偏 Correct → 验证 Verify → 回流 Learn

### 维度二：目标来源（3 类，MECE）

1. 诊断驱动（增长卡点 → 目标，有诊断追溯）
2. 决策驱动（老板直觉/经验 → 新方向 → 记录决策 → 目标，有决策追溯）
3. 外部驱动（市场变化/客户流失/竞争 → 目标）

### 维度三：目标对齐关系（3 类，MECE）

1. 纵向对齐（部门目标 ↔ 公司目标，父-子）
2. 横向依赖（部门目标 ↔ 部门目标，输入-输出，市场获客支撑销售转化）
3. 约束注入（目标 ↔ 企业事实，财务预算/资源/能力）

### 维度四：目标管理方式（4 类，MECE）

OKR / KPI / MBO / 无正式体系（Synova 默认 Goal）。原则：适配企业考核方式，不强加。

### 维度五：执行主体（3 层，MECE）

老板（决策+全局）/ 中层·部门负责人（执行+核查，最大用户群）/ 个人（具体任务）

## 四、研究问题（Q1-Q6）

- Q1 现状审计：权威文档13 的 6 节点设计 vs 代码实现，逐节点三态打标；重点 N13 断裂、middle-evolution 零调用、闭环验证、免打扰、GA 协同。
- Q2 与专家架构衔接：结论树（L1-L4）→ 目标来源；多岗位 → 执行主体；因果闭环"跟踪→验证"→ 导航本质。
- Q3 目标来源管理：诊断/决策/外部三来源，各自"记录 + 跟踪 + 回溯"。
- Q4 目标对齐 + 约束：纵向/横向/事实层约束注入，对齐检查 + 约束检查 + 冲突检查。
- Q5 目标管理方式适配：OKR/KPI/MBO/无体系，配置化适配。
- Q6 执行跟踪 + 验证回流：跟踪→纠偏→验证→回流（含 N13 修复优先级 + 越用越懂）。

## 五、研究任务分章（6 章 + 附录）

**第一章｜导航现状审计**：权威文档13 的 6 节点 + 5 章 vs 代码实现，三态打标（已实现/部分实现/断裂）；N13、middle-evolution、闭环验证、免打扰、GA 协同现状。

**第二章｜目标设定与来源**：Set 环节 + 3 来源（诊断/决策/外部）的"记录 + 跟踪 + 回溯"；决策驱动的"决策记录"机制。

**第三章｜目标分解与对齐**：Decompose + Align 环节 + 3 关系（纵向/横向/约束）的对齐检查 + 约束检查 + 冲突检查。

**第四章｜执行跟踪与纠偏**：Execute + Track + Correct 环节，提醒（P0/P1/P2 分级 + 免打扰）+ 轻量级再诊断 + 调整。

**第五章｜验证与回流**：Verify + Learn 环节，闭环验证 + N13 反馈→规则闭环 + 越用越懂（红线：不宣称自我进化）。

**第六章｜目标管理方式适配 + 权威统一 + 路线图**：4 适配方式（OKR/KPI/MBO/无）+ DSH 借鉴 + 术语 + 落地路线。

**附录｜证据清单**：权威文档13 设计点 vs 代码 file:line 证据索引。
