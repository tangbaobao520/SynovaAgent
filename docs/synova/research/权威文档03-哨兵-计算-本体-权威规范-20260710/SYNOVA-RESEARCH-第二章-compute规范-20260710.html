一、管理经济学10个新增compute（完整规范）

C1. computeBreakEven

字段内容
契约IDCOMPUTE-BREAK-EVEN-v1
功能盈亏平衡点: BEP=FC/(P-AVC)。多产品线时加权平均。P<AVC→BEP不存在
读取的42边E-13 CAPITAL_ALLOCATION(allocation_ratio→固定成本占比), E-23 OPERATIONAL_EXECUTION(efficiency_rate→单位变动成本代理)
可执行路径规范DiagnosisContextNode → ALLOCATES(E-13) → CAPITAL_POOL.allocation_ratio; → PRODUCES(E-23) → PRODUCTION.efficiency_rate。输入fixture: {fixedCost:100,price:10,avgVC:6,actualQ:25} → BEP=25, safetyMargin=0%, critical。边界: P≤AVC → degraded:true
输入/输出Input: {fixedCost,price,avgVariableCost,actualQuantity?} → Output: {bep,safetyMargin,degraded,warnings[]}
降级契约多产品线→加权平均+标注; P<AVC→degraded:true; 多产品无分产品线数据→使用企业级加权平均
关联哨兵sentinel-breakeven, margin-health
数据源等级A (ERP直接可得)
节点池归属CAPITAL_POOL(存量池), PRODUCTION(活动池)
statusNEW

C2. computeDOL

字段内容
契约IDCOMPUTE-DOL-v1
功能经营杠杆: DOL=CM/EBIT=(Revenue-VC)/(Revenue-VC-FC)。EBIT≤0→DOL无意义
读取的42边E-13 CAPITAL_ALLOCATION(allocation_ratio→FC), E-23 OPERATIONAL_EXECUTION(efficiency_rate→VC代理)
可执行路径规范DiagnosisContextNode → ALLOCATES(E-13)→CAPITAL_POOL.allocation_ratio; →PRODUCES(E-23)→PRODUCTION。fixture: {rev:1000,vc:400,fc:400}→DOL=3.0→高杠杆
输入/输出Input: {revenue,variableCost,fixedCost} → Output: {dol,warning_threshold_exceeded,degraded}
降级契约EBIT≤0→degraded:true, DOL标记为"不适用"; 利息费用单独处理(不含入FC)
关联哨兵sentinel-operating-leverage, margin-health
数据源等级A
节点池归属CAPITAL_POOL, PRODUCTION
statusNEW

C3. computePriceElasticity

字段内容
契约IDCOMPUTE-PRICE-ELASTICITY-v1
功能需求价格弹性: ED=ΔQ%/ΔP%。需至少3次PriceEvent。ceteris paribus前提
读取的42边E-30 PRICING(price_level,discount_depth)
可执行路径规范DiagnosisContextNode → SETS_PRICE(E-30) → PRICE_EVENT节点序列。fixture: 3次事件→ED≈0.7±0.3。边界: <3次事件→degraded,标注置信区间
输入/输出Input: PriceEvent[] → Output: {elasticity,ci95_low,ci95_high,sampleSize,degraded}
降级契约<3次事件→降级,标注"样本不足"; 排除促销期异常值; 季节性去趋势
关联哨兵sentinel-price-elasticity
数据源等级B (需PriceEvent实体+GA配置)
节点池归属PRICE_EVENT(需新实体)
statusNEW

C4. computeNPV

字段内容
契约IDCOMPUTE-NPV-v1
功能净现值: NPV=ΣCF_t/(1+r)^t-I0。折现率r由GA设定。非传统现金流可能产生多重IRR
读取的42边E-13 CAPITAL_ALLOCATION(allocation_ratio→CF预测), E-37 PROFIT_REINVEST(retention_ratio→折现率参考)
可执行路径规范DiagnosisContextNode → ALLOCATES(E-13) → CAPITAL_POOL; → REINVESTS(E-37) → retention_ratio。fixture: {I0:500,CFs:[150,200,250],r:0.1}→NPV=24.6。边界: r误设→GIGO,标注r置信度
降级契约折现率r缺失→降级:使用行业默认10%并标注; 现金流预测不完整→降级:标注缺失周期
关联哨兵sentinel-npv-negative
数据源等级A-B (现金流从ERP, r需GA设定)
statusNEW

C5. computeMarginalCost

字段内容
契约IDCOMPUTE-MARGINAL-COST-v1
功能边际成本: MC=ΔTC/ΔQ。成本必须正确分为固定/变动。Phase 1简单分类, Phase 2回归处理半变动
读取的42边E-23 OPERATIONAL_EXECUTION(efficiency_rate→VC代理), E-13 CAPITAL_ALLOCATION(allocation_ratio→FC占比)
可执行路径规范DiagnosisContextNode → PRODUCES(E-23) → PRODUCTION.efficiency_rate + output_quantity; → ALLOCATES(E-13) → CAPITAL_POOL。fixture: TC_prev=100,TC_curr=115,Q_prev=1000,Q_curr=1200 → MC=75。边界:成本分类错误→MC失真
降级契约成本无法分固定/变动→降级:用总成本/Q作为近似,标注crude_estimate=true
关联哨兵sentinel-margin-trend
数据源等级A (ERP数据可得, 但分类需GA配置)
statusNEW

C6. computeHHI

字段内容
契约IDCOMPUTE-HHI-v1
功能市场集中度: HHI=Σ(市场份额_i)²。范围0(完全分散)-10000(完全垄断)。<1500分散,1500-2500中度,>2500高度集中
读取的42边E-33 MARKET_COMPETITION(一阶), E-36 COMPETITIVE_POSITION(一阶)
可执行路径规范DiagnosisContextNode → COMPETES_IN(E-33) → 竞品市场份额数据。fixture: 前3家:40/25/15 → HHI=2450。边界: 份额不完整→HHI失真,标注已知竞品数
降级契约竞品份额<3家→降级:标注"基于已知竞品,可能存在未统计竞争者"; 无竞品数据→degraded:true
关联哨兵sentinel-hhi-concentration, competitive-position
数据源等级C (需GA手工输入竞品份额)
statusNEW

C7. computeLearningCurve

字段内容
契约IDCOMPUTE-LEARNING-CURVE-v1
功能学习曲线: AC_n=AC_1×n^(-b)。b>0越大=学得越快。需≥6月累积产量数据
读取的42边E-19 ORG_LEARNING(二阶, KEEP标签不变), E-23 OPERATIONAL_EXECUTION(efficiency_rate→单位成本)
可执行路径规范DiagnosisContextNode → LEARNS(E-19) → KNOWLEDGE_POOL.learning_rate; → PRODUCES(E-23) → unit_cost时序。fixture: 6月数据→b=0.08。边界:工艺变更加断点→重新计数;原材料暴涨→排除异常
降级契约<6月数据→降级:标注"样本不足"; 工艺变更→分段回归; 无行业基准→只报告趋势不比较
关联哨兵sentinel-learning-curve
数据源等级A-B (制造业A级, SaaS B级需代理)
statusNEW

C8. computeAgencyCost

字段内容
契约IDCOMPUTE-AGENCY-COST-v1
功能五大道德风险信号评分(0-1): 偷懒/在职消费/短期行为/风险规避/帝国建设
读取的42边E-16 INFO_TRANSMISSION(signal_fidelity), E-17 INCENTIVE_ALIGNMENT(incentive_distortion)
可执行路径规范DiagnosisContextNode → TRANSMITS(E-16) → signal_fidelity; → ALIGNS(E-17) → incentive_distortion; → 团队产出-资源比(多边聚合)。fixture: signal_fidelity=0.4+incentive_distortion=0.8→2信号>0.7→critical
降级契约部分信号数据不可得→降级:缺失信号取0.5(中庸),标注uncertainty
关联哨兵sentinel-agency-cost
数据源等级B (本体层图遍历可得,但信号保真度部分依赖GA评估)
statusNEW

C9. computeSurvivalMargin

字段内容
契约IDCOMPUTE-SURVIVAL-MARGIN-v1
功能存活因素聚合: 0-100免疫指数 = weighted(现金流跑道,关键人备份率,核心客户留存,合规)
读取的42边E-13 CAPITAL_ALLOCATION, E-02 PASSIVE_SIGNAL, E-31 CLIENT_RETENTION, E-18 RULE_CONSTRAINT
可执行路径规范DiagnosisContextNode → 四边并行读取 → 加权聚合。fixture: {cashRunway:3月,keyBackup:0.3,coreRetention:0.85,compliance:ok} → 45 → warning
关联哨兵sentinel-survival-margin
节点池归属CAPITAL_POOL, HUMAN_CAPITAL_POOL
statusNEW

C10. computeCSFProfile

字段内容
契约IDCOMPUTE-CSF-PROFILE-v1
功能行业CSF提取+企业CSF得分: LLM从行业报告提取CSF模板→GA结构化访谈校准→本体层数据填充得分
读取的42边E-36 COMPETITIVE_POSITION, E-01 ACTIVE_SCANNING
关联哨兵sentinel-csf-profile
数据源等级C (需LLM+GA输入+行业报告)
