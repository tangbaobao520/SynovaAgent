1.1 信号优先级排序器

定位：SignalAggregator（L3）输出50个结构化信号，排序器将其精简为1-3个候选故事，供主动触达引擎使用。

1.1.1 排序公式

candidate_priority(signal, persona) = severity × persona_match × time_decay × edge_complexity_factor
因子范围定义来源
severity1-10信号严重度。P0生存威胁=10，P1效率=5-7，P2机会=1-4哨兵规范的严重度阈值表
persona_match0-1信号涉及的因果边与该角色的职责关联度角色画像匹配模型（§1.2）
time_decay0.3-1信号时间衰减: 当前=1.0, 1天前=0.9, 1周前=0.7, 1月前=0.3信号timestamp
edge_complexity_factor1-2二阶边=1.5，跨环节联动=2.0，一阶边=1.042边类型字段

1.1.2 排序器可解释性要求

排序器不能是黑盒。当用户问"为什么不告诉我那个信号"时，系统必须能回答：

"信号X（客户流失风险，严重度7，您关心的领域）被选中。信号Y（设备产能不足，严重度4）未被选中——因为它低于您当前报告的最低严重度阈值。信号Z（HHI变化，严重度5）虽然严重但属于CFO职责范围，已推送给CFO。"

1.1.3 排序器架构位置

L2/L3边界——消费SignalAggregator（L3）的实时输出，产出给主动触达引擎（L2）。

关键决策 排序器不替代SignalAggregator的信号级聚合（同类合并、去重、时序对齐）。排序器只做"用户级筛选"——基于角色画像过滤和排序。

1.3 多信号去重合并机制

1.3.1 合并判定规则

当同一时间窗口（默认1小时，可配置）内多个信号同时触发，执行以下合并逻辑：

条件合并策略示例
两个信号消费同一条42边的不同参数合并为"该边的多维异常"margin-health(E-23效率异常) + unit-economics(E-23缺陷率异常) → "E-23运营执行出现多维异常：效率下降+缺陷率上升"
两个信号涉及同一客户/产品/部门的不同边合并为"该实体的复合因果故事""客户A流失风险"(E-31) + "A产品线毛利率下降"(E-23) → "关于A产品线，有两个相关风险信号"
两个信号上下游因果相关（如E-23→E-13→E-37）合并为"因果链故事"，按因果顺序组织运营效率下降(E-23) + 资本配置效率下降(E-13) → "生产端的问题正在传导到资本端"
两个信号无因果关系且涉及不同实体不合并。各自独立触达人才流失(E-38) + 竞品降价(E-33) → 两条独立触达

1.3.2 合并后的"复合因果故事"标题生成

规则：取最高严重度信号的实体名 + "及相关风险信号"。
示例："王总，关于A产品线，有两个相关的风险信号需要您关注"（而非"客户A流失风险"和"A产品线毛利率下降"两条独立消息）

1.5 叙事式触达模板

1.5.1 触达四要素结构

每条主动触达消息必须包含四个要素：

  1. 发生了什么（信号+数据）
  2. 为什么重要（影响范围+金额/百分比）
  3. 可能的根因（沿42边追溯）
  4. 下一步行动（追问入口+预判按钮）

1.5.2 触达示例（三种严重度）

P0 触达示例（cash-runway → 老板）：
"王总，您的现金跑道预估仅剩2.3个月（当前现金83万，月均烧钱36万）。过去的假设——'大客户B的续费会在本月到账'——尚未被验证。这条现金跑道从3个月前开始加速缩短。要一起分析现金流结构并制定预案吗？"
追问按钮：[现金结构分析] [应收款催收方案] [我已知晓，暂不处理]
P1 触达示例（margin-health → CFO）：
"李总，B产品线的毛利率在过去两周下降了4.2个百分点，从32%降至27.8%。这和您上周关注的原材料价格波动有关——B产品的核心原材料环氧树脂价格上涨了18%。B产品现在的单位边际贡献从8.6元降到了5.1元。要一起看看提价方案还是成本优化方案？"
追问按钮：[成本结构分析] [竞品价格对比] [提价影响测算]
P2 触达示例（sentinel-learning-curve → 运营VP）：
"王经理，C产品线的学习曲线表明，您的团队正在以每月7%的速度降低单位成本。这比行业平均（3%）快一倍以上。如果您打算扩大C产品线，现在是一个成本结构上的好时机。要看看扩张的可行性分析吗？"
追问按钮：[扩张可行性] [竞品学习速度对比] [暂不关注]

1.6 42边叙事结构模板库

核心设计原则：每条因果边不是"数据字段"——它是一种"因果故事类型"。不同边类型的信号，需要不同的叙事骨架。

E-01 主动扫描外部环境（感知衰减型）
"在[时间窗口]内，您的[市场/竞品/技术/政策]监控覆盖率为[X%]，有[Y]个外部信号被延迟感知。关键信号[SignalName]到达决策层的时间延迟了[Z]天。"
信号类型：filter_bias过高、scan_coverage下降
E-02 被动信号向上传递（信号衰减型）
"您预期从[来源节点]获取的[信息类型]未按时到达[决策节点]。衰减发生在[中间节点]，衰减率从正常的[X%]恶化到[Y%]。[后果：决策延迟/误判]。"
信号类型：signal_fidelity下降、transmission_delay增加
E-05 获取资本（资本通道型）
"您的[债权/股权/经营]资本获取渠道在[时间窗口]内[收紧/扩大]。债权可得性从[X]变为[Y]，实际利率[Z]% vs 行业基准[W]%。"
信号类型：financing_accessibility下降、cost_of_capital上升
E-13 资本配置（资源流向型）
"在[时间窗口]内，您的资本配置效率为[X]（满分1.0），相比上一周期[Y]。[活动A]占用了[Z%]的资本但产出了仅[W%]的利润贡献。资源配置与利润贡献之间的偏差为[D%]。"
信号类型：allocation_efficiency下降、allocation_ratio偏离贡献
E-14 决策权分配（权力结构型）
"决策集中度基尼系数为[X]（0=完全分散，1=一人独裁）。关键决策的平均审批层级为[Y]层，其中[T%]的决策超过[Z]层——这导致平均决策延迟[A]天。"
信号类型：concentration_gini过高、decision_latency过长
E-15 人力配置（人岗匹配型）
"[部门/团队]的人力配置效率为[X]。[Y]%的关键岗位由B级以下人才担任，[Z]%的A级人才被分配在非关键任务上。技能匹配度为[M%]。"
信号类型：skill_match_rate下降、key_position_backup_rate不足
E-16 信息传递（信息失真型）
"从[数据源]到[决策者]的信息传递过程中，数据失真率为[X%]（正常<5%）。关键发现：'[具体数据]'在传递过程中从[A]被错误地报告为[B]。偏差来源：[节点/环节]。"
信号类型：distortion_rate上升、info_fidelity下降
E-17 激励对齐（KPI扭曲型）
"[部门/角色]的KPI激励机制可能正在产生不良副作用。[行为X]从KPI角度看起来优化了[Y%]，但实际上损害了[指标Z]。KPI-实际价值偏差：[Δ]。"
信号类型：kpi_actual_gap扩大、perverse_incentive强度上升
E-19 组织学习（学习曲线型）
"[活动/产品线]的累计产量每翻一番，单位成本下降[X%]（学习率）。这[高于/低于/符合]行业基准[Y%]。如果学习率维持在[X%]，预计到累计产量达到[Z]时，单位成本将降至[A]。"
信号类型：learning_rate偏离、learning_plateau出现
E-23 运营执行（效率断裂型）
"[活动]的单位成本在过去[X]个周期内[上升/下降]了[Y%]，偏离了行业基准[Z%]。可能驱动因子：[因子1（贡献A%）, 因子2（贡献B%）]。[活动]的缺陷率/周期时间同时[恶化/改善]了[W%]."
信号类型：efficiency_rate下降、defect_rate上升、cycle_time延长
E-25 品牌建设（品牌积累型）
"您的品牌溢价能力从[X]变为[Y]（1.0=无溢价）。品牌延伸弹性为[Z]——意味着品牌从[产品A]延伸到[产品B]时，[W%]的品牌资产可以转移。过去[N]个月的品牌建设投入产出比为[M]。"
信号类型：premium_capability下降、extension_elasticity降低
E-30 定价（价格信号型）
"[产品]的需求价格弹性为[X]（|X|>1=弹性，<1=刚性）。当前价格[P]对应的边际收入为[MR]。如果提价[ΔP%]，预计需求量变化[ΔQ%]，利润变化[ΔProfit]。"
信号类型：elasticity变化、price_competitiveness下降
E-31 客户锁定（客户流失型）
"[客户群]的切换成本比率从[X]变为[Y]。具体而言：在过去[时间窗口]内，有[N]个客户[停止续费/减少采购/转向竞品]。[客户A]和[客户B]的流失对总收入的潜在影响为[Z%]。"
信号类型：switching_cost_ratio下降、churn_rate上升
E-33 市场份额获取（竞争动态型）
"您的市场份额从[X%]变为[Y%]（变化[Δ%]）。竞品[A]市场份额[上升/下降]了[B%]，主要靠[价格/产品/渠道]策略。您的市场集中度HHI指数为[Z]（<1500=分散, >2500=集中）。"
信号类型：market_share变化、HHI上升（集中化）或下降（碎片化）
E-36 竞争位势评估（七力护城河型）
"您的竞争位势七力评分为[X]/7.0（上一周期[Y]）。其中：规模经济[A]/1.0、网络效应[B]/1.0、切换成本[C]/1.0、品牌认知[D]/1.0、独占资源[E]/1.0、流程优势[F]/1.0、反定位[G]/1.0。最弱环节：[维度]，已在过去[M]个月内持续下降。"
信号类型：seven_powers_score下降、任一子维度跌破阈值
E-37 利润再投资（增长循环型）
"您的利润留存率为[X%]，再投资效率为[Y]（再投资1元产生的增量利润）。过去的战略假设：'将[Z%]利润投入[方向A]将产生[B%]的增量回报'——实际回报为[C%]，偏差[D%]。这个偏差已经持续了[E]个周期。"
信号类型：retention_ratio过高(投资不足)或过低(过度投资)、reinvestment_efficiency下降
E-42 假设打破→资本联动（假设验证型）
"在[时间窗口]内，有[X]个支撑当前资本配置的关键假设被现实数据挑战。假设'A：[假设内容]'——实际情况（[实际数据]）与假设假设偏差[Y%]。如果该假设被打破，受影响的资本配置金额约为[Z]万。建议：立即审查受影响项目并更新假设。"
信号类型：assumption_deviation超过阈值、assumption_age过长（>90天未验证）

注：以上为42边叙事模板的高频示例（17/42条）。完整42条边的叙事模板见完整42边叙事模板库（待工程实现阶段产出，当前17/42高频边已覆盖）。

1.7 安静期协议

1.7.1 不触达条件（优先级从高到低）

条件定义例外
免打扰时段用户定义的工作外时段（默认：工作日22:00-08:00，周末全天）P0生存威胁无视此规则
深度对话模式中用户正在与Agent进行深度诊断对话时，不插入新话题P0生存威胁以"折叠通知"形式提示（不抢占对话焦点）
连续无响应衰减连续[3]次触达未获用户响应 → 降频50%（如每天→每两天）。连续[7]次无响应 → 暂停主动触达，仅在工作台可被动查看P0生存威胁无视此规则的前3次。第4次起仍需衰减。
低置信阈信号置信度<50% → 标记为"内部预警"，不主动触达。仅在GA工作台可见无例外。低置信=不打扰。
用户显式暂停用户说"暂停通知"→ 暂停主动触达，持续[N]小时（默认24h），以提示"通知已暂停"显示P0生存威胁仍会触发。用户可设"包括紧急通知也暂停"。

1.7.2 非负面触达策略

Agent不应只在"出问题"时出现（变成"报丧鸟"）。也需要主动做正向叙事：

  • 季度回顾："王总，这个季度您的企业在以下5个维度上都有改善……"
  • 里程碑庆祝："恭喜！您的团队完成了XX项目，关键指标A提升了Y%。"
  • 前瞻提醒："下季度预算窗口将在2周后开启。以下是上次预算周期的执行回顾。"
  • 行业洞察："您所在行业的HHI指数本月有显著变化——这可能是一个战略窗口。"
