7.1 Pinpoint 模板

字段类型说明
pinpointIdstringPIN-{YYYYMMDD}-{seq}，如 PIN-20260710-001
severityP0|P1|P2P0=影响诊断正确性 / P1=影响系统可靠性 / P2=技术债
discoveredAtdatetime发现时间
discoveredByenumGA / 自动测试 / 用户反馈 / 因果回归测试 / 专家推理验证
descriptionstring问题描述
affectedstring[]涉及的 compute/哨兵/42 边/专家 的 ID 列表
rootCauseenum数据问题 / 推理逻辑 / 阈值设置 / 架构问题 / 时序处理 / 提示词设计
fixstring修正方案
acceptanceCriteriastring验收标准
verificationResultstring验证结果（通过/失败/部分通过）
relatedTestIdsstring[]关联的测试用例 ID（L1 契约测试 / L2 接线测试 / L4 因果回归 等）
causalRegressionResultstring通过因果回归验证？（通过/偏差 X%/未验证）

7.2 自动关联规则

pinpoint 创建时：

  1. grep 找到 affected 字段中涉及的代码文件路径 → 自动记录到 pinpoint 中
  2. 后续该文件被 git diff 修改时 → 自动提醒 "此文件关联 pinpoint #XX，请确认修正是否相关"
  3. pinpoint 标记为"已验证通过"后 → 此文件再次被修改时 → 提醒 "此文件的历史故障 pinpoint #XX 已修复，请确保不引入回归"
