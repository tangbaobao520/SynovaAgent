路线3：安全、测试与质量体系设计

C1-C5方向 | 2026-07-10

C1. 三层权限模型

数据层(谁看什么数据) / 诊断层(谁触发什么诊断) / 行动层(谁执行什么建议)。

对标Claw Code ROADMAP pinpoint 140：permissionMode迁移时无声降级DangerFullAccess->WorkspaceWrite。Synova原则：权限schema必须version-locked，禁止无声降级。

本地部署安全边界：只读ERP/CRM。默认阻断外部网络。沙箱文件系统。进程隔离。

遗忘权：企业停用30天后清理。员工离职30天后匿名化。

C2. 对抗性鲁棒性

提示注入：所有ERP/CRM/IM数据通过输入清洗层——剥离指令语法，仅保留数据值。参考ROADMAP中11次prompt.injection记录。

脏数据：统计异常检测(均值±3σ)，标记异常值但不自动删除。

数据投毒：跨数据源交叉验证——ERP和CRM中同一指标不一致时降级置信度。

C3. 四层测试金字塔

L1单元(每次commit) / L2集成(每次push) / L3 E2E(每次release) / L4 GA验证层(每周GA标注->计算precision/recall)。

对标Claw Code 456-pinpoint模式：每个诊断错误公开记录：问题+根因+修正+验收标准。来源：ROADMAP.md的pinpoint格式。

C4. 因果可解释性

诊断结论->点击->展开根因链。每条根因标注置信度+证据来源。42条边的触发路径可视化。

C5. 人机协同干预

P3/P4自动推送。P2需中层确认。P1需GA+中层确认。P0需GA+老板双确认。confidence<0.5降级为参考建议。
