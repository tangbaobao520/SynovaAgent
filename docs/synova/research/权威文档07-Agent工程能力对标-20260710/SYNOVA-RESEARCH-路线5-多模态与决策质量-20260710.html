E1. 多模态与工具集成

企业数据类型：图表(财务报表的柱状图/趋势图)、PDF报告(咨询公司出具的行业报告)、扫描件(合同/发票)。

对标发现：Claw Code的claw-rag-service设计——RAG索引独立于Agent主循环，通过HTTP API调用retrieve_context。来源：D:\Git项目研究\claw-code-main\rust\crates\claw-rag-service\（ingest + serve + SQLite + embedings）。

Synova多模态架构：企业上传PDF/图片->自动解析(OCR/表格提取)->关键数据关联到本体层节点。RAG索引服务独立于诊断循环。

E3. 决策质量自检循环

双循环设计：运维自检(系统是否正常运行——哨兵执行耗时、专家推理token消耗、compute函数调用成功率) + 决策质量自检(系统是否在做出正确的诊断——GA反馈+诊断结论与后续业务结果一致性)。

对标Claw Code ROADMAP：71次recover出现 + 29次agent.*fail——暴露了"Agent做错了但不知道"的系统性问题。Synova的决策质量自检正是为了避免这种"无声退化"。

诊断质量仪表盘：GA可以看到：最近30天precision/recall趋势、每个哨兵的误报率变化、专家推理的被驳回率、compute函数的degraded频率。当任何指标连续下降超过2个周期时自动告警："诊断系统可能在退化"。
