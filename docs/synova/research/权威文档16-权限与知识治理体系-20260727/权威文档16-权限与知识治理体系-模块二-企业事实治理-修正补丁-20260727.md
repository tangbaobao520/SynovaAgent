# 模块二补丁：企业事实治理 (文件驱动版)

> 原模块二的主体逻辑 (事实生命周期/审批/冲突/回滚) 仍然有效。
> 以下为配合文件驱动架构的修正项。

---

## 修正一: 存储位置变更

| 原设计 | 修正后 |
|--------|--------|
| `agent_memory` 表, `type: 'enterprise_fact'` | `.codex/enterprise/facts/{category}/{key}.md` |
| SQL UPSERT 覆盖旧值 | 文件编辑, git 自动版本追踪 |
| 需代码实现 version_id/previous_value | git log 免费提供版本链 |

---

## 修正二: 冲突检测简化

原设计需代码扫描 SQL 表检测同领域内数值矛盾。文件驱动后:
- git diff 提供逐行变更追踪 (免费)
- 系统定时扫描同 category 目录下的 active 文件, 检测数值矛盾
- 冲突标记为在文件末尾追加 HTML 注释 (而非修改 status 字段)

---

## 修正三: 智能辅助建议的来源标注 (不变)

智能辅助建议的来源区分 (数据分析 vs 模式匹配) 和置信度标注保持不变。
