Index 公式设计 1.1 设计动机 非共识信号 = 方向 × 时机。方向正确但时机错误 = 先烈（如 Webvan 2000、电动车 2005、VR 2016）。方向正确且时机正确 = 颠覆者（如特斯拉 2010、Airbnb 2008、ChatGPT 2022）。STM Index 的使命：在"方向判断"之外，独立给出"时机成熟度"评分。 核心理念来自两个理论锚点： Perez (2002) 技术-经济范式： 每次技术革命经历导入期（Irruption → Frenzy）→ 转折点（Turning Point）→ 协同期（Synergy → Maturity）。导入期投资基础设施未就绪 → 高死亡率。转折点后基础设施就绪 → 应用层爆发。 Andreessen Horowitz "基础设施先行"框架： 每一波应用层繁荣之前，必然有一波基础设施层的大规模建设。移动互联网应用爆发（2010-）之前是 3G/4G + 智能手机的大规模部署（2007-2010）。AI 应用爆发（2023-）之前是 GPU 算力成本十年下降 1000 倍 + Transformer 架构成熟。 1.2 核心公式 STM_Index(direction) = Σ(w_i × readiness_i) × urgency_factor 其中： w_i = 第 i 项基础设施对该方向的重要度权重 (0～1, Σ w_i = 1) readiness_i = min(1.0, current_penetration_i / threshold_i) —— 当前渗透率相对于临界阈值的比例，上限 1.0（超阈值不再加分） urgency_factor = 1.0 + log(1 + n_thresholds_crossed_recently) —— 近期（12个月内）跨越临界点的指标数量越多， 先发窗口正在关闭的紧迫性越高，分数乘数 > 1.0 值域: [0, u_max] 0.8 → 成熟 —— 基础设施早已就绪，警惕：可能是伪非共识（为什么没人做？） 1.3 权重确定方法 方向依赖的基础设施权重集 W(direction)： 不同的非共识方向依赖不同的基础设施组合。移动互联网方向权重最高的是"智能手机渗透率"和"宽带覆盖率"；AI 方向权重最高的是"AI 芯片算力"和"云计算成本"；新能源方向权重最高的是"电池能量密度"和"物流基础设施"。 权重确定依赖两步： 历史类比映射： 在 100 个非共识案例库中，找到与该方向最相似的 k 个历史案例（按商业模式结构、技术栈、用户行为模式相似度匹配），提取这些案例成功时各项基础设施的渗透率作为"临界参考"。 专家校准： 结合 Perez 框架中该方向所属技术-经济范式的阶段判断，调整各项基础设施的阈值和权重。 1.4 方向权重矩阵（示例） 基础设施 移动互联网 方向权重 AI 应用 方向权重 新能源 方向权重 区块链 方向权重 智能手机渗透率 0.35 0.05 0.00 0.10 跃升至 64%——这就是阈值。 Perez 转折点对应： Perez 框架中，转折点的标志是"基础设施网络效应开始正向反馈"。将阈值映射到该理论所描述的转折点条件。 成本曲线外推： 对于成本型指标（电池、AI芯片、云计算），使用 Wright's Law（累积产量每翻倍，成本下降固定百分比）和 Moore's Law 变体进行趋势外推，标注"从昂贵到可负担"的拐点。 2.3 去掉时机维度的方向判断，等于给投资决策者分发"正确的错误地图"——指引他们走向正确的方向，却在错误的时间。 五、诚实边界：系统的局限与未知 5.1 基础设施数据可得性限制 限制类型 具体问题 影响 全球 vs 区域差异 智能手机渗透率 72% 是全球均值，但撒哈拉以南非洲仅 45%，印度仅 55%。对于一个聚焦单一市场的方向，全球均值可能严重误导。 STM Index 必须支持按目标市场切片计算。 数据滞后 电池能量密度、AI芯片算力的公开数据通常滞后 3-6 个月。前沿数据掌握在企业内部（特斯拉、英伟达）而非公开市场。 STM Index 对"刚过临界"的判断存在 3-6 个月不确定窗口。 基础设施成熟度指数的主观性 "区块链基础设施成熟度"和"物流基础设施指数"是综合指标，依赖子指标的权重设定——不同方法论可能给出不同分数。 综合指数类基础设施的阈值置信度低于直接测量型（如渗透率、成本）。 中国 vs 全球的流动性壁垒 移动支付渗透率中国 ~90%，美国 ~35%。基础设施在 A 市场就绪不意味着在 B 市场就绪。跨境推广时需重新计算。 STM Index 需要"区域模式"开关。 5.2 对于"基础设施远未就绪的全新型方向"的处理 场景：可控核聚变商业化 当前 STM Index 对可控核聚变的读数：所有 10 项基础设施中，只有"AI 芯片算力"和"云计算成本"间接相关（用于等离子体模拟），其余 8 项权重接近 0。STM Index 如果硬套会输出 ~0.08——但这毫无意义。因为核聚变根本不在当前的 10 项基础设施框架内。 STM Index 对"范式外方向"的正确输出 STM Index 必须内置"范式识别"前置步骤： 方向分类： 该方向属于已有技术-经济范式（如互联网、AI、新能源）还是全新范式（如核聚变、量子计算、太空制造）？ 如果是已有范式方向： 正常计算 STM Index。 如果是全新范式方向（全新范式 = 当前 10 项基础设施对该方向的总权重 不输出 STM Index 数值——改为输出定性标注："此方向位于当前技术-经济范式之外。STM Index 不适用。建议替代评估框架：技术就绪度（TRL）+ 科学突破时间线概率 + 政府/军事采购意愿。" 附加：识别该方向一旦可行的"次生基础设施需求"——核聚变若成功，电网改造、储能、氢气运输等基础设施需要多少年跟上？ 5.3 其他已知盲点 监管/政策黑天鹅： 基础设施再就绪，一条禁令足以清零。例如中国教培行业 2021——所有基础设施就绪（在线支付、直播技术、AI 推荐），但政策突变导致行业归零。STM Index 当前不含监管维度（注：这属于"外部环境"层，应由 SynovaAgent 的环境哨兵独立评估）。 用户行为惯性： 基础设施就绪 ≠ 用户会用。智能家居的基础设施（IoT、5G、云计算）已就绪多年，但用户采用率仍然远低于预期。STM Index 测量的是"供给侧就绪度"，未测量"需求侧接受度"。 既有玩家锁定效应： 即使基础设施就绪，如果市场已被网络效应锁定（如社交被 Meta 锁定、搜索被 Google 锁定），新进入者的成功概率仍然极低。STM Index 必须与"生态位挤压指数"（SynovaAgent 界面层哨兵）联合使用。 六、研究方法论 6.1 研究设计 本研究采用"历史案例回溯法 + 基础设施渗透率标注"的混合方法。核心逻辑：如果"时机成熟度"是一个真实存在的、可量化的维度，那么它应该能通过历史案例的 事前 预测测试——即用案例发生时间点之前的数据计算 STM
