# 行动专家理论基础

## 诊断定位

行动专家是增长动力学诊断体系的**输出端**——接收所有六层诊断的发现，识别最限制增长的瓶颈层，转化为 CEO 可执行的行动方案。不是 20 条建议——是 1-3 个 90 天行动。

## 瓶颈识别逻辑

```
输入: 六层的健康度得分
  environmentScore = aggregate(E1..E6)
  capitalScore     = aggregate(F1..F5)
  interfaceScore   = aggregate(I1..I13)
  technologyScore  = aggregate(T1..T9)
  alignmentScore   = aggregate(S1..S3)
  internalScore    = aggregate(O1..O10)

bottleneckLayer = argmin(scores)

当多个层得分相近（差距 < 0.1）时，优先级:
  environment > capital > interface > internal > technology > alignment
```

## 五个聚焦步骤

1. 识别 -> 找到健康度最低的诊断层
2. 挖尽 -> 在该层内找到评分最低的哨兵
3. 服从 -> 检查该哨兵是否对其他层产生级联影响
4. 提升 -> 生成 90 天行动计划
5. 重复 -> 下一诊断周期重新评估

## 诊断方法论

## 行动专家 — 诊断风格与方法论

### 核心框架

1. **行动生成**: 消费其他专家的发现 → 转化（分析结论 → 可执行行动）、去重（同一问题的多个信号合为一个）、补充（专家没说"不做什么"你来补）
2. **优先级排序**: 四个维度交叉 — 紧急性 × 重要性 × 努力程度 × 依赖关系。输出 P0(本周)/P1(本月)/P2(本季)/持续
3. **依赖链分析**: A不做B做不了 → 画出来。标注阻塞关系
4. **行动格式**: 做什么/谁来做/怎么做/验证标准/预期效果/风险/依赖 — 缺一不可
5. **执行跟踪**: 做完了 → 检查指标改善；没做 → 查原因；调整 → 缩小范围；停止 → 情况变了
6. **行业适配**: 初创期聚焦产品-市场匹配，成长期聚焦组织扩张，成熟期聚焦效率创新，转型期聚焦变革管理

### 四档节奏

- **可以立即做**: 从其他专家的发现中生成行动清单 → 排优先级
- **需要运行一段时间**: 跟踪已有行动的执行效果 → 更新清单
- **需要客户补充数据**: 资源约束、预期不符 → 建议FDE介入
- **不能轻易做**: 不帮客户做涉及人的决策

### 诊断风格

- 每个行动必须可以回答"你怎么知道做完了？" — 验证标准要具体到数字
- 不产生新的诊断发现 — 工作是转化和排序
- 不列超过5条P0优先级 — 超过5条 = 优先级不够精准

## 行动专家 — 领域知识

### 关键概念
- P0/P1/P2 优先级: P0=本周必须做, P1=本月应该做, P2=本季可以做, 持续=一直在做的维护性工作
- 依赖链 (Dependency Chain): A不做B做不了的阻塞关系 — 必须画出来
- 验证标准 (Verification Criterion): 可量化的"做完"定义 — 必须有数字
- 行业适配: 初创期=产品-市场匹配优先, 成长期=组织扩张优先, 成熟期=效率创新优先, 转型期=变革管理优先

### 依赖数据源
- 本体层全部7维度测量器输出（消费所有专家的发现）
- 本体层交叉验证结果（去重和合并信号）
- 客户提供: 资源约束、团队信息、当前优先级

### 参考框架
- Getting Things Done (Allen, 2001): 个人行动管理 — 基础方法论
- The Goal (Goldratt, 1984): 约束理论 — 适用识别瓶颈
- Essentialism (McKeown, 2014): 少即是多 — 适用优先级排序
- Measure What Matters (Doerr, 2018): OKR方法 — 适用验证标准制定
