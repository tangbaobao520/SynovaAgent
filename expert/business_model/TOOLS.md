# 商业模式专家 — 可用工具

## 专有工具

### 诊断工具

- **structure_health_check**: 结构健康体检（段永平六问）
  - Q1: 复购驱动力是什么？可持续吗？
  - Q2: 定价权在谁手里？
  - Q3: 现金流是先收后干还是先干后收？
  - Q4: 竞品复制的结构性障碍在哪？
  - Q5: 规模是朋友还是敌人？
  - Q6: 毛利率的稳定性（被谁挤压？）
  - 输出: 六维体质雷达图 + 每项 🟢/🟡/🔴 判定

- **value_cycle_audit**: 价值循环审计（曾明视角）
  - 价值创造→传递→捕获的完整链路映射
  - 各环节利益分配比例分析
  - S2B2C 适配性: S该做什么？B该做什么？分工合理吗？
  - 输出: 价值流图 + 利益分配表 + 分工合理性评估

- **stakeholder_alignment**: 利益相关者对齐审计（曾明视角）
  - 客户: 复购驱动力 + 转换成本 + NPS
  - 渠道: 推你 vs 推竞品的利润率对比
  - 供应商: 双方依赖度对比
  - 员工: 核心人才激励与公司长期利益的对齐度
  - S2B2C: 小B为什么跟你干？分配比例合理吗？跳单率？
  - 输出: 利益相关者动力矩阵

### 描述工具

- **canvas_scan**: 商业模式画布九要素现状扫描
  - 逐要素检查，标注数据来源（"数据" vs "推断"）
  - 发现要素之间的矛盾（如"高价定位"但"低质渠道"）
  - 定位: 检查清单，确保不遗漏

- **value_price_audit**: 价值-价格自洽性审计
  - 价值主张 vs 定价策略 vs 客户感知（NPS/续约率）
  - 判断: 高价低值？低价高值？匹配？
  - 输出: 自洽性评分 + 不匹配的要素

- **revenue_structure**: 收入结构分析
  - 收入来源多样性、集中度、增长性
  - 按行业模式（零售/项目/订阅/S2B2C/分销/服务）分类评估
  - 收入模式与成本结构的匹配度
  - 输出: 收入结构健康度 + 🔴/🟡/🟢

- **mode_evolution**: 模式进化空间评估
  - 卖产品 → 卖服务 可能性？
  - 项目制 → 产品化/订阅 可能性？
  - 线型业务 → S2B2C 重构 可能性？
  - 单一收入 → 多层收入（剃须刀+刀片）可能性？
  - 输出: 进化方向 + 可行性 + 风险 + 前置条件

## 共享工具

- **cross_validate**: 与其他专家的发现交叉验证
  - 营销专家: 验证定价策略、客户细分
  - 财务专家: 验证收入结构、成本结构
  - 战略专家: 验证竞争壁垒（7 Powers 交叉）
- **query_graph**: 查询本体层节点和边
- **trace_evidence**: 追溯每条发现的证据链

## 受限工具（需 FDE 确认）

- **business_model_redesign**: 商业模式转型建议
  - 涉及企业根本方向，必须全维度数据齐备
  - 标注置信度和风险等级
- **pricing_elasticity**: 定价弹性分析
  - 需客户提供定价实验数据或支付意愿调研
- **partner_contract_audit**: 合作伙伴条款审计
  - 需客户提供合作协议/合同条款

## 组织弹性边界分析 (EOB)

诊断人+Agent混合组织的动态边界管理能力。

### 核心信号
1. Agent流失率 — inactive/offline Agent占比
2. 弹性响应速度 — 任务激增到新Agent上线的时间
3. 外部比例 — external Agent占比
4. 僵尸权限风险 — 已停用Agent仍有关联边

### 边界健康度
boundaryHealth = 1 - churnRate×0.4 - zombieRisk×0.3 - |externalRatio-0.3|×0.3
流失率>30%或僵尸风险>50%: critical, healthScore<0.5: warning

## 价值链解构方法（管理经济学）

### 基本活动
- 内部物流→生产→外部物流→营销销售→售后服务
  - 每个环节标注：当前利润贡献、Agent自动化潜力(高/中/低)、改进空间

### 支持活动
- HR→技术→采购→基础设施
  - 每个环节标注：成本占比、Agent替代率

### 利润池迁移识别
- 比较过去12个月各环节的利润贡献变化趋势
- 如果利润在向某个环节迁移，标注"利润池迁移中"
