# 资本预算与营运资金管理（管理经济学）

## 资本预算决策树

### Step 1: NPV > 0？
```
NPV = Σ(CashFlow_t / (1+r)^t) - InitialInvestment
```
- NPV > 0 → 创造价值，继续评估
- NPV = 0 → 盈亏平衡，可考虑（如果战略价值大）
- NPV < 0 → 不创造价值，建议放弃

### Step 2: IRR > WACC？
- IRR > WACC → 回报率超过资金成本，继续评估
- IRR = WACC → 刚好盈亏平衡
- IRR < WACC → 回报率不足以覆盖资金成本

### Step 3: 回收期 < 阈值？
- 回收期 < 项目周期 × 70% → 正常
- 回收期 > 项目周期 × 70% → 现金流风险较高，需敏感度分析

### Step 4: 综合判定
| NPV | IRR vs WACC | 回收期 | 决策 |
|-----|------------|--------|------|
| > 0 | > WACC | 短 | 推荐 |
| > 0 | > WACC | 长 | 需关注现金流风险 |
| > 0 | = WACC | 任意 | 战略价值驱动 |
| = 0 | = WACC | 任意 | 可选（非核心） |
| < 0 | < WACC | 任意 | 不推荐 |

## 营运资金优化原则

### 现金转换周期
CCC = DSO + DIO - DPO
- DSO（应收周转天数）：越低越好，目标 < 行业平均
- DIO（库存周转天数）：越低越好，但需平衡缺货风险
- DPO（应付周转天数）：越高越好，但不损害供应商关系

### 优化方向
1. **应收端**：加速回款（折扣激励、电子发票、自动催收）
2. **库存端**：降低安全库存（需求预测精度提升 + 供应商协同）
3. **应付端**：协商更优付款条款（不超 90 天）
4. **现金端**：现金流预测精度 > 90% 时方可降低现金储备

### 预警信号
- CCC 连续 3 期上升 → 营运资金效率恶化
- DSO > 行业均值 × 1.5 → 信用管理可能松弛
- DIO > 行业均值 × 2 → 库存积压风险
- 应付周转天数同比减少 > 30% → 供应商议价权变化
