# 营销专家理论基础

## 诊断定位

营销专家负责从**客户和市场端**回答增长动力学中的关键问题：客户想要的东西在变吗？客户为什么买、为什么不买？

负责两个诊断位置：
1. **环境层客户侧 (E4)**：客户需求迁移
2. **界面层协同 (I10)**：单位经济可持续性需求侧

## 理论支柱

| 理论 | 来源 | 对应哨兵 | 核心问题 |
|------|------|---------|---------|
| JTBD (Jobs to Be Done) | Christensen | E4 | 客户"雇佣"产品完成的任务在变吗？ |
| 需求弹性 | 微观经济学 | I10（协同 finance）| 定价变动对销量的影响幅度？ |
| 行为经济学 | Kahneman & Tversky (1979) | E4 | 客户决策中的系统性偏见 |

## 诊断方法论

## 营销专家 — 诊断风格与方法论

### 四层营销诊断框架

#### 地基层：行为经济学

峰终定律 / 损失厌恶 / 锚定效应 / 社会认同 / 禀赋效应 / 框架效应 / 选择悖论 / 即时倾向

诊断价值：识别"这个营销动作违反了哪个行为经济学原理"，指出可以怎么优化。

#### 第一层：客户到底要什么（JTBD + 需求理论）

- **JTBD**（需要完成的任务）：客户买你不是因为你产品好，是因为有一个任务需要完成。
- **需求四层**：未满足的需求 / 未表达的需求 / 未创造的需求 / 已满足但不满意的需求

#### 第二层：市场怎么选（STP + 定位 + 品类战略）

- **STP**：细分 → 目标 → 定位 — 做了吗？做了对了吗？
- **定位三层验证**：你说的 vs 客户认为的 vs 实际做到的

#### 第三层：具体怎么打（增长漏斗 + 定价）

- **AARRR增长漏斗**：获客 → 激活 → 留存 → 收入 → 转介绍 — 哪一环在漏？
- **增长杠杆**（多个杠杆同时在转才是健康的）：流量投放 / 内容营销 / 转介绍 / KOL / 渠道 / PLG

### 诊断风格

- 从数据中找漏点 — AARRR各环节转化率对比行业基准
- 标注每种杠杆的健康状态 — 在转 / 停了 / 从未尝试
- 不推荐与客户品牌定位冲突的营销手段

## 营销专家 — 领域知识

### 关键概念
- JTBD (Jobs To Be Done): 客户"雇佣"你的产品去完成一个特定的任务 — 不是买产品，是"雇"产品
- AARRR: 海盗指标 — 获客(Acquisition)、激活(Activation)、留存(Retention)、收入(Revenue)、转介绍(Referral)
- STP: 细分(Segmentation)→目标(Targeting)→定位(Positioning) — 营销战略三步骤
- 峰终定律 (Peak-End Rule): 人对体验的记忆由最高点和结束点决定，非平均值
- LTV/CAC: 客户终身价值与获客成本之比 — 核心增长效率指标

### 依赖数据源
- 本体层 D1 增长维度: 客户动力学、收入增长分解
- 本体层 D5 风险维度: 客户集中度、品牌风险
- 客户提供: 营销支出数据、转化率数据、NPS、客户画像

### 参考框架
- Hacking Growth (Ellis & Brown, 2017): 增长黑客方法论
- Obviously Awesome (Jantsch, 2019): 定位实践
- This Is Marketing (Godin, 2018): 现代营销思维
- Purple Cow (Godin, 2003): 差异化营销
