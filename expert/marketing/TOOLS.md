# 营销专家 — 可用工具

## 专有工具
- growth_funnel: AARRR增长漏斗分析 — 逐环转化率、行业对标、漏点识别
- behavioral_economics: 行为经济学诊断 — 识别违反行为原理的营销动作
- market_positioning: STP+定位验证 — 细分→目标→定位，三层一致性
- growth_levers: 增长杠杆健康扫描 — 流量/内容/转介绍/KOL/渠道/PLG状态

## 共享工具
- cross_validate: 与其他专家的发现交叉验证
- query_graph: 查询本体层节点和边

## 受限工具 (需FDE确认)
- pricing_strategy: 定价策略建议 — 需充分的竞品定价和客户支付意愿数据
- brand_audit: 品牌审计 — 需客户品牌资产数据

## 需求弹性估算（管理经济学）

当诊断涉及定价、调价、价格敏感度分析时调用此工具。

### 价格弹性
ED = (ΔQ / Q₀) / (ΔP / P₀)
  ED > 1: 需求有弹性 — 降价可增收
  ED < 1: 需求无弹性 — 涨价可增收
  ED = 1: 单位弹性 — 价格变动不影响收入

### 估算方法（无回归条件下的简便方法）
1. 找到最近2-3次价格变动事件+对应的销量变化
2. 每次计算弹性值
3. 去掉极端值后取中位数
4. 标注置信度：数据点越多越可信

### 交叉弹性
EXY = (ΔQX / Q₀X) / (ΔPY / P₀Y)
  EXY > 0: Y涨价=X销量增 → 替代品
  EXY < 0: Y涨价=X销量降 → 互补品

### 混合组织修正
- Agent可能实时调整价格（动态定价）→ 弹性的"反应时间窗口"缩短
- 竞争对手Agent也会调价 → 简单弹性模型可能失效
- 诊断结论标注"弹性估算基于历史数据，未考虑对手Agent的动态响应"

## 行为经济学诊断（管理经济学）

### 前景理论
- 损失厌恶系数：人对损失的敏感度约为收益的2-2.5倍
- 诊断应用：当企业主拒绝一个数学上合理的方案时，考虑损失厌恶影响

### 锚定效应
- 初始值对后续判断的影响远超理性预期
- 诊断应用：在定价谈判、估值讨论中，初始锚点设置不当可能是原因

### 现状偏误
- 人们倾向于维持现状，即使改变是理性的
- 诊断应用：组织变革建议被拒绝时，区分"理性反对"和"现状偏误"
