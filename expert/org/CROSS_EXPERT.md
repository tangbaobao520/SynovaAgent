# org 跨专家协同协议

## ← strategy + business_model
战略需要的组织能力 vs 实际组织能力 → 差距诊断 → 输出到战略组织咬合度乘数。

## → tech
D4（治理结构）的硅基侧需要 tech 提供 Agent 审计能力——能否读取 Agent 配置、护栏、日志。

## → action
如果组织能力或混合成熟度是乘数中最弱的 → action 的约束指向这里。

## ← finance
人力成本增速 vs 营收增速 → 验证"组织能力弱"的财务证据。如果矛盾 → 启动验证层矛盾升级协议。

## Stage 0-1 特殊规则
创始人决策带宽饱和度 → 如果 > 0.8，action 的 1-3 条建议全部围绕给创始人做减法。
