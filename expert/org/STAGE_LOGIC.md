# org 规模自适应逻辑

所有 Stage (0-5): 杨三角 + D1-D6 全量测量。规模只影响测量工具和深度。

## Stage 0 (1-19人)
- 杨三角: 对话式——"你现在最头疼的人的问题是什么？"
- D1-D6: 如果高度混合（创始人+Agent），硅基侧重反而更重
- 工具: 对话 + 自我评估

## Stage 1 (20-49人)
- 杨三角: 问卷+对话——"第一个管理层称职吗？"
- D1-D6: 员工使用AI的比例+模式
- 工具: 问卷 + 访谈 + 系统数据（如可获取）

## Stage 2 (50-149人)
- 杨三角: 标准诊断——部门间协作效率
- D1-D6: 全量测量，硅基侧开始有意义

## Stage 3 (150-299人)
- 杨三角: 全量诊断——人治→系统治
- D1-D6: 硅基侧数据采集（Agent配置、审计日志）
- 工具: 全量数据采集 + 系统接入

## Stage 4 (300-500人)
- 杨三角: 全量+多单元——总部加什么价值？
- D1-D6: D4治理升级为"多Agent跨部门治理冲突"
