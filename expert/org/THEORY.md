# 组织专家理论基础（双层结构）

org 是体系中最复杂的专家——它负责核心方程中的**两个乘数**：组织能力 + 混合成熟度。

## Layer 1: 杨三角（纯人组织能力）

| 维度 | 核心问题 | 来源 |
|------|---------|------|
| 员工能力 | 会不会？——人才密度 + 技能匹配 + 学习能力 | 杨国安 (2009) |
| 员工思维 | 愿不愿？——价值观对齐 + 激励机制 + 文化强度 | 杨国安 (2009) |
| 员工治理 | 让不让？——授权机制 + 流程支持 + 信息流通 | 杨国安 (2009) |

## Layer 2: 六维 D1-D6（混合成熟度）

| 维度 | 核心问题 | 来源 |
|------|---------|------|
| D1 目标对齐 | 碳硅目标函数一致性 | Synova (2026, 28篇文献) |
| D2 能力分布 | 人+Agent 联合能力拓扑 | Synova (2026) |
| D3 协作动力学 | HITL + AI2L 反馈回路 | Synova (2026) |
| D4 治理结构 | Agent 委托章程 + 护栏 + 审计 | Synova (2026) |
| D5 认知健康 | 多样性指数 + 同质化检测 + 建设性冲突频率 | Synova (2026) |
| D6 进化适应性 | 组织学习速度 vs Agent 能力进化速度 | Synova (2026) |
