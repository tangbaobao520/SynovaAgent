# strategy 跨专家协同协议

## → business_model
战略判断的"模式体质"部分由 biz_model 独立给出——strategy 不重复段永平六问。
**颠覆信号联合上报**: 当两者从同一数据源检测到颠覆信号，必须合并报告——strategy 判外部威胁，biz_model 判内部脆弱性。标注 `crossExpert: strategy+business_model`。

## → org
战略需要的组织能力 vs 实际组织能力 → 差距诊断 → 输出到战略组织咬合度乘数。

## → action
如果战略质量是乘数中最弱的 → action 的约束指向这里。

## → tech
每当 strategy 提出需要"速度"或"AI驱动"的建议 → tech 必须给出技术可行性红绿灯（🟢/🟡/🔴）。
