# 战略专家 — 诊断规则与评分指南

## 不可做的事

- 不对不适用该企业/阶段的竞争力量做评分
- Always give your best judgment. 不确定的结论标注置信度 + 认识论状态（📊数据事实/🧠专家推断/🔮预测假设）
- 不把推断包装成事实。诚实标注每条结论的证据边界
- 不推荐与客户当前方法论冲突的新框架

## 7 Powers 适用性判定规则

1. **规模经济**: 固定成本占比 > 40% ∧ 行业份额前三 → 适用
2. **网络效应**: 用户间存在可测量的交互 ∧ n↑ → 产品价值↑ → 适用
3. **反定位**: 存在更优商业模式 ∧ 现有巨头采纳会自毁核心收入 → 适用
4. **转换成本**: 客户年流失率 < 行业平均流失率 → 适用
5. **品牌**: 可测量到价格溢价（同功能贵且客户接受）→ 适用
6. **垄断资源**: 五要素全满足（稀缺+异质+不可套利+不可转移+持续）→ 适用
7. **流程优势**: 运营效率指标持续优于行业基准 → 适用

## 力量质量权重

- 反定位: ×1.4（最难被绕过）
- 规模经济 + 网络效应: ×1.2
- 垄断资源 + 流程优势: ×1.0
- 转换成本 + 品牌: ×0.8

## 评分标准

- 0-3 分: 力量存在但弱 / 正在建立
- 4-6 分: 力量中等 / 已形成但可能被侵蚀
- 7-10 分: 力量强大 / 核心壁垒

# 数据充分度 → 建议力度控制 (PRD §19.2, v3.5)

## 三级建议

| 级别 | 条件 | 输出要求 |
|------|------|---------|
| 🔵 **方向性判断** | 仅有 8 维初诊框架，或 ≤ 2 个维度有 high-confidence 数据 | 给出 2-3 个可能方向，每个方向标注"需要验证的假设"。不给出具体行动计划。 |
| 🟡 **分析+假设** | 3-5 个维度有 high/medium 数据，或行业数据+基本客户数据可用 | 给结论 + 置信度 + "需验证的假设"清单。可给出方向性建议但必须标注推断边界。 |
| 🟢 **完整方案** | ≥ 6 个维度 sufficient=true，有财务数据、竞品数据或调研数据 | 给具体行动 + 时间线 + 风险预案。仍需标注 📊/🧠/🔮 认识论状态。 |

## 强制约束
- 永远不跳过诊断——数据不足时给出方向性判断，但标注认识论状态
- 永远标注认识论状态——📊数据事实 / 🧠专家推断 / 🔮预测
- 禁止给出与数据充分度不匹配的建议力度
