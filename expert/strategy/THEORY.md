# 战略专家理论基础

## 理论支柱

| 理论 | 来源 | 在诊断中的位置 |
|------|------|--------------|
| 五力分析 | 波特 (1980) | 赛道引力：行业的结构性利润率 + 谁在吃掉利润 |
| 网络位置 | 曾明 (2018) | 赛道引力：在价值网络中的位置 + S2B2C 适配 |
| 7 Powers | 赫尔默 (2016) | 竞争力量：结构性的还是运营性的？含完整数学推导 |
| 飞轮效应 | 柯林斯 (2001) | 竞争力量：在加速飞轮还是推新石头？ |
| 颠覆式创新 | 克里斯坦森 (1997) | 竞争力量：谁在看不见的边缘？成功是否在变盲？ |

## 诊断逻辑

1. **赛道判断**: 波特五力 + 利润池地图 → 最赚钱的环节在哪？你在那个环节吗？
2. **壁垒判断**: 7 Powers 适用性判定 → 只判适用的力量，不适用的不评分
3. **飞轮判断**: 识别核心飞轮 → 驱动力 vs 阻力
4. **颠覆预警**: 边缘信号 → 替代方案 → 客户流失的低端市场

## 该理论为什么适用于各规模企业

- Stage 0-1: 赛道引力判断（"选这个赛道的原因是？更大对手为什么不进来？"）
- Stage 2-3: 全量诊断（赛道+壁垒+飞轮）
- Stage 4+: 全量+第二曲线（"第一曲线的天花板在哪？"）

## 路径依赖检测框架

### 核心概念
路径依赖：组织过去的决策限制了当前的选择空间。在组织诊断中表现为某些维度长期不变化，且偏离同类团队的正常变化频率。

### 锁定信号
1. 分工结构 6 个月未调整
2. 信息流拓扑 3 个月未变化
3. 权威治理模式持续不变
4. 激励体系无更新

### 检测方法
- 对比当前维度状态与 90 天前状态
- 同类团队基线变化率（源自框架库）
- 锁定维度 > 2 个 → 存在路径依赖风险

## 市场结构四象限（管理经济学基础）

| 类型 | 企业数量 | 产品差异 | 进入壁垒 | 定价能力 |
|-----|---------|---------|---------|---------|
| 完全竞争 | 极多 | 无 | 无 | 无 |
| 垄断竞争 | 多 | 有 | 低 | 有限 |
| 寡头 | 少数 | 可有可无 | 高 | 强 |
| 垄断 | 一个 | - | 极高 | 极强 |

### HHI指数 (Herfindahl-Hirschman Index)
HHI = Σ(Si²)
  < 1500: 不集中
  1500-2500: 中度集中
  > 2500: 高度集中 — 需要提示反垄断风险

### 混合组织修正
- Agent驱动的定价算法会自动学会隐性合谋
- 共享相似的定价训练数据可能会诱发定价趋同
- 标注"存在算法共谋的可能性"
