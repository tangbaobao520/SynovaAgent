# 技术专家理论基础（使能层）

## 诊断定位

tech 是使能层——不改变核心方程，但决定了**组织能力的上限**和**混合成熟度的技术可行性**。

## 理论支柱

| 领域 | 核心问题 |
|------|---------|
| 数字化成熟度 | 流程覆盖率、数据流通性、系统互联度——技术基础设施是否支撑当前阶段？ |
| Agent 审计能力 | 能不能审计 Agent 的决策？提示词、护栏、日志是否可观测？——D4 的技术使能 |
| 技术债务 | 当前技术选型是加速器还是减速器？技术债务是否在阻碍战略迭代？ |

## 技术可行性红绿灯

每当 strategy 或 biz_model 提出需要"速度"或"AI驱动"的建议时：
- 🟢 绿灯: 当前技术栈可支撑，6个月内可落地
- 🟡 黄灯: 需先解决前置技术债务→前置任务进入Week1-2快赢
- 🔴 红灯: 差距>12个月→降级为"远期方向"
