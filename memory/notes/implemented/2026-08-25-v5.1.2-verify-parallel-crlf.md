## 决策
V5.0.1 豁免逻辑的 read 循环内 `_f="${_f%$'\r'}"` 清洗 Windows CRLF；D484 已合并文档在 Windows 下正确跳过。

## 理由
第一性原理：Windows Python stdout 文本模式 print 输出 CRLF，`$(...)` 命令替换保留行内 \r，`git cat-file -e "origin/main:$f"` 带 \r 必失败——豁免判定依赖的文件存在性检查失效。清洗 \r 恢复判定（与 task-start L44 同型，Windows 适配层遗漏）。Anthropic：平台差异收口到适配层，一行修复。
