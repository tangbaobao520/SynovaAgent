# D911-C — G12 判据确定性（三源并集 / commit-date / fail-open 显式化）

## 触发场景（实测，非转述）

2026-09-22 CTO 排查未合 PR 队列 39 件时实测（见 `docs/synova/coordination/裁定记录-门禁三缺陷-20260922.md`
§缺陷③）：#696（= 修 main 恒红的 PR）被两条门禁同时卡死 ——
- **3a 口径互斥**：D708 接受三源并集（S1 `task-state/*.json:write_set` ＋ S2 dev doc 写集表 ＋ S3 brief Q2），
  D749/G12 只认 S3 → Q2 里写文件名（`check-pr-budget.sh`）而 G12 要路径（`scripts/control-tower/check-pr-budget.sh`）
  → 8 处「不在 Q2 范围内」。
- **3b 判据漂移**：组 12 用**文件名日期前缀 ±1 天**挑「今日 brief」，而「今日」取自 `date`（运行日）
  → brief 掉出窗口 → `ALL_TODAY_BRIEFS` 空 → 整段跳过 → 输出 `✅ G12: 所有文件均在 Q2 范围内`
  （**假绿：未执行任何判定**）。同一 commit 今天红、后天绿。
- **3c 正解不可达**：失败提示只说「不在 Q2 范围内」，不告诉执行方 D749 有 `## 写集` 机器块
  （`brief_parser.py` 机器块优先）→ 执行方只能猜格式。
- **3d 剥壳规则不对称**：`merge_writeset_gate._clean_entry()` 剥反引号 + 剥 ` — `/` —— `；
  `brief_parser.parse_q2()` 只剥 ` — ` 且不剥反引号 → 同一份 Q2 文本两道门禁读出两种结果（CTO 亲自踩）。
- **3e 模板与门禁矛盾**：`scripts/pre-commit-check.sh:886` 的 awk 在 `next` 掉 `## Done 标准` 标题行后取不到内联内容，
  而 `brief-compose` skill 教的正是「`## Done 标准:` 冒号紧跟」的内联写法（skill 原文：*至少 1 条*）。

## 决策（本卡落地）

1. **C1 源并集**：组 12 的认领源 = S1 ＋ S2 ＋ S3（复用 `brief_parser.py` / `devdoc_writeset.py`，
   不新写解析器）——与 D708 `collect_declared()` 同口径；来源逐条可打印（可审计）。
2. **C2 判据确定性**：「今日」= **被检查提交的 commit date**（`git log -1 --format=%cI <sha>`），
   不用 `date` / CI 运行日。commit date 取不到才回退墙钟，且**显式打印降级**。
3. **C3 fail-open 显式化**：有暂存文件但无任何认领 brief → 必须打印
   `⚠️ 无认领 brief → 本组未执行`；`SYNO_CI=1` 下转硬阻断（D515/D516 分层：本地软提示、CI 权威）。
4. **C4 剥壳对称**：`parse_q2()` 后置剥壳与 `_clean_entry()` 同规则（剥反引号 + `\s+[—–-]{1,2}\s+`）。
5. **C5 给正解**：报「不在 Q2 范围内」时同时提示 `## 写集` 机器块（D749 单一事实源）这条可操作路径。
6. **C6 内联 Done 写法被接受**：`## Done 标准: <标准>` 的标题行冒号后内容计入；
   阈值语义钉回门禁自己的原话「至少**一条**完成标准」（原 `-le 1` 实为「至多一行才算空」= 要求 ≥2 行，
   全仓 13 份现存 brief 因此假红）。

## 不做（防止把「判红」改成「不判」）

- 不新增门禁机制/组；不动 `ci.yml`、`scripts/audit/**`、审计标准。
- 反例必须仍在：真越界文件 → 仍 `❌`；`## Done 标准` 段为空或仅占位符 → 仍 `❌`。
