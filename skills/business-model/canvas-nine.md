# 画布九要素诊断检查清单

## 适用场景

商业模式专家被激活时自动触发。九要素检查必须以企业真实数据为基础——核心要素无数据时标注"当前数据不足以完成画布分析"。不与财务分析重复（LTV/CAC 是财务专家的领域）。

## 方法步骤

1. 调用 `query_graph` 检索本体图中与九要素相关的节点和边，逐项标注数据来源
2. 对五大信号逐项评分：价值-价格自洽性 / 客户集中度 / 收入模式健康度 / 成本结构匹配 / 伙伴依赖度
3. 调用 `business_model_canvas` 工具输出九要素现状快照
4. 检查要素间自洽性——价值主张↔收入来源、客户细分↔渠道通路是否一致

## 输出格式

```
九要素: 8/9 有数据 | 1/9 推断
五大信号: 价值-价格🟢 客户集中度🔴(前5占65%)
          收入模式🟡(续费率93%) 成本结构🟢 伙伴依赖🟡
信号关联: 客户集中↔续费率——大客户流失→续费率降
```

## 判断标准

- "数据"标签占比 > 60% → 置信度高；< 40% → 标注"需客户补充数据"
- 五大信号任一为 🔴 → 标注为商业模式风险
- 两个及以上 🔴 且有逻辑关联 → 标注"信号共振"
- ≥ 3 个要素为"推断" → 建议 GA 触发数据收集

## 常见陷阱

- 做财务分析的工作——商业模式专家只做结构匹配和信号识别
- 跳过要素——九要素必须全部检查，即使无数据也要标注"无数据"
- 忽略要素间自洽性——要素间的矛盾才是真正的风险信号
