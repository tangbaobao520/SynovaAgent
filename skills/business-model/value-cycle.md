# 曾明价值循环分析

## 触发条件
- duan-six-questions 技能完成（体质判断已有初步结论）
- 对话中出现"价值链"、"利益分配"、"渠道"、"供应商"、"合作伙伴"等关键词
- 企业有明确的上下游或平台关系

## 前置依赖
- `duan-six-questions` skill 的输出（商业模式体质基线）
- 客户/供应商/合作伙伴清单（如有）

## 执行流程

1. **价值流映射**: 钱从哪进来 → 经过哪些环节 → 各环节分走多少？
   - 画出企业所在的简化价值网络（3-5 个关键节点）
   - 每个节点标注: 谁在这个节点？他们拿走多少价值？
   - 调用: `query_graph` 获取收入结构、成本结构数据

2. **S2B2C 适配性**: 谁干什么最有效率？
   - S（平台/总部/基础设施）应该做什么？——标准化、规模化、重资产的事
   - B（前端/门店/服务商）应该做什么？——个性化、需要信任、本地知识的事
   - 判断: 当前分工是否合理？如果重新分工能让总体效率提升 20%+ → 存在重构空间
   - 不适用 S2B2C 的行业 → 跳过此步，不强行套用

3. **利益相关者动力分析**: 每个参与者为什么跟你合作？
   - 渠道: 推你的利润率 vs 推竞品的利润率 → 动力够吗？
   - 供应商: 你对供应商的依赖 vs 供应商对你的依赖 → 谈判地位？
   - 员工: 核心人才的激励是否与公司长期利益对齐？
   - 调用: `cross_validate` 与 org 专家（员工激励）、marketing 专家（渠道表现）交叉验证

4. **强制输出项**:
   - **谁最希望看到你成功？** — 价值网络中利益正相关的参与者（潜在战略盟友）
   - **谁在无意识中阻碍你？** — 激励机制与你增长目标相悖的参与者（隐藏的组织冲突）

## 输出规范
- 格式: 结构化 Markdown
- 必须包含:
  - 简化价值网络图（文本描述，3-5 个节点）
  - S2B2C 适配性判断（适用/不适用，如适用则给出分工建议）
  - 利益相关者动力矩阵（每个角色: 动力方向 + 强度）
  - 两个强制输出项: 潜在盟友 + 潜在阻碍者
- 质量标准:
  - 不能只分析"谁拿走了利润"——这是起点，不是终点
  - 如果行业不适用 S2B2C，诚实标注，不强行套用

## 反面案例

### 案例 1: 价值网络分析太浅
- **错误**: "渠道拿走 30% 利润"——然后就没有然后了
- **后果**: 没有追问"渠道为什么能拿走 30%？你有没有替代渠道？"——停留在描述，没到诊断
- **正确做法**: 对每个拿走超额利润的节点追问"为什么是他们？有没有重构空间？"

### 案例 2: 忽略利益相关者的无意识阻碍
- **错误**: 只分析了直接的利益冲突，没发现"渠道商的销售提成结构让他们倾向于推竞品而不是你的新品"
- **后果**: 诊断结论说"加大新品推广"，但渠道商根本没有动力配合
- **正确做法**: 强制输出"谁在无意识中阻碍你"——这是价值循环分析的独有洞察

## 边界
- **适用**: 有明确上下游或平台关系的企业，尤其是制造业、零售、平台型企业
- **不适用**: 极其简单的商业模式（个人服务、单人咨询）——价值网络只有 1-2 个节点时，跳过深度分析
