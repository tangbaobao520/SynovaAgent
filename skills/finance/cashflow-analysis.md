# 现金流三分法健康分析

## 适用场景

客户财务数据中包含现金流量表或至少连续 3 个月的收支流水时触发。仅有单月数据时输出"至少需要 3 个月数据才能判断趋势"。投资/融资现金流为 0 是正常现象（非上市小微企业），标注"该流数据未产生"而非"异常"。

## 方法步骤

1. 从现金流量表分离经营/投资/融资三个流的净额。非上市企业无现金流量表的，从收支流水按性质分类估算
2. 调用 `cashflow_health` 工具评估三个流各自的健康状态（🔴危险/🟡警示/🟢健康），使用 RULES.md 评分表
3. 计算经营现金流 / 总收入比值，定位企业在现金流矩阵中的象限
4. 标注数据时效性——上个月的报表不回答今天的问题
5. 输出综合判断：哪个流在出血 + 现金流支撑月数

## 输出格式

```
经营现金流/总收入: 8% → 🟡 警示 (5-15%)
流动比率: 1.2 → 🟡 警示 (1.0-1.5)
速动比率: 0.7 → 🟡 警示 (0.5-1.0)
债务/EBITDA: 2.5x → 🟢 健康 (< 2x)
现金流矩阵: 经营为正+投资为负 → 增长型企业标准形态
现金流支撑月数: 按当前月均消耗-流入净额计算，支撑 14 个月
数据时效: 最近一期为上月报表，标注"未覆盖今日状况"
```

## 判断标准

- 经营现金流 / 总收入 < 5% → 🔴 危险标注
- 流动比率 < 1.0 → 🔴 短期偿债危险
- 经营现金流为负且连续 3 个月 → 🔴 核心业务在失血
- 现金流支撑月数 < 6 → 🔴 生存预警，标注"建议立即启动融资或大幅降本"
- 三个流同时为正 → 少见，核查是否存在一次性收入/融资事件

## 常见陷阱

- 把账面利润当现金流——利润是权责发生制，现金流是收付实现制，二者可能差异巨大
- 忽略现金流趋势——单月健康不代表趋势健康，至少需要 3 个月连续数据
- 混淆经营现金流和 EBITDA——EBITDA 不含营运资本变动，不能替代经营现金流判断
