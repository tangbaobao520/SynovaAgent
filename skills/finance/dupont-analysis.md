# 杜邦分析

## 触发条件
- finance 专家被激活
- 客户有可用的财务报表数据（利润表 + 资产负债表）
- 对话中出现"回报率"、"利润率"、"资金效率"等关键词

## 前置依赖
- 利润表数据: 营收、净利润
- 资产负债表数据: 总资产、净资产
- 数据不足时 → 标注"杜邦分析需要完整的利润表和资产负债表"，不估算

## 执行流程

1. **计算三因子**:
   - 利润率 = 净利润 / 营收
   - 周转率 = 营收 / 总资产
   - 杠杆乘数 = 总资产 / 净资产
   - ROE = 利润率 × 周转率 × 杠杆乘数
   - 调用: `query_graph` 获取财务数据

2. **趋势分析**: 计算三因子过去 3 年的时间序列
   - 哪个因子在恶化？哪个在改善？
   - 调用: `cross_validate` 与 strategy 专家交叉验证（利润恶化 → 战略问题？赛道利润池在缩小？）

3. **行业对标**: 与 knowledge/industry/ 下的行业基准比较
   - 你的利润率 vs 行业均值 → 高/中/低
   - 你的周转率 vs 行业均值 → 快/中/慢
   - 你的杠杆 vs 行业均值 → 高/中/低

4. **诊断定位**:
   - 利润薄 → 定价权问题 or 成本问题 → 与 biz_model 交叉验证
   - 转得慢 → 资产效率问题 or 库存/应收管理问题 → 与 org 交叉验证
   - 杠杆高 → 财务风险 or 增长策略 → 标注风险等级

## 输出规范
- 格式: 结构化 Markdown
- 必须包含:
  - 三因子数值 + ROE
  - 3 年趋势（如有数据）→ 恶化/改善方向
  - 行业对标比较
  - 诊断定位: 哪个因子是瓶颈？
- 质量标准:
  - 不只看 ROE 绝对值——必须拆到因子层
  - 行业对标必须引用 knowledge/industry/ 的数据

## 反面案例

### 案例 1: 只看 ROE 不看拆解
- **错误**: "ROE = 22%，财务表现良好"
- **遗漏**: ROE 高是因为杠杆 5×——利润率和周转率都在下降。高杠杆掩盖了经营恶化
- **正确做法**: 必须拆到三因子。ROE 只是起点

### 案例 2: 没有行业对标
- **错误**: "利润率 15%，良好"
- **遗漏**: 同行业利润率均值 25%——15% 其实是行业下游
- **正确做法**: 必须引用行业基准。"良好"是相对的——相对于行业

## 边界
- **适用**: 有完整财务报表的企业
- **不适用**: 没有资产负债表数据的企业（如个体户、极早期创业公司）→ 使用简版单位经济学替代
