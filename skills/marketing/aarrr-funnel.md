# AARRR 增长漏斗分析

## 适用场景

客户有可追踪的用户行为数据（产品分析工具、CRM 漏斗数据）时触发。无转化率数据时标记"数据不足，建议客户安装产品分析工具"，不臆测哪个环节在漏。B2B 长周期交易的漏斗分析需标注各阶段平均停留天数。

## 方法步骤

1. 从数据源提取 AARRR 五环节各自转化率：获客→激活、激活→留存(30d)、留存→付费、付费→转介绍(NPS>0)
2. 对照 RULES.md 评分表逐环判定：🔴漏 / 🟡可优化 / 🟢健康
3. 调用 `growth_funnel` 工具获取行业基准对比数据
4. 列举客户使用的增长杠杆（流量投放/内容营销/转介绍/KOL/渠道/PLG），逐项标注🟢在转 / 🟡停了 / 🔴从未尝试
5. 输出：各环节转化率 vs 行业基准的差距 + 单环节优化建议

## 输出格式

```
获客→激活: 15% → 🔴 漏 (行业基准 > 20%)
激活→留存(30d): 35% → 🟡 可优化 (行业基准 > 40%)
留存→付费: 4% → 🟡 可优化 (行业基准 > 5%)
付费→转介绍(NPS>0): 45% → 🟡 可优化 (行业基准 > 50%)
最大漏点: 获客→激活 — 低于基准 5 个百分点
增长杠杆: 流量投放🟢在转, 内容营销🟢在转, 转介绍🔴从未尝试, KOL🟡停了
单环节建议: 获客→激活从 15%→25% 可使最终付费率提升 67%
```

## 判断标准

- 获客→激活 < 20% → 🔴 漏——着陆页或注册体验可能有根本问题
- 激活→留存(30d) < 15% → 🔴 漏——产品核心价值未传递给用户
- 任一环节低于基准 → 标注"低于基准 X 个百分点"，优先处理差距最大的环节
- 所有增长杠杆状态皆为 🔴 从未尝试 → 标注"增长体系缺失"
- 多个 🔴 同时存在时，优先修复获客→激活（漏斗最上游）

## 常见陷阱

- 只看转化率不看绝对值——高转化率但流量极少可能是统计偏差，标注样本量
- 忽略环节间延迟——B2B 从获客到付费可能 90 天，用最近一个月数据无法反映真实漏斗
- 同时优化所有环节——资源有限，标注"优先优化差距最大的环节"，不列超过 2 条同时建议
