# 市场引力分析

## 适用场景

客户所在行业有可获取的结构化数据（行业报告、财务可比数据、竞争格局信息）时触发。当行业数据 < 3 条且无法通过 query_graph 补充时，标记"数据不足以支撑市场引力结论"并跳过。

## 方法步骤

1. 调用 `query_graph` 查询客户所在行业的结构化数据（规模、增长率、集中度、进入壁垒）
2. 对波特五力逐项评分（1-10分，10=对在位者最有利），记录每项评分的数据来源
3. 调用 `market_gravity` 工具完成 PEST+CC（政治/经济/社会/技术+竞争/客户）扫描
4. 识别利润池迁移方向——产业链上哪个环节的利润在增长、哪个在萎缩
5. 综合输出：市场引力总评分（1-10）+ 关键引力信号（正/负）

## 输出格式

```
市场引力总评分: 7.2/10（中等偏高引力）
五力分布: 卖方议价能力 8, 买方议价能力 4, 新进入者威胁 6, 替代品威胁 3, 现有竞争 5
利润池迁移: 从「生产制造」迁移至「售后服务」
关键信号: 行业集中度连续3年上升（CR3 从35%→48%），利润池正在向售后迁移
置信度: 中（基于4个行业数据源，无一手客户访谈）
```

## 判断标准

- 五力中任一力评分 ≤ 3 → 标注为"结构性威胁"
- 利润池迁移方向跨环节 → 标注"迁移中，具体锁定需客户补充数据"
- 数据源 ≥ 3 个独立来源 → 置信度标注"高"；1-2 个来源 → "中"；0 个 → "不足以支撑结论"
- 任一维度无数据 → 在输出中明确标注"该维度当前无数据"

## 常见陷阱

- 把历史数据当趋势预测——行业结构可能在12-18个月内剧变，标注数据时效性
- 忽略企业规模对五力影响——同一行业中小企业和龙头的五力结构完全不同，需对照客户实际份额评分
