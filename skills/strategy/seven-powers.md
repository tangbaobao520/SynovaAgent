# 7 Powers 量化引擎

## 适用场景

在完成市场引力分析后自动触发。当客户有明显的竞争优势（高于行业平均利润率、持续增长的市场份额、客户忠诚度高）时也必须运行。不适用于从未盈利且无任何竞争壁垒的企业——此时输出"暂无适用竞争力量"即可。

## 方法步骤

1. 对 7 种竞争力量逐项判定适用性，使用 RULES.md 中的判定规则
2. 只对适用该企业的力量评分（0-10分），不适用的不算分、不报警
3. 按力量质量权重加权（反定位 ×1.4，规模经济+网络效应 ×1.2，垄断资源+流程优势 ×1.0，转换成本+品牌 ×0.8）
4. 调用 `seven_powers` 工具输出评分矩阵
5. 结合市场引力分析判断企业在 S 曲线的位置：引入期 / 增长期 / 成熟期 / 衰退期

## 输出格式

```
适用力量: 规模经济(适用), 转换成本(适用), 品牌(适用)
不适用力量: 网络效应(无用户间交互), 反定位(无不兼容的新模式)
评分矩阵:
  规模经济 7/10 (固定成本55%, 行业份额第二)
  转换成本 5/10 (年流失率12%, 行业均值15%→弱保护)
  品牌 3/10 (同功能溢价5%→可忽略)
加权总分: 6.2/10 (品牌×0.8调整后2.4+规模经济×1.2调整后8.4+转换成本×0.8调整后4.0)/(1.2+0.8+0.8)=7.0
S曲线位置: 增长期后段—规模经济将成型但品牌尚弱
```

## 判断标准

- 加权总分 ≥ 7 → "竞争壁垒强"；4-6 → "壁垒中等，可被侵蚀"；< 4 → "壁垒薄弱"
- S 曲线定位与力量评分的匹配校验：增长期企业品牌评分 > 6 可能异常（品牌需时间积累）
- 不适用的力量不应出现在评分输出中——如果七种力量全部不适用，输出"暂无适用竞争力量"

## 常见陷阱

- 对所有力量都评分——不适用的力量不算分，否则会虚增竞争壁垒评分
- 忽略适用性判定门槛——规模经济判定前提是固定成本 > 40% 且行业份额前三，不满足不评分
- 把品牌溢价当品牌力量——同功能溢价才是品牌力量的证据，单纯知名度高不是
