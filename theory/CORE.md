# 增长动力学核心方程

## 企业可持续增长

```
企业可持续增长 = f(环境条件, 生态位质量, 资本燃料, 技术就绪度, 战略-组织匹配度, 内部演化能力)

其中每一项都是一个向量，由多个哨兵指标组成。
增长停滞发生在任何一个向量降至临界阈值以下。
```

## 六层诊断架构

```
  顶层校准: 技术-经济范式分析（Perez, 2002） -> 校准所有下层哨兵的阈值

  外部层 (E1-E6):   环境诊断     - 市场还有空间吗？窗口在打开还是关闭？
  资本层 (F1-F5):   公司金融诊断  - 增长的燃料够吗？钱用对了吗？
  界面层 (I1-I13):  生态位诊断    - 生态位有多宽？壁垒有多强？实现方式可持续吗？
  技术层 (T1-T9):   技术健康与AI成熟度
  匹配层 (S1-S3):   战略-组织匹配度
  内部层 (O1-O10):  组织动力学诊断
```

## 七大学科基础

| 学科 | 来源 | 对应层 |
|------|------|--------|
| 产业生命周期 + 技术-经济范式 | Gort & Klepper 1982, Perez 2002 | 环境层（外部机会） |
| 生态位理论 | Hutchinson 1957, Levins 1968 | 界面层（价值捕获 I1-I6） |
| 交易成本经济学 | Coase 1937, Williamson 1985 | 界面层（生态位实现方式 I7-I13）|
| 演化经济学 | Nelson & Winter 1982 | 内部层（内生创造） |
| 公司金融 | Fazzari 1988, MM 1958, Stein 1997 | 资本层（资本燃料） |
| 信息论 | Shannon 1948 | 内部层（组织信息健康 O6-O7）|
| 行为经济学 + 组织学习 + 组织政治学 | Kahneman 1979, Argyris 1978, Pfeffer 1981 | 内部层（组织修复能力 O8-O10）|
