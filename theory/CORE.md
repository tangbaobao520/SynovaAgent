# Synova 核心方程

## 企业健康度

```
企业健康度 = 战略质量 × 组织能力 × 混合成熟度 × 战略组织咬合度
```

### 乘数 1: 战略质量
**负责专家**: strategy + business_model

```
战略质量 = 赛道引力 × 竞争力量 × 模式体质
```

- **赛道引力**: 这个行业的结构性利润率是多少？谁在吃掉价值链的利润？
- **竞争力量**: 你凭什么赢？这个优势是结构性的还是运营性的？
- **模式体质**: 这个赚钱机器天生好吗？

### 乘数 2: 组织能力
**负责专家**: org（杨国安杨三角）

```
组织能力 = 员工能力 × 员工思维 × 员工治理
```

- **员工能力**: 会不会？——人才密度 + 技能匹配 + 学习能力
- **员工思维**: 愿不愿？——价值观对齐 + 激励机制 + 文化强度
- **员工治理**: 让不让？——授权机制 + 流程支持 + 信息流通

### 乘数 3: 混合成熟度
**负责专家**: org（六维 D1-D6）+ tech（D4 使能）

```
混合成熟度 = D1目标对齐 × D2能力分布 × D3协作动力学
            × D4治理结构 × D5认知健康 × D6进化适应性
```

### 乘数 4: 战略组织咬合度
**负责专家**: strategy × org 交叉验证

```
战略组织咬合度 = 1 − |战略要求的组织能力 − 组织实际拥有的能力| / max(两者)
```

差距越大 → 咬合度越低 → 整体健康度折扣越大。这是交叉验证乘数——专门捕捉"战略需要A、组织却在做B"的结构性矛盾。

## 为什么是乘法

任何一个乘数为零，整体为零。这直接对应高德拉特的约束理论——**找到那个最接近零的因子，其他优化都是浪费。**

诊断的目的不是"找到所有问题"，而是"找到那个让乘积最小化的因子"。

## 验证层与行动层

| 角色 | 专家 | 功能 |
|------|------|------|
| 验证层 | finance + marketing | 不改变方程的数值——从财务和市场两端验证诊断结论 |
| 行动层 | action | 接收诊断结果，找到约束，转化为 CEO 可执行的行动方案 |
| 使能层 | tech | 数字底座是否支撑当前阶段的战略×组织×混合？ |
| 知识层 | knowledge | 跨专家知识检索 + 行业对标 + 模式识别 |
